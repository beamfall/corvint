corvint-tasks queue snapshot [--out FILE] [--worktree DIR]   (writes the intent tree as one taskman-intent-snapshot/0 object for a lane host without a journal, which reads it with CORVINT_TASKS_SNAPSHOT=FILE; --worktree reads DIR/.taskman instead of the primary checkout's store, so a linked or pruned worktree's store is validated with ticket show/blockers, queue status and roadmap; example: corvint-tasks queue snapshot --worktree ../lane --out /tmp/lane-snapshot.json)
