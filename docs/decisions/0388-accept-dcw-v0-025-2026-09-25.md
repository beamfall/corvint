# Decision 0388 — accept `DCW-V0-025` and the `GOC-V0-009` and `ERI-V0-006` amendments

Date: 2026-09-25. Status: accepted. Authority: repository owner instruction "accept DCW-V0-025 and
both amendments" (2026-09-25).

V1-0264 proposed that the daily dogfood path keep two more `corvint impact` refusals as typed
abstentions, so a repository with no Go module or a change at the Go module root can still complete.
The accepted `GOC-V0-009` and `ERI-V0-006` admitted only `unsupported-impact-range`, so the change
also needed an amendment to each.

1. **`DCW-V0-025` is accepted as written** (`docs/specs/daily-change-evidence-workflow-v0.md`; V1-0264,
   PR #204). `prechange-impact` keeps an exit-2 refusal whose single stderr envelope carries
   `unsupported-impact-range`, `unsupported-impact-repository` or `unsupported-impact-path` as a
   `NOT_PRODUCED` row under that exact code. The row does not block `"complete": true`, and
   `dogfood check` accepts it only under the existing bindings and verifier rerun. Every other code,
   exit or shape still blocks.
2. **The `GOC-V0-009` amendment is accepted** (`docs/specs/go-only-cutover-v0.md`). The qualifying
   typed exit widens to exactly those three codes, each retained under its own code with the same
   artifact bindings.
3. **The `ERI-V0-006` amendment is accepted** (`docs/specs/expanded-range-impact-v0.md`). The
   repository coordinator may preserve `unsupported-impact-repository` or `unsupported-impact-path`
   as explicit `NOT_PRODUCED` context evidence under the same terms as `unsupported-impact-range`.

The acceptance evidence is the V1-0264 BUILD-LOG entry, which covers the built-binary fixture
`TestDogfoodDailyPathCompletesWhenImpactRefusesTheRepositoryOrModuleRoot` and the
`script/dogfood-change_test.sh` cases. A real Beamfall change stays NOT_OBSERVED.

Rollback: revert the V1-0264 change to `internal/dogfoodflow` so that only `unsupported-impact-range`
qualifies, and restore the proposed status of `DCW-V0-025` and both amendments. No persisted format
changes: the abstention artifact keeps `corvint-dogfood-context-abstention/0`.
