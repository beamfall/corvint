# Decision 0328 — publish the issue #49 fix as v0.5.0a2

Date: 2026-09-20. Status: accepted. Authority: repository owner explicitly requested that the
issue #49 fix be merged and followed by a new GitHub release.

## Decision

The publication target is `0.5.0a2`, Git tag `v0.5.0a2`. `VERSION`, native version output, archive
smoke expectations, exact editor admission, active installation/release documentation and release
tests move together. Historical decisions, measurements, receipts and the existing `v0.5.0a1` tag
retain their original identities.

This release retains decisions 0108, 0109 and 0327's boundaries: **No signing**, publisher identity
`NOT_VERIFIED`, GitHub prerelease status, no command or integration promotion, four non-Windows core
archives plus their unchanged gate-produced `SHA256SUMS`, and no Windows attachment. The separately
qualified macOS arm64 companion is included because the issue #49 fix ships in
`corvint-js-test-provider`; it must bind the same exact Corvint commit and retain its source,
licensing, manifest, checksum and installed qualification evidence.

The release delta is the standard Playwright 1.63 device-spread regression from issue #49 on top of
issue #50's stricter bundled-browser qualification. The exact final commit must pass the scoped unit
and live Playwright witnesses. On 2026-09-20 the repository owner explicitly directed this release
to skip the full repository release gate. The full-gate row therefore remains `NOT_RUN`; the earlier
gate on the issue branch is supporting evidence only and is not represented as exact-candidate
qualification. Artifact construction still verifies the bytes it produces, but no skipped gate or
qualification is reported as passing. Version change and publication do not qualify retrieval,
hosted CI, editor hosts, other Playwright tuples or any previously `NOT_RUN` claim.

## Rollback

Before publication, withdraw the candidate without moving an existing public tag. After publication,
leave `v0.5.0a2` immutable and supersede it with a later version; do not rewrite release assets,
receipts or historical evidence.
