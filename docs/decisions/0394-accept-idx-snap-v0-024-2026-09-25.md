# Decision 0394 — accept `IDX-SNAP-V0-024`

Date: 2026-09-25. Status: accepted. Authority: repository owner instruction "accept
IDX-SNAP-V0-024 and ticket the gaps" (2026-09-25). Finding: pre-1.0 panel review blocker B9.

One tracked path whose Git bytes are not UTF-8 made `index`, `impact`, `context`, `affected --base`
and clean-tree `prove` refuse the whole repository.

`IDX-SNAP-V0-024` is accepted as written (`docs/specs/index-snapshot-v0.md`). Such a path is kept
out of `Sources` and recorded in `Exclusions` with the reason `unsafe-or-non-utf8-path`, under its
display form (each invalid byte run replaced by U+FFFD). Every other path indexes and answers as
before, and path `impact` and `prove` disclose the exclusion through the receipt's existing
exclusion sample. No wire shape changes.

The acceptance evidence is the B9 BUILD-LOG entry and the tests
`TestNonUTF8TrackedPathIsExcludedAndTheRestIndexes` and
`TestParseStatusNamesNonUTF8PathsInDisplayForm` in `internal/contextindex`.

## Gaps left open

Each gap is a separate ticket; this decision does not close them.

1. V1-0313: `query --task` and `prove --task` still refuse with `unsupported-query-history` when history
   holds such a path. That refusal is frozen under `GPK-V0` with oracle parity.
2. V1-0314: `affected` and `prove` on a dirty tree still refuse, because
   `internal/liveverify/affected/dirty.go` has its own status decoder.
3. V1-0315: the `context` packet has no exclusions member, so the exclusion is disclosed only in the `impact`
   and `prove` receipts.

Rollback: restore the three refusals in `internal/contextindex/git.go` and
`internal/contextindex/history.go`, and restore the proposed status of `IDX-SNAP-V0-024`. No
persisted format changes.
