# Decision 0387 — accept `GPK-V0-066`, reject `GPK-V0-067`

Date: 2026-09-25. Status: accepted. Authority: repository owner instruction "accept GPK-V0-066,
reject GPK-V0-067" (2026-09-25).

Two Go-kernel ranking amendments were proposed on 2026-09-25 and both changed ranking by default.

1. **`GPK-V0-066` is accepted as written** (`docs/specs/go-production-kernel-migration-v0.md`,
   "Accepted amendment: unsupported records yield to supported symbols"; V1-0260, PR #189). When a
   record or document packet fails the `GPK-V0-039` floor, `evalQuery` compiles the confident-symbol
   packet and publishes it only if it clears the same floor; otherwise the withdrawal stands.
   Packets that already clear the floor are unchanged. The analyzer schema moves to
   `corvint-analyzer/84`. The frozen evaluations recorded in the V1-0260 BUILD-LOG entry are the
   acceptance evidence.
2. **`GPK-V0-067` is rejected** (V1-0263, PR #198 at `9a3ac924`). It proposed scoring a non-test Go
   reverse importer that names an exported declaration of the changed file at 775, and a feature or
   scenario record reached only through a reverse-importing test at 650. It does not enter the spec,
   PR #198 closes unmerged, and the requirement ID is not reused. The owner gave no reason. The
   V1-0263 finding (importer-test records outranking Go callers in `impact`) stays open; a later fix
   needs a new proposal.

Rollback: for item 1, revert the `evalQuery` substitution, restore the proposed status of
`GPK-V0-066` and the analyzer schema to `corvint-analyzer/83`. Item 2 changes no code.
