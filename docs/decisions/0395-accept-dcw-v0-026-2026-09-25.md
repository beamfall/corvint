# Decision 0395 — accept `DCW-V0-026`

Date: 2026-09-25. Status: accepted. Authority: repository owner instruction "accept DCW-V0-026 and
ticket the base-commit check" (2026-09-25). Finding: pre-1.0 panel review must-fix M1.

`dogfood change` reran `query` and `impact` against `HEAD` into the agent's pre-change receipt
paths (`<git-dir>/corvint/prechange-query.json` and `prechange-impact.json`). That truncated the
base-tree receipts, and the report called the post-change output `prechange-* PRODUCED`.

1. **`DCW-V0-026` is accepted as written** (`docs/specs/daily-change-evidence-workflow-v0.md`;
   PR #222). `dogfood change` never writes the agent receipts. Its own runs are the
   `coordination-time-query` and `coordination-time-impact` steps, in file names, report rows,
   `packetCoverage` entries and NOTE lines. Reports and self-observations written earlier keep
   their `prechange-*` rows, and `dogfood-observe` admits both spellings.
2. **The rewording is accepted.** `DCW-V0-016` and the accepted `DCW-V0-025` name the renamed
   `coordination-time-impact` step. `LCP-V0-005` says the coordinator never writes the pre-change
   receipts. Neither changes what those requirements allow or refuse.

The acceptance evidence is the panel M1 BUILD-LOG entry and
`TestChangeKeepsAgentPrechangeReceipts`.

V1-0316. An absent receipt stays non-blocking, as `DOGFOOD-002` requires none.
