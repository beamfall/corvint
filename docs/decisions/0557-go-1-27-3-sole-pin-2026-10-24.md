# Decision 0557 — go1.27.3 is the sole Go toolchain pin

Date: 2026-10-24. Status: accepted. Authority: repository owner, in chat on 2026-10-24: "can we make
sure thing are using go1.27.3 so things are always valid". It partially supersedes decision 0522
(the go1.27.2 pin) and decision 0547 (go1.27.3 admitted beside it, local checks only) for the
toolchain pin. Both stay in force for everything else they record, including the structural tuples
and the retained-table provenance below.

## Context

Decision 0547 admitted go1.27.3 for local checks only. CI (`.github/**`), the release scripts, the
release identity (`conformance/release-artifact-v0`, `internal/releasecandidate`,
`internal/companionrelease`), the go-live-test provider tuple and `tools/**` still asserted exactly
go1.27.2. The development host has only go1.27.3, so every local build and test ran on go1.27.3
while CI and the release checks required go1.27.2. A build, test or release made with the one
installed toolchain could not be valid end to end.

## Decision

1. go1.27.3 is the one exact pin everywhere a toolchain is asserted or installed:
   - the root `go.mod` and `tools/local-authority/go.mod` directives (`go 1.27.3`, no `toolchain`
     directive);
   - the Makefile `go-version` target and the `AGENTS.md` verify line, which accept exactly
     `go1.27.3`. go1.27.2 is not kept as a local transition revision; one pin is the point of this
     decision;
   - every `setup-go` install, `GOVERSION` assertion and printf'd go.mod line in `.github/workflows`;
   - the release scripts and `cmd/corvint-public-release-check`, each release-artifact schema
     `const`, the release-candidate and companion-release identity, and the `tools/**` checks;
   - the go-live-test provider tuple (`internal/liveverify/provider.GoVersion`,
     `conformance/go-live-test-v0`). The 0547 module-cache go1.27.2 fallback in the
     `cmd/corvint-go-test-provider` fixture is removed; the harness's own GOROOT is the pin.
   - the toolchain sets in `tools/corvint-pr-tests` (AFP-V0-296) and full OpenCode qualification
     (AHI-175), which each admit exactly `go1.27.3`.
2. These stay as they are on purpose:
   - `CEM-V1-050` keeps admitting `go1.27.1`, `go1.27.2` and `go1.27.3` as structural tuples, because
     sealed historical packets bind the first two.
   - `.github/cishards` `SourceGoVersions` admits `go1.27.1`, `go1.27.2` and `go1.27.3`. The retained
     package-cost and test-slice tables were measured under the older toolchains and stay valid
     without regeneration.
   - `interop/cem01-go/go.mod` keeps `go 1.24.0`. It is the portable consumer's declared source-build
     floor (`cem-stable-v1.md`), not a toolchain pin.
   - The build log, earlier decision bodies, sealed `protocol/**` packets, `.corvint/changes` CEMs,
     measurement records and captured streams keep the version they recorded.
3. The sql-native ratchet pin table drops its two `go1.27.2` rows, because `SNR-V0-030` admits only
   versions the `go-version` target admits. The Homebrew darwin/arm64 `go1.27.3` row stays. The
   linux/amd64 official-module row that `SNR-V0-031` requires is `NOT_OBSERVED` until it is
   measured on such a host.

## Consequences

- Release artifacts and rc builds made with go1.27.2 no longer match the release pin. The
  unpublished 1.0.0-rc.3 candidate must be rebuilt with go1.27.3 before it is published.
- A host with only go1.27.2 now refuses at `make go-version`, `make windows-vet`, the release
  gates, the go-live-test fixture and the qualification drivers. Install go1.27.3.
- A linux/amd64 host running the official go1.27.3 module refuses the opt-in
  `make sql-native-ratchets` with `TOOLCHAIN_MISMATCH` until its row is measured.
- The Windows/WSL benchmark host (`docs/BENCHMARK-HOST.md`) still records go1.27.2 and needs
  go1.27.3 before its runs match the pin.
- CI changes (`.github/**`) need the owner's ci-control-plane status before they merge.

## Rollback

Revert the change that applied this decision. That restores the decision 0547 state: go1.27.2 as
the pin with go1.27.3 admitted for local checks, CI and release on go1.27.2, and the removed
sql-native ratchet rows.
