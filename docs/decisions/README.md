## Checking numeric uniqueness

Run `script/check-decision-numbers.sh` from anywhere in the repository. It checks every direct
`docs/decisions/NNNN-*.md` file, lists every leading number claimed by multiple files, and exits
non-zero when any collision exists. Exactly one pair is grandfathered by
`0048-four-owner-calls-2026-09-04.md`: the two `0016` files, both cited by full filename from frozen
evidence; a third `0016` file or any other collision still fails.

## Citing a decision unambiguously

Cite a decision by its full filename (which embeds the topic and, from 0012 forward, the date), not
by number alone, whenever the citation could cross a lineage boundary — a code review comment,
a merge/integration note, or any reference outside the branch that recorded the decision. A bare
"decision 0012" is only unambiguous within the lineage making the reference.

This index remains a documentation aid; `script/check-decision-numbers.sh` provides the mechanical
check, exposed as `make decision-numbers-check` and a `make gate` prerequisite since
`0048-four-owner-calls-2026-09-04.md`.
