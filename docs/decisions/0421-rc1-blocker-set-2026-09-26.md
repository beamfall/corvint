# Decision 0421: the 1.0.0-rc.1 blocker set

Date: 2026-09-26. Status: accepted (owner answer 2026-09-26: "use your recommended blocker set").
Tickets: V1-0018, V1-0020.

## Context

V1-0020's first acceptance criterion says every P0 and P1 release blocker is closed before the
release candidate is published, but no decision named those blockers. On 2026-09-26 the store had 6
open P0 and 21 open P1 tickets:

- The six P0 tickets are the release chain itself (V1-0016, V1-0018 to V1-0021) plus V1-0014, which
  is already on the `post-1-0` milestone.
- Ten of the P1 tickets have merged fixes and wait only for manual completion.
- Reviews filed new P1 tickets throughout the freeze work, so without a named set the candidate had
  no fixed finish line.

## Decision

1. **Blockers.** The P1 release blockers for `1.0.0-rc.1` are exactly these six tickets:

   | Ticket | Why it blocks |
   |---|---|
   | V1-0263 | `impact` omits a cross-package Go caller that Core claims to report |
   | V1-0284 | the Core refusal envelope is not uniform across frozen modes (`CCF-V1-004`) |
   | V1-0286 | Claude Code hooks degrade on every prompt after each commit |
   | V1-0346 | the local console release gate passes flags the companion release command does not define |
   | V1-0350 | the frozen enumeration register omits nested enumerations |
   | V1-0357 | the go-product CI job runs within minutes of its time limit |

2. **Deferred past 1.0.** These tickets stay open at their current priority but do not block
   `1.0.0-rc.1` or `1.0.0`:

   | Ticket | Why it waits |
   |---|---|
   | V1-0014 | independent producer and consumer qualification is already on `post-1-0` |
   | V1-0184 | the Beamfall dogfood receipt is external evidence, not a Core defect |
   | V1-0249 | the flows run-evidence adapters are experimental AFU-V1 work outside the Core surface |
   | V1-0259 | both intent routes merged (#187, #190); what remains is Beamfall adoption |
   | V1-0285 | the `CCF-V1-007` N-1 rule needs a spec correction, and N-1 replay stays opt-in |
   | V1-0319 | the paired orientation trial is blocked on a Beamfall run |

3. **Completed fixes.** The ten P1 tickets whose fixes have merged are closed by the owner's manual
   completion and are not part of the set.
4. **Store encoding.** Each blocker changes code that the frozen candidate must contain, so the six
   blockers become `COMPLETED` dependencies of V1-0018 (freeze), alongside its existing ones. V1-0020
   reaches them through V1-0019.
5. **Closed set.** A ticket filed after this decision joins the set only when the owner adds it.

## Non-goals

This decision does not change any ticket's priority or milestone, close any ticket, or change the
release chain `v0-6`, `v0-9`, `v1-0`.

## Rollback

Revert this change and reset V1-0018's dependencies to V1-0011, V1-0012, V1-0016 and V1-0017.
