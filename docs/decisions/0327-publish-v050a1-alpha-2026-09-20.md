# Decision 0327 — publish the integrated alpha as v0.5.0a1

Date: 2026-09-20. Status: accepted. Authority: repository owner explicitly selected `v0.5.0a1`
while authorizing integration, merge and publication of GitHub issues 39–47.

## Decision

The publication target is `0.5.0a1`, Git tag `v0.5.0a1`, superseding the unperformed `0.4.0a4`
publication target for this integrated candidate. `VERSION`, the CLI version constant, active
release documentation, exact editor admission, archive manifest and publication tests move together.
Historical measurements, decision records and receipts keep their original version identities.

This release retains the publication constraints of decisions 0108 and 0109, expressly selecting
**No signing** for `0.5.0a1`: publisher identity remains `NOT_VERIFIED`, checksums prove byte integrity
only, and no signing key or identity is requested or used. The GitHub release is a prerelease, with
the four independent non-Windows CLI archives (`darwin_amd64`, `darwin_arm64`, `linux_amd64`,
`linux_arm64`) and gate-produced `SHA256SUMS`. A separately qualified optional macOS arm64 companion
bundle may accompany them; it never changes the default one-binary install.

The experimental/unqualified retrieval status and no-promotion boundary of decision 0307 continue
for this alpha. Changing the version is not qualification, publication evidence, completion of an
unrun check, or promotion of any experimental feature. The combined gate and release/install
qualification must bind the exact final committed candidate before publication.

## Rollback

Before publication, withdraw this candidate without moving an existing public tag or rewriting
historical records. Any later publication version or signing policy requires its own owner decision.
