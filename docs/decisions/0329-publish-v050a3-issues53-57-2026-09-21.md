# Decision 0329 — publish the integrated issue #53–#57 candidate as v0.5.0a3

Date: 2026-09-21. Status: accepted for candidate preparation; the exact token awaits the owner's
confirmation before any tag is pushed. Authority: repository owner asked that every open GitHub
issue (#53, #54, #55, #56, #57) be covered by the next rerelease and then requested a new version.
The owner did not name the token; `0.5.0a3` is the next alpha increment in the `0.5.0aN` series
selected by the release coordinator, and a different owner selection replaces it before publication.

## Decision

The publication target is `0.5.0a3`, Git tag `v0.5.0a3`. `VERSION`, native version output, archive
smoke expectations, exact editor admission, active installation/release documentation and release
tests move together. Historical decisions, measurements, receipts and the existing `v0.5.0a1` and
`v0.5.0a2` tags retain their original identities; `v0.5.0a2` is never rewritten.

This release retains decisions 0108, 0109, 0327 and 0328's boundaries: **No signing**, publisher
identity `NOT_VERIFIED`, GitHub prerelease status, no command or integration promotion, four
non-Windows core archives plus their unchanged gate-produced `SHA256SUMS`, and no Windows
attachment. No companion is attached unless the exact candidate commit carries its own installed
qualification evidence; the live Playwright `/2` qualification for issue #56 is `NOT_RUN`, so `/2`
remains non-promotable and no companion is qualified by this decision.

The release delta is the integration of the sealed issue branches for #53 (behavior-contract
provider records and variation reconciliation frontiers), #54 (criterion-level falsification
controls), #55 (OpenCode file-change bursts and unadmitted suffixes), #56 (sensitive input
redaction in browser runtime evidence) and #57 (affected-test planning from explicit dirty-worktree
snapshots), plus `main`'s gate ledger (`GL-V0`). Unlike decision 0328, the full repository gate MUST
run on the exact clean candidate commit and MUST pass before publication; each issue branch also
carries its own enrolled or recorded gate evidence. External MCP host qualification (#57) and live
Playwright `/2` qualification (#56) stay `NOT_RUN`. Version change and publication do not qualify
retrieval, hosted CI, editor hosts, other Playwright tuples or any previously `NOT_RUN` claim.

## Rollback

Before publication, withdraw the candidate without moving an existing public tag. After publication,
leave `v0.5.0a3` immutable and supersede it with a later version; do not rewrite release assets,
receipts or historical evidence.
