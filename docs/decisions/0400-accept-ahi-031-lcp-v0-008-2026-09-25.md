# Decision 0400 — accept `AHI-031` and its `LCP-V0-008` amendment

Date: 2026-09-25. Status: accepted. Authority: repository owner instruction "accept AHI-031,
LCP-V0-008, CCF-V1-006 and CCF-V1-007" (2026-09-25). Finding: pre-1.0 panel review blocker B8.
Ticket: V1-0286.

After a commit no index snapshot matches the tree, so every automatic `dogfood event` read
compiled the index in memory and ran past its deadline. The event reported only
`dogfood-event-deadline`, which the Claude Code adapter treats as an expected fallback, so every
prompt degraded with no cause and no remedy shown.

`AHI-031` is accepted as written (`docs/specs/agent-harness-integration-v0.md`; PR #225). An
event whose deadline expires after a snapshot miss reports `dogfood-event-index-snapshot-stale`;
the Claude Code adapter treats that reason as a fault and names the refresh argv
`["corvint","--root",ROOT,"index","--if-stale"]`. The matching `LCP-V0-008` amendment
(`docs/specs/local-completion-policy-v0.md`) is accepted with it, and the code joins the admitted
`dogfood event` rejection registry. Hooks still write no snapshot.

The acceptance evidence is the panel B8 BUILD-LOG entry,
`TestDogfoodEventSnapshotMissExpiryNamesStaleSnapshot` and
`TestClaudeAdapterStaleSnapshotNamesRemediation`, both failing on the base and passing with the
change. The Codex adapter shows the new code without the refresh argv; that stays a follow-up.

Rollback: report `dogfood-event-deadline` for every expiry again, remove the stale-snapshot
branch from the Claude adapter, and restore the proposed status of `AHI-031` and the
`LCP-V0-008` amendment.
