# Decision 0072 — The 0.4.0 version bump is one tested tuple, not a constant edit; the wave lands at 0.4.0a3

Date: 2026-09-05. Status: accepted (2026-09-05, delegated call). Authority: repository owner, delegated call; the owner instructed on 2026-09-05 that the wave land once the gate passes. This record settles what the landing carries.

## Context

The 2026-09-05 wave (decisions 0066 to 0071) is staged and gated. The planned release commit
bumped `0.4.0a3` to `0.4.0`. Reading the contracts that carry the token shows the bump is not a
constant edit:

- `VSC-V0-007` (`docs/specs/vscode-extension-v0.md`) admits `0.4.0a3` as the only V0
  developer-preview token; every other token is `CLI_INCOMPATIBLE` until an amendment adds an
  exact tested tuple.
- `tools/release_artifact.py` (`EXPECTED_VERSION`, the dist-info name, the `--version` smoke),
  `tests/test_release_artifact.py`, `pyproject.toml`, `cmd/corvint/main.go`, and the
  release-artifact conformance fixture (`conformance/release-artifact-v0/gate_test.go`, smoke
  `expectedVersion`) all pin the token, and `script/go-archive-gate` runs inside `make gate`.
- Decision 0064 sequences the add-on portfolio after "the 0.4.0 tag"; the tag is the owner's.

Changing the token in some of these and not the others produces a binary the extension refuses
and a wheel the checker rejects. Doing all of them after the gate has run would leave the landing
without gate evidence for exactly the files the gate checks.

## Decision

1. The wave lands on `main` at `0.4.0a3`. The release-notes section is headed "Unreleased" and
   lists what shipped and what was measured.
2. The 0.4.0 bump is one change that moves every pin above together: the `VSC-V0-007` amendment
   with the tested tuple, `EXPECTED_VERSION` and the dist-info and smoke strings, the Python tests,
   `pyproject.toml`, the Go constant, and the conformance fixture; it runs `make gate`, the
   Python tests, and `script/release-checklist` on its own tree before the owner cuts the tag.
3. Until then `script/release-checklist` reports the tag row against `v0.4.0a3`, which is where
   it is.

## Evidence and falsifier

`rg -n '0\.4\.0a3' --glob '!docs/**'` lists every pin the bump must move; a bump that leaves
one behind fails either `tools/release_artifact.py check`, the release-artifact conformance
package, or the extension's `VSC-V0-007` probe.

## Consequences

- The landing needs no rerun of the archive gate or the Python tests for the version.
- The next-generation handoff (`docs/plans/NEXT-GEN-HANDOFF-2026-09-05.md`) starts from a
  consistent `main` at `0.4.0a3`.

## Rollback

None needed; the bump is a forward change.
