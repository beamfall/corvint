# Decision 0293 — The pinned toolchain moves from go1.27.0 to go1.27.1

Date: 2026-09-14. Status: accepted (owner, "maybe we can use 1.27.1", 2026-09-14). Authority:
repository owner; applied in the isolated performance lane before its measurements.

## Context

Homebrew upgraded the host's default `go` to 1.27.1 while `go 1.27.0` remained the exact pin in
`GPK-V0-018`, `PUB-V0-003`, the compat-trial build identity, the go-live provider identity, the
release-artifact gate, the Makefile verify line and `AGENTS.md`. Under the upgraded host, every
exact identity check refused: `conformance/go-live-test-v0` and `cmd/corvint-go-test-provider`
reported `IDENTITY_MISMATCH`, and `tools/compat-trial` plus its `build-fixtures` refused with
"requires go1.27.0". The 2026-09-14 performance lanes had already built their candidates with
1.27.1 without noticing (`go version <binary>` on the retained artifacts says so).

## Decision

The exact pin becomes `go1.27.1` everywhere a check is exercised by `go test ./...`, `make gate`
or a release gate: `go.mod` (`go 1.27.1`), the Makefile and `AGENTS.md` verify lines,
`internal/companionrelease`, `internal/liveverify/provider`, `conformance/go-live-test-v0`,
`conformance/release-artifact-v0` (code, manifest, README), `tools/compat-trial`, and the spec
sentences that state the pin (`GPK-V0-018`, `compat-trial-v0`, `go-live-test-provider-v0`).
Every check stays exact: nothing accepts a range or skips identity validation.

Left as they were, each with a follow-up in `docs/agent-memory/fixes.md`: the
`tools/local-authority` wasm recipe and the `experimental/analyzers/sqlnative` candidate
coordinate, whose pinned digests were measured with the 1.27.0 keg and need their own
re-measurement; the `docs/specs/analyzer-candidate-profiles.md` fixture coordinates; and every
historical evidence record.

## Consequences

- A host without go1.27.1 as `GOTOOLCHAIN=local` refuses, as before with 1.27.0.
- The performance record separates toolchain gains from source gains: every arm of the
  2026-09-14 qualification matrix is built with the same verified go1.27.1 executable, and the
  earlier go1.27.0-built numbers stay labelled as such.
- Rollback: revert this commit; the 1.27.0 keg remains at `/opt/homebrew/Cellar/go/1.27.0`.
- Addendum (same day): the first full suite under the pin found five checks the move had
  missed, all refusing on `1.27.0` against a `go.mod` that now says `1.27.1`: the analyzer-go
  compiled-CLI keg path, the release-artifact manifest directive and archive-report toolchain
  checks with their fixtures, the archive verifier's directive check, and the provider's
  version-mismatch fixture. Moved in a follow-up commit; every check stays exact.
- Addendum (2026-09-18): the first GitHub Actions run of the published tree found the last one.
  `.github/workflows/ci.yml` still installed `1.27.0` for the `go-product` and
  `artifact-integrity` jobs and asserted `go1.27.0`, so both refused at `go.mod requires
  go >= 1.27.1` before any test ran; the workflow had never executed before publication. The
  three pins move to `1.27.1`. The `go-interop` job keeps `1.23.12`, its module's own floor.
