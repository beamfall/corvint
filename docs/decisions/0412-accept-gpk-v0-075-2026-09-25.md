# Decision 0412 — accept `GPK-V0-075` (proposed as `GPK-V0-068`)

Date: 2026-09-25. Status: accepted. Authority: repository owner instruction on PR #247 "accept
GPK-V0-068, fix the reason text, add the register entry" (2026-09-25). Ticket: V1-0263.

PR #247 proposed the omitted-caller disclosure as `GPK-V0-068`. Decision 0396 had already accepted
a different clause under that ID, so this clause is recorded as `GPK-V0-075`, the next ID unused on
`main` and on every open branch. The content the owner accepted is unchanged. The owner's "fix the
reason text" adds part (b).

`GPK-V0-075` is accepted (`docs/specs/go-production-kernel-migration-v0.md`):

- (a) When the result limit drops a direct Go caller's reverse-import row from a path `impact`,
  `coverage.uncertainty` names the caller, its call line, its rank and the limit. The budgeted
  packet carries the same lines. The disclosure is computed after the `GPK-V0-070` caller
  reservation, so it names only callers that the reservation also left out.
- (b) A feature or scenario record admitted only by the marker of a test that imports a changed
  path gives the reason `test TEST importing changed CHANGED carries KIND:ID`. A record whose marker
  a changed path itself carries keeps `changed path carries KIND:ID`. The score stays 800, and the
  `GPK-V0-067` re-scoring stays rejected (decision 0387).

The analyzer schema moves from `corvint-analyzer/85` to `corvint-analyzer/86`, so existing indexes
rebuild. The retired oracle emits neither form. That divergence is registered as `DR-0042`, a
`python-defect` declared on `impact-python-module` and `impact-python-nomodule` in
`conformance/cli-parity-v0`.

Evidence. Beamfall at `0d7796be`, `impact internal/plugin/trust.go
internal/integrationhost/model_loader.go --limit 10`, compared against an `origin/main` (`b549d59f`)
binary:

- Before: the same ten rows. `identify-scrape` and `library-health` (800) both give "changed path
  carries", although neither changed path carries either marker. `coverage.uncertainty` says only
  "119 ranked results omitted by result limit". The direct caller `internal/app/skipdetect_jobs.go`
  ranks 30th and is not named.
- After: the same ten rows, scores and order. The two reasons name
  `internal/identify/identify_test.go` and `internal/graph/health_bulkops_selected_test.go`, each
  "importing changed internal/plugin/trust.go". Three uncertainty lines name
  `internal/app/skipdetect_jobs.go` (line 87, rank 30), `internal/graph/graph_consoleconfig.go`
  (line 73, rank 34) and `internal/integrationhost/model_artifact.go` (line 115, rank 46).

Tests:

- `TestImpactDisclosesOmittedDirectGoCallers/GPK-V0-075` covers (a).
- `TestImpactNamesTheImportingTestThatCarriesARelatedMarker/GPK-V0-075` covers both reason forms
  of (b) and the 800 score. It fails when the carrier selection is disabled.
- `TestGPKV0002ManifestReplay` passes with the `DR-0042` declarations.

Rollback: revert the change. That removes the disclosure and the importing-test reason, restores
`corvint-analyzer/85`, removes the `DR-0042` declarations and restores `PASS` for the two Python
cases, and returns `GPK-V0-075` to proposed.
