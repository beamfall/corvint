## Codex review fix (2026-11-02)

Codex returned PASS with one P2 finding and no P0 or P1 findings.

- P2, fixed: in `TestFreshHelperInterruptionReapsChild`, the parent cancels as soon as the PID
  marker exists. `os.WriteFile` creates the file before it writes the PID, so a descheduled
  descendant could be killed with an empty marker, and `strconv.Atoi` would then fail even though
  cleanup was correct. The descendant now writes `<marker>.tmp` and renames it onto the marker, so
  the marker path appears only with its full content. Verified with 50 runs of the test and one
  whole-package run on Linux, plus `go vet` for linux and windows.
- The earlier seal attempt failed at batch-precheck `repin (mechanical)`. That repin moved the
  `analyzer_schema_test.go` citation in `docs/specs/stable-operations-v0.md` from line 250 to 274,
  following the V1-3659 test change. It is committed here.

## Friction

1. A PreToolUse hook blocks native-Windows `go test` over ssh, and heavy.sh has no PowerShell mode,
   so the lane wrote throwaway `.ps1` runners.
2. `~/bench/ci-preflight.sh` lives outside the repository and has no package scope. Scoping AC3
   meant copying it with one edit.
3. The serial `-race` witness test takes about 130 s per run at 48 burners. 20 or 50 serial loaded
   runs do not fit one bounded command.
4. AFP-V0-415 claimed projectpath item (1) was fixed, but it still failed natively.
5. The TestWindowsJobObjectABI expectations had never run natively, so the trailing zero-size pad
   was missed. Two more Windows test defects followed: the missing `.exe` and the 100 ms deadline.
6. The Windows PATH `go` is 1.27.0, while the repository needs 1.27.3.
7. The node host-adapters test needs undocumented envs.
8. Many Windows refusals are masked by generic errors, so `SkipWindowsRefusal` cannot classify
   them. Two refusals are unlisted: upgradechanges and native-hook-observer.
9. WSL /tmp is at 71% from other lanes' leaks, and the Go cache in `~/.cache` is 34G and unbounded.
10. release-gates still fails on main, on four targets (five on macOS).
11. Issue #1958 cannot be resolved after the repository reset.
12. The assigned ID block collides: AFP-V0-640 and 641 are already used.
13. The Mac load is about 96 on 12 cpus.
14. IsolateGit's identity env silently outranks `-c user.*` in fixtures. A package adopting it can
    change committed authors, which broke changee2e's head-author oracle.
15. cce-live runs only when internal/changee2e changes, so "5 hosted runs" evidence comes from old
    branch runs and is never refreshed on main.
16. The V1-2746 "on CI" target is unobservable, because main CI reuses results and prints no test
    timings.
17. Relocate has no store-package test helper. A store-level RELOCATE test has to rename the
    checkout, re-resolve it, re-lower the writer-checkpoint floor (keyed by StateDir), and use the
    fixture clock (a reap moved it past wall time).
