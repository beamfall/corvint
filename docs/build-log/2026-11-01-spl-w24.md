   `c7dd32799`. The findings were made on `095d0a981`.
2. The V1-2810 AC3 timing was never recorded. It cannot be measured outside the lane's checkout,
   because `dogfood-check` at a bind commit needs that lane's dogfood report.
3. The V1-4091 assignment conflicts with charter rule 8: ckc-w15 owns propose-citations.
4. `grep -r /private/tmp` on the Mac hung past the tool timeout.
5. Mac `tar` piped over ssh writes LIBARCHIVE xattr warnings and `._*` AppleDouble files on WSL
   unless `COPYFILE_DISABLE=1` and `--no-xattrs` are used.
6. The V1-3892 acceptance names `corvint affected`, which another lane (aff-w23) owns.
7. `git log --all --grep=V1-2810` lists commits 6dff80a12 and d9f071dc8, which are not ancestors
   of main, although the work merged under other shas. Screening by grep alone misreads the
   ticket as undelivered.

   already labelled all 17.
9. Any change to codex-review's output breaks an exact match in `script/lane-scripts_test.sh`.
   That match duplicates `codex-review_test.sh` coverage.
10. The charter's requirement-ID block 1020..1039 is four digits. `gen-spec-requirements.sh` on
    main indexes only `-[0-9]{3}` IDs, so `make spec-requirements` reported "no changes" and the new
    IDs are untraced until V1-3793 lands. ASD-V0 already uses 998, so three-digit IDs are nearly
    exhausted.

    refuses `whole-reason-missing`. The tools packages ran whole without that refusal. The rule is
    not visible from the command line.
12. `test-run-pattern` over this lane selects 88 tests in 26 packages. Most come from the `Makefile`
    base name, which many tests read, so a Makefile edit stays broad.
