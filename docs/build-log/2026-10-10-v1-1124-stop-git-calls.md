# V1-1124: consolidate enrolled Stop Git subprocesses

Date: 2026-10-10
Intent: proposed, pending owner acceptance (`LCP-V0-019`).
Base: `2145af619f68698dbb1c097369e29d589e623f7d` (`origin/main`).

## Intent and bounded implementation

Reduce redundant Git subprocesses in an enrolled Stop without changing its policy result,
error codes, private-input reads, content binding or wire format. A first full evaluation returns
an opaque observation of immutable target/tree/content. The event reuses these facts
only when its closing repository observation matches target and tree. The second evaluation reloads
all private state/artifact inputs and runs localcompletion's own Git status at both ends. A changed
ancestry is re-proved on every read; absent/mismatched facts fall back to full evaluation.
Drift-only snapshots omit `ls-tree`; snapshots consuming the content digest retain it.

Non-goals: changing gokernel's repository observations, private state formats, completion outcomes,
or installing/releasing the candidate. Rollback: revert this patch; no state migration is required.
