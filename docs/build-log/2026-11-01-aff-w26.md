## V1-4170 root cause

`script/analyzer-schema.sh` runs `heavy=${CORVINT_ANALYZER_HEAVY-script/heavy.sh}` inside a
`sh -c "$command"` string held in a variable. `script/codex-review.sh` runs
`exec ${heavy:+"$heavy" --admit-only} ...` with a `$(dirname "$0")/heavy.sh` default. The shell
plugin modelled none of the three forms, so neither script had an edge to `script/heavy.sh`
(`shell:dynamic-source`). Their tests were selected for a heavy.sh edit, but not for an
unrelated edit, although the unbounded-readers ledger records them. AFP-V0-553 adds the three
forms. Each only adds edges. Any other `$(...)` part stays a wildcard, and a subtest pins that.
