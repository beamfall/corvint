`ticket create` checks each `effects.touchPaths` entry at `origin/HEAD`, else `origin/main`. A path
absent there is refused `MALFORMED`, with nothing written, unless one of two things holds:

- the body records `Source ref: BRANCH@FULL_SHA`, which is checked at that commit when it is in
  this clone and recorded `NOT_OBSERVED` when it is not;
- `--creates-paths` is given.

`script/lane-dispatch-check.sh` names the recorded ref on an `ABSENT` finding.

- Decision (AC3, from V1-3622): the dispatch-time dependency check is `lane-dispatch-check --base`

  is not dispatched against a base that lacks the code.

  check has no structured input. A typed source-ref record field would change the store schema and
  is out of this lane's scope; the body line is the record.
