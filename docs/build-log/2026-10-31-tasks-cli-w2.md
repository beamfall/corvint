## Review fixes

The independent review found six P2s. Each was checked against the code. Each fix has a regression
test that fails when its fix is reverted (mutation run) and passes with the fix. The spec change
is in `816be0aed` and the code in `7a460cc73`.

- **Interrupted intent write blocks a retry: FIXED** (`7a460cc73`). Each intent file is written to
  a synced `.tmp-restore-` temp and then linked into place. A rerun skips such temps and sweeps them
  under the lock (TRL-V0-871). `TestTRLV0871_FailedIntentWriteLeavesARetryableRoot` fails on the old
  O_EXCL write in two ways: the partial `AT-0002.json` is left behind, and the rerun refuses
  `INTENT_DIVERGED`.
- **State publication precedes durable intent entries: FIXED** (`7a460cc73`). Every directory that
  holds or was created for an intent file is synced before the state dir is renamed.
  `TestTRLV0871_RestoreSyncsIntentDirectories` fails without that sync: `.taskman/tickets` and
  `.taskman` are never synced.
- **A duplicated member passes revalidation: FIXED** (`7a460cc73`). The staging read keeps a set of
  member names, refuses a repeat or a size other than the manifest's, and requires every member.
  `TestTRLV0871_DuplicateStagedMemberRefuses` fails on the old counter, which returned no error.
- **A reloaded dispatcher uses stale note statuses: FIXED** (`7a460cc73`). `newDispatchQueue` reads
  pools and matched statuses from the applied config at each tick (ON-V0-870).
  `TestONV0870_ReloadedConfigGovernsNoteSelection` fails with the captured statuses, because the
  COMPLETED note is missing after a reload.
- **`--root` does not govern relative input files: FIXED** (`7a460cc73`). `archive verify` and
  `archive restore`, plus the relative file flags of delivery-screen, obligations, similar,
  run-batch/qualify and external-review, now resolve through `commandPath(env.Cwd, …)` (CTS-V0-871).
  `TestCTSV0871_RootGovernsRelativeFileArguments` fails on the old code with
  `open backup.tar: no such file or directory`.
- **Restore reads existing intent files unbounded: FIXED** (`7a460cc73`). An existing intent file is
  compared by size first and is never read when the size differs. When the size matches, the
  sha256 is computed as a stream over at most size+1 bytes (TRL-V0-870).
  `TestTRLV0870_OversizedIntentFileRefusesUnread` fails on the old `os.ReadFile`, which allocated
  268469224 bytes for a 256 MiB sparse `queue.json`.
