# Citation preparation and draft blob batching

Scope: owner-requested V1-4851 and V1-4852, lane `citeperf`, base
`9761ea1f459c0d3b3c963953e24a76eaeda16370`. This is a build-only delivery;
execution, independent review, timing qualification and CEM binding belong to integration.

## Decisions and contracts

V1-4851 uses the existing public command entry in-process for `cem cite` and `cem mark`
when the selected executable and the running executable are the same file. This includes
the explicit same-binary path the shell wrapper supplies. A different or unavailable
selection retains subprocess execution. The existing flow still owns row order, private
stage/probe files, failure collection and publication. Reusing the parser and implementation
keeps authority, error text, status and JSON shapes unchanged. No public batch command or
citation-result cache is added. Contract: `DCW-V0-8760`, refining `DCW-V0-335` and
`DCW-V0-2130`. Rollback restores the runner factory's `dogfoodflow.Exec` calls.

V1-4852 extends the existing `CKC-V0-012` bounded prefetch helper to TARGET hunk blobs
and refresh-plan evidence at BASE, TARGET and an established prior BASE. These are exact
read sets already named by the patch or plan, not a recursive repository inventory.
This works on Git versions without the `%(objectmode)` atom needed by the opportunistic
reader. Claims-specific batching and fallback for unsupported literal paths remain intact.
The fallback previously ignored `cat-file` failure and could cache a present empty blob;
it now records absence, producing the existing absent-evidence reason. Batch cache
publication requires all requested records, distinct expected object IDs, blob types,
bounded sizes and LF framing. A malformed tail cannot publish a successful prefix.

## Evidence and limits

The added regressions compare multi-hunk CEM bytes and every stdout/stderr/status with the
per-hunk subprocess path, assert failed rows leave the map unchanged, and remove the
executable after selection to prove citation dispatch does not spawn it. A separate refusal
test preserves external selection. Blob regressions compare both public draft flows with
per-file reads, count two Git commands for twenty files, and cover missing/corrupt objects,
empty blobs, aliases, malformed/truncated/duplicate/unexpected batch records and no partial
publication. Existing assertions and committed goldens are unchanged.

fixture, retain host load, argv, wall time, return code and output digests. Its output must
be outside the fixture repository. No speedup or completed acceptance is claimed.
