## What changed

- AMAP-V0-881 (V1-3954):
  - Each map screen carries an optional `dialect`, set by `markDialects` from the router file that
    declared its state. The member is omitted when several dialects declared the ID.
  - `newScreenIndex` reads the ranked set from that member, and `urlMatches` ranks. The build's
    goto attribution, `findScreen`, `Observe`, the UI-record resolver and the refs and
    site-knowledge readers therefore resolve a URL alike.
  - `BuilderVersion` is now `appmap-builder/3`.
  - Older maps parse, carry no dialect and rank nothing, which is their earlier reading.
  - Not bumped: `application-map/0`, because the member is optional.
- AMAP-V0-882 (V1-3935):
  - `reactMergeAlternates` folds a resolved, unnamed, non-redirect leaf into its first
    declaration when a later route tree declares it again with the same full path and the same
    canonical `element` token text. The folded entry carries the union of both declarations'
    constraints.
  - Every `ambiguous-template` unknown now carries the detail `declared by <screen ids>`.
  - This ships under the same unreleased `appmap-builder/3`.
