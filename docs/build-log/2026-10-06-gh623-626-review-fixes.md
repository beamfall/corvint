# Review fixes for V1-0852 and V1-0855 (issues 623, 626)

Independent Codex review of `claude/gh623-626-claim-admission` (base `a5aeee41`) raised two P2
findings. Both were confirmed against the code and reproduced by a failing test before the fix.

## P2-1: health preparation implied the CAL-V0-104 cover (confirmed)

POOL_PREPARE rederived authors with the cover always on. A review claim with `--exclude-authors`
and no `--exclude-member` passed its own derivation; if another caller's unpooled claim and release
then left a member-less generation, preparation covered it and ran the health command before the
final admission refused. The store now carries the claim's explicit members into the prepare
request (allowed only together with the author mode), and preparation uses `DeriveAuthors` with
them, so the cover is never implied. `TestCALV0104_HealthPrepareNeverImpliesCover` races in the
unrecorded generation from the preparation hook: the claim refuses `INDEPENDENCE_UNVERIFIED`, no
health command runs and no pool entry is written. On the pre-fix tree the same test ran `review`'s
health command.

The prepare request preimage now includes `excludeMembers` when the claim had explicit members; a
prepare without them keeps its historical bytes. A claim retried across an upgrade under the same
request ID with explicit members would see `REQUEST_ID_CONFLICT` on its prepare child.

## P2-2: default and pooled plans read downstream competitors differently (confirmed)

`admissionQueue` evaluated a downstream competitor at its own stage but kept the caller's pool
(empty in the default plan), so the default plan counted a review ticket that had no free
review-eligible member while `--pool` and an explicit claim excluded it. Every competitor is now
read against the pool itself, at its stage, without the plan's or claim's own exclusions. For
same-stage competitors this changes no yield: a competitor without a free member implies the
claimer has none either. `TestCALV0105_DownstreamCompetitorNeedsItsStageMember` (only free member
reserved for implement, a waiting review) asserts the default plan, `--pool` plan, claimability,
claim-next and the explicit claim all admit the implement ticket; the default plan deferred it
before the fix. Dropping the claimer's `--exclude-authors` from competitor reads also removes the
earlier plan/claim divergence under that flag.

Spec: CAL-V0-098 and CAL-V0-104 (preparation cover) and CAL-V0-105 (competitor read) amended;
traceability rows list the new tests.
