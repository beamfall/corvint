# decide-1021: VS Code import command removed (V1-0438); Pi expand null-index refusal, adapter 0.3.3 (V1-2150)

Date: 2026-10-21. Lane: claude/decide-1021 (base f284484eb). Decision record:
`docs/decisions/0550-owner-delegated-1021-vscode-import-pi-expand.md` (owner delegation of
2026-10-21). `VSC-V0-079` and `AHI-071` are accepted under the owner's standing auto-accept of
2026-10-11.

## Problem

- V1-0438: the VS Code "Import Test Observation" command could only refuse with
  `UNVERIFIED_IMPORT`, because no shared go-live verifier is linked.
- V1-2150: Pi 0.99.1 runs `Value.Convert` before schema validation. That turns a null integer
  into 0, so `corvint_expand` with a null `result`/`evidence` index expanded row 0. A missing index
  failed with an untyped host error. The native `adapter pi-tool expand` already refused both cases;
  the defect was host-side coercion.

## Change

- VS Code: removed the command, its activation event, the `corvint.testObservationPath` setting and
  its restricted-configuration entry, the registration and the README text.
  `test/manifest.test.ts` pins the exact six-command manifest.
- Conformance: the exact command list was updated, `VSC-V0-079` was added to the presentation
  case, and the import vectors were kept as internal-path safety assertions.
- Pi: `tools.js` refuses a null or missing index with the typed fault `invalid-expansion-index`
  in two places, with no dispatch:
  - in `prepareArguments`, which the host runs before conversion
  - in the handler
- The adapter is now 0.3.3 everywhere 0.3.2 was pinned: the package, both compatibility
  manifests, runtime/workflow, `piAdapterVersion`, AHI-024, LCP-V0-008/009 and the PWV inventory.
  `dogfood event` admission now reads the shared constants.
- `TestPiLocalCompletionTuple` gains a negative 0.3.2 row.

## Evidence

  the 0.3.2 tuple row.
- Unit and focused runs:
  - VS Code `npm test` 90/90; lint is clean.
  - Node host-adapter suite: 122 pass, 1 skipped.
  - Go `host-adapter-test` subset (`TestPi|TestDogfoodEvent|...`) passes.
  - `protocol/integrations`, `tools/capabilities-check` and `conformance/harness-event-v0` pass.
- Real Pi 0.99.1 validator: null and missing indexes are refused with the typed text, and a
  valid index passes.
- Live host (macOS, `CORVINT_PI_HOST_BIN` set, candidate binary at 0.3.3):
  - Pass: the `host.test.mjs` lifecycle/tool-flow tests, workflow-host 1/1, tasks-host 3 pass
    (1 skipped) and cockpit-host 3/3.
  - Pre-existing failures, also on an origin/main baseline build: `host.test.mjs` tests 6/7 (the
    native lease's `observedAt` drift against the installed corvint-tasks) and core-host
    PWV-V0-012 (affected test selection returns undefined).
- Qualification stays FALLBACK; this run does not upgrade it.

Revert the change. The Pi package and the Corvint binary must be rolled back as a pair, because
0.3.2 and 0.3.3 refuse each other.
