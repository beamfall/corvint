## Independent review (Codex, one round) and fixes

- **P1 fixed: a failed `git diff` read as FRESH** (`script/lane-binary-check.sh`). When the
  binary's commit object exists but its tree does not (for example an offline partial clone),
  `cat-file -e` succeeds and the diff fails with no output, which the old code took as "no Go
  source differs". The diff's exit status is now checked and a failure prints `UNVERIFIED ... git
  diff from commit C failed in DIR` (exit 1). Regression: the lane-binary group copies the fixture
  repository, deletes the first commit's loose root tree, and expects `UNVERIFIED`.
- **P2 fixed: a commit-only `--version` line was rejected.** A plain `go build` or `go install`
  prints `Corvint V (commit SHA)` without a build number (`versionline.Format`, CRB-V0-003). The
  commit member is now read on its own and the installed build is named `unstamped build`. A
  `, modified` build still states no clean commit and stays `UNVERIFIED`. Both lines are covered by
  the lane-binary group. The text line is kept rather than `--version --json`: the check stays a
  dependency-free shell read of the documented line, and the fakes in the test print that line.
- **P2 fixed: `jobs` was dropped by `--summarize`** (`tools/retrieval-bench/stats.go`).
  `storedReport` now reads `jobs`, where a report without it ran serially (1). `resummarize` refuses
  to merge reports run under different `jobs`, because their wall times measured different host
  loads, and writes `jobs` into the merged report. Covered by
  `TestCEPV0756SummarizeKeepsJobsAndRefusesMixedJobs`. CEP-V0-756 now states this.
