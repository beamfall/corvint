# fric-a lane, speed wave sp1 (2026-10-31)

Lane fric-a on the WSL host, base `origin/main` `8daec98ce4349c1583186692726d2c3a782ac647`,
branch `claude/lane-fric-a-1101`. Twelve friction tickets in priority order. Each delivered fix has

## Decisions

- **V1-3635 (`CAL-V0-227`).** Confirmed with a failing test: the standalone `work-state-reader`
  (a direct `ReadStates` caller) lifted its quarantine by the reboot proof and wrote the
  `HOST_REBOOT` record, but emitted no `reader-recovered` event. That reader has its own program
  directory, which no dispatch start ever opens, so refusing the proof there would leave it
  quarantined until an operator recovery. Instead it now appends the same event to its own event
  log, numbered after the log's last event, because it keeps no ledger. An unwritable event
  refuses the read. This is the smallest change in `internal/tasks/dispatch`, which another lane
  owns: one function and one call site.
- **V1-3636 (`PWP-V0-960`).** Confirmed with a reporter fixture: a `test.fail()` attempt was
  recorded by its raw status. The reporter now follows Playwright's outcome: a failed attempt of
  an expected-failure test is `passed` with no message, and a passing one is `failed` with a named
  message. It adds no new state and no report member, so the Go decoder's closed shape is unchanged.
- **V1-3637 (`DCW-V0-990`; `DCW-V0-960..967` were already used on main).** Plan rows accept
  `bytes:START:END` in `dogfood change`, `inputs-check` and `finish-lane`, which now use the
  same grammar as `dogfood-bind-range.sh`. Every `cem cite` call, probe and pre-check goes through
  `citeSpanArgs`. The recite check compares a byte row with the map's recorded span directly. The
  uniform-plan check keeps byte and line spans distinct. Known gap: a line span and a byte span
  naming the same BASE bytes are not joined by that check. The new fixture CEM cites lines 1:2,
  which are bytes 0:8, and the test fails on BASE. The change touched no dogfood script.
- **V1-3642 (`DCW-V0-991`).** `DCW-V0-801` refused character classes on purpose. The class is now
  admitted instead, because a quoted `[45]` is literal to the shell, the word is recorded as one
  argv argument, and lanes select related tests with it. Only classes of name characters are
  admitted; negated and empty classes are not. Every other quoted `-run` word stays refused, and
  `finish-lane` and `inputs-check` add a `refused:` line naming its first unadmitted character and
  byte offset, or its shape. Five existing fixtures used a class as their "still refused"
  example; they now use `.*`. That includes `script/dogfood-change_test.sh`, which another lane
  owns: its two fixture strings and the pinned V1-3637 plan-row hint are the only edits there. The
  `dogfood change` local-outcome hint now names the admitted bracket-class form.
- **V1-3648 (`AFP-V0-990`; `AFP-V0-960/961` were already used).** Several `--path` values were
  already accepted, so the new `--by-path` flag writes a separate `affected-by-path/1` document
  and leaves the frozen `affected-plan/1` wire unchanged. The shared set is the units that every
  path selects and that at least one selects as UNBOUNDED_READER. The first attempt used the union
  plan's single witness, which hid units that are unbounded through one path and literal through
  another. Latency on this host does not reproduce the ticket's 10-40 s: two cold single-path
  calls took 4.67 s and 3.78 s, and one `--by-path` call takes 2.08 s cached or 6.45 s cold. The
  output is 13 KB instead of 27 KB of overlapping text. Measurements are in the spec.
- **V1-3655 (`TSA-V0-960`).** An empty setup universe returns mode `none` with reason `no-setups`.
  It keeps only the input reasons (`missing-path`, `empty-spec-list`), because no unclosed import
  can widen an empty universe.
- **V1-3662 (`PMR-V0-960`).** Nothing in the repository derives workflow IDs from free text. The
  ID producers are scripts, so the shared helper is `postmergeworkflow.EncodeID`/`DecodeID`, and
  scripts call it through `corvint-postmerge-workflow encode-id VALUE`. The encoding turns every
  byte outside `[A-Za-z0-9._-]` into `:` plus two uppercase hex digits, so `claude/lane-a` becomes
  `claude:2Flane-a`. The round trip is exact, because the decoder refuses any escape the encoder
  would not write.
- **V1-3663 (`GPK-V0-960`).** The query receipt is frozen by the core-freeze fixtures, so the field
  is labelled in `corvint query --help` ("Receipt fields") rather than renamed or given a
  `revision_kind`. The help test pins the label.
- **V1-3664 (`AFP-V0-991`).** The replay is a Go tool, `tools/tiers-replay`, because a shell tool
  would need gate registration. It runs this checkout's `tiers.sh` with `GIT_DIR` set and its
  working directory in a `git archive` export of each merge, which needs no worktree and leaves no
  repository state. The retained run `benchmarks/results/tiers-replay-2026-10-31.jsonl` covers the
  20 merges ending at `8daec98ce`: 16 FULL and 4 NARROWED, in 60 s.

## Friction

   neither origin/main nor this host.
