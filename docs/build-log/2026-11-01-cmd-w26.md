## Friction

1. Inline heredocs and python inside `ssh host '...'` break under local zsh quoting (`unmatched "`).
   Expected: a simple way to run a multi-line edit remotely. Actual: every edit needed an scp'd script.
2. heavy.sh load queueing: waits of up to 120 s before 5-10 s tests while the box was loaded.
3. `git log --all --grep <ticket>` on the fresh snapshot finds only old-lineage commits, so it misleads
   "already delivered" checks; content at BASE is the only proof.
4. Stale `t-*.json` files from another lane sat in the shared scratchpad.
5. WSL `/tmp` reached 0 GB free; heavy.sh only warned and the next build failed.
6. Real Playwright 1.63 traces did not carry the fields the appmap reader assumed (snapshot in the
   after record's `result.snapshot`; `action` phase) (fixed, OUE-V0-685).
7. Playwright 1.63 asks for chromium revision 1243; WSL has only 1228, so the run needed an explicit
   `executablePath`.
8. `script/gen-spec-requirements.sh` treats an evidence line `- \`ID\`: ...` as a second definition;
   the line had to be reworded to `- For ID, ...`.
9. `corvint context` prints the tree id as `revision` beside `commit` (the V1-2190 confusion).
10. `corvint-tasks ticket show` returns `items[0].record` with `ticketId`, not `id`; `operatorNote`
    holds only a digest and needs `ticket note show`.
11. `plan preview` gives no human-readable explanation of `DEVELOPMENT_MODE` (V1-3535 AC2 remainder).
12. V1-2740's baseline timings are stale against current runs (2 s against 200 s), so its list misleads.
13. heavy.sh refuses `-run "."` and `-run "^Test"` as whole-package runs; a lane must build a
    selection manifest first even for a package it owns outright.
14. `corvint affected` / `corvint test --dry-run` select 218 packages for this small diff because
    reader attribution fans out from `cmd/corvint` test files to every tools/ reader.
