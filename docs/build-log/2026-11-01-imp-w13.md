- V1-3873 (GPK-V0-880): the `unsupported-impact-path-suffix` refusal now also names the fix
  `affected.use-path` (new `docs/specs/FIX-REGISTRY.tsv` row). A directory or a `Makefile` cannot be

  `corvint impact --capabilities` listing (`reverseImports`: depth 1, Ruby autoload advisory
  depth 2, not a closed test selection, transitive selection via `corvint affected --path`) and in

  receipt and the register for a constant fact. Recorded as the amendment's divergence decision.
- V1-3882 (ASD-V0-880): new doc gate `make go-version-pins-check` (in `DOC_GATE_TARGETS`). It
  compares the `go env GOVERSION` checks in `AGENTS.md`, `README.md`, the `Makefile` and
  `.github/workflows/*.yml` with the `go.mod` toolchain pin, and fails on drift (including a
  `toolchain` line that differs from the `go` directive). `AGENTS.md` is a project-owned contract;
  it already pins go1.27.3 on the base, so the lane reads it and does not edit it.
- V1-2718 (spike): recommendation is to keep `corvint.impact` single-root. MMR-V0-005 and
  MMR-V0-007 bind each MCP call to the repository its alias names, and the two-root non-goal is
  already recorded in `application-navigation-ledger-v0.md` (ANL-V0-064..067 follow-up). A cross-root
  MCP tool needs an owner amendment of MMR-V0; the CLI `corvint impact --app-root DIR --test-root
  ALIAS=ROOT` already answers the question. The small in-scope part, a pointer in
  `docs/MCP-SERVER.md`, is delivered. The owner decision on amending MMR-V0 stays open.

## Friction

1. The installed plugin cache (0.3.6) still runs the old `corvint-mcp`; many sessions show
   CONNECTION_CLOSED, and its stderr says only `repository unavailable`. Repro: start Claude Code
   on the Mac with the corvint plugin; the MCP server fails to connect.
2. V1-3880's premise was wrong: the snapshot is keyed per tree and engine, so every lane commit or
   rebuilt binary misses once. Repro: commit, then `corvint impact PATH` prints the miss notice.
3. The charter's `mkdir -p` cache directories are 0775 under the WSL umask 0002, which triggers
   V1-3874's refusal until `chmod 700` is run.
4. The Mac primary checkout's `AGENTS.md` still says go1.27.2 (stale primary `main`).
5. Many lane tickets were already delivered on `claude/batch-1101b` or `main`; screening took a
   large share of the lane budget.
6. `pi mcp add` writes global config, so the Pi receipt needed a scratch HOME.
7. `make spec-requirements` refuses a requirement defined outside `## Requirements`, so an
   amendment's narrative and its requirement bullets must live in two places.
8. `corvint affected --path` refuses any dirty worktree (`unsupported-affected-mixed-worktree`), so
   the new `affected.use-path` fix is usable only after a commit.
9. `corvint affected` prints DEGRADED `self-binary-stale` after every lane commit; expected but noisy.
10. A new repository-root read in a test (`go_version_pins_test.go` globbing `.github/workflows/`)
    passes its own tests but fails only at `make test-read-scopes-check`; the scope had to be added to
    `.corvint/test-read-scopes.json` at the end. Repro: add a `filepath.Join("..", "..", ...)` read of a
    new root path to a tools test and run the gate.
11. Two added lines in `docs/MCP-SERVER.md` moved three `docs/GLOSSARY.md` line citations; fixed with
    `script/check-line-citations.sh --repin`. Any doc insertion above a cited line costs a repin.
