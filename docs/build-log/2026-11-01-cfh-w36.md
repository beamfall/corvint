## Friction

1. **The ticket text under-described the schema gap.** V1-2521 and the `CEM-V1-084` traceability row
   named only `axes.authentication` and the four issue codes; the receipt echo and both artifact
   `kind` enums also refused the case. Expected: the row names every node the public case's results
   need. Actual: found by the validation test after the first two runs. Suggest the regen tool's
   `--check` (or a gate) validate every public-case `EXPECTED.json` result against the schema, so a
   gap is a failing check and not a reviewer note (confirmed, this lane, head `266bf5fcb`).
2. **`cem-stable-regen` default `--date` is `2026-11-02`** while this lane ran on 2026-11-01; the
   `CHANGES.md` sections carry that date. Expected: today's date. Actual: a hard-coded default.
   Harmless here (the decision file is dated 2026-11-02 by charter) but worth a `date -I` default
   (confirmed, `tools/cem-stable-regen/main.go`).
3. **V1-3188 seam (as asked by the charter).** A lane cannot compose a qualification of the closeout
   coordinator through its public entry points, because every entry point that exercises the
   interesting stages (`finish-lane`, `dogfood-closeout`, `dogfood-seal`) seals, and the charter
   forbids a lane to seal. A disposable-worktree harness that the orchestrator runs (interruption,
   citation correction, changed source, pure seal) is the missing seam; `script/dogfood-finish.sh`
   has no dry-run that stops before the bind commit. Expected: a non-sealing rehearsal mode. Actual:
   none (suspected design gap, not measured).
4. **`corvint-tasks ticket show` is unavailable on this host** for the four tickets (the host store
   lacks them; the orchestrator pasted the records). Same as V1-3262.
5. **`corvint affected` is `UNKNOWN` for a docs-plus-packet change**: a new decision file and the
   `REQUIREMENTS.tsv` regeneration fan out to 124 packages through `PATH_LITERAL_READER` and
   `UNBOUNDED_READER` rows (`internal/contextindex` 181 tests via `docs/decisions/README.md`), so
   the selection cannot steer a lane; `corvint test --dry-run` then plans 252 packages whole.
   Expected: a bounded selection for a decision-file add. Actual: `UNKNOWN`, `LANGUAGE_FRONTIER=87`,
   `UNOWNED_DIRTY_PATH=17` (confirmed, this lane).
6. **`corvint test --dry-run` reports `DEGRADED self-binary-stale`** after any Go edit until the lane
   rebuilds `corvint`; the message is clear, but a lane that must not install binaries system-wide
   needs a per-worktree rebuild hint (`make dogfood-build-corvint`?) in the line (minor).
