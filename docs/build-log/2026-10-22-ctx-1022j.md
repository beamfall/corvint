## Decisions

- V1-0319: `tools/cw-trial` gained a `gate` command (`CWT-V0-015`). It reads a frozen gate file
  (`corvint-cw-trial-gate/0`), rebuilds the report's derived metrics from its raw fields, and writes
  a canonical `corvint-cw-trial-gate-verdict/0`. Exit codes are 0 `ADMIT`, 1 `REFUSE` and 2 input
  error. There are three kinds of rule:
  - identity: the set digest, every task once in both arms, complete and non-pilot, the same access
    and limit, and an observed Corvint binary;
  - treatment-context failures;
  - one paired rule per metric. A failed arm counts as a miss.
- The lane chose the threshold for the gate. It is model-free: `corvint` against `grep`,
  `packet_top_10` and `gold_as_result`, margin 0 (non-inferior or better), and at most 5 failed
  `corvint` packets. The gate file was frozen and committed (6cd5c7896) before any run of the set,
  with sha256 `46b86180…`.
- The orientation run uses `abstain-agent.sh`, so it reads retrieval only. It is not the agent-claims
  bet, which stays blocked on the owner questions in the set's README.
- Routing changed only after `ADMIT` (`CWT-V0-017`):
  - Both shipped skills prefer `corvint context --task "TASK" --limit 20` for ticket-to-change
    orientation and keep `query` for symbol and claim lookups. They say that a `READY` packet can
    still miss the gold.
  - `docs/DOGFOOD.md` step 1 and the section 1 block retain `prechange-context.json`.
    `dogfood change` still reads only the query and impact receipts.
  - Claude Code moved to 0.3.5 and Codex to 0.2.9.
- V1-2351: the memo is asserted by its derivation counter: one derivation across the indexed loop,
  and `Load == "reused"` with zero freshness time on the batch path. No wall clock is involved.
- V1-2311: a `requirement-definitions-test` make target was added to `GATE_STEPS`.
- V1-2298: added `TestAFPV0184UnresolvedRelativeImportRaisesItsFrontier`, which covers a missing
  module in a namespace package and a climb above the root. Under a regular package, `.missing`
  resolves to the package by the longest prefix, which is correct.
  - Added `TestAFPV0185UnreadableSourceRaisesItsFrontier`, which covers a file over `MaxSourceBytes`.
  - `AFP-V0-186` now measures the tracked fixture `internal/liveverify/affected/testdata/python-corpus`
    (10 modules, 21 tests). Editing `src/corpus/index.py` selects exactly 8 of the 21 tests.
- V1-0679: `PWP-V1-009` documents the exclusion. The supported closure is the single executable, and
  a relocation-dependent launcher fails closed as `application-attestation-provider-unavailable` with
  no observation. Corvint does not copy host libraries.
  - `TestApplicationAttestationRelocatedLauncherFailsClosed` reproduces the case portably with a
    shell launcher that execs a sibling.
