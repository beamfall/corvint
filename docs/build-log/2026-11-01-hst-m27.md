## Friction

Each item is repro → expected → actual.

1. `corvint-tasks ticket show` → the record at top level → it is nested under `items[0].record`.
2. The rm safety check fired on a command containing no `rm` → no prompt → refused.
3. Mac PATH `corvint` is 410 commits behind BASE → current → stale build 40.
4. Plugin pre-tool and SessionStart outputs omit `hookEventName` → present per the host schema →
   absent, though the host accepted them.
5. The orchestrator session reports `plugin:corvint:corvint` CONNECTION_CLOSED with no mcp-logs →
   a named cause → its project directory is missing (inference above).
6. AGENTS.md pins go1.27.2 while `make windows-vet` and the tree require go1.27.3 → one version →
   two.
7. The ledger silently refused opt-in event rows → recorded → dropped (fixed, AHI-630).
8. The AHI-806 spec said no named-path affected mode exists → `affected --path` exists → spec was
   wrong (fixed).
9. `corvint affected --path` in a dirty tree → plans → refuses without `--worktree`.
10. macOS tar to WSL with `COPYFILE_DISABLE=1` → silent → `LIBARCHIVE.xattr` warnings.
11. Mac load stayed at 35-131 throughout the lane, and live timings carry it.
12. heavy.sh refuses whole-package runs without `-run`. On WSL with no config it runs locally and
    says so.
13. The heavy.sh host line with `HEAVY_REMOTE_HOSTS` named a host the probe did not try first
    (fixed, V1-3518).
14. `pi` is not on the WSL PATH → installed → borrowed `~/.cache/mcp-w10` from another lane.
15. OpenCode is absent on WSL and Unraid → a lane host has it → only the Mac does.
16. The OpenTUI 0.7 `SyntaxStyle` owner requirement broke the Corvint TUI plugin silently. Only the
    host log named it, and the AHI-620 cause showed the stock panel (fixed, AHI-633).
17. Plan-affected degrades to the deadline at load ≥50 under the 2 s opt-in host kill.
18. Nested heredocs through ssh under zsh break quoting, so scripts must be sent as files.
19. `make spec-requirements` refuses unstaged specs, and `spec-requirements-check` fails (rc=2)
    until the regenerated TSV is staged.
20. WSL `tail -5` is refused (uutils), so `tail -n 5` is needed.
21. `codex mcp list` shows `Auth Unsupported` for a stdio server, which reads like an error.
22. `date +%s%3N` over ssh from zsh gives garbage, so timing needs python.
23. `ugrep` hits a regex complexity limit on the OpenCode binary, so python was used to search it.
24. `qualify-opencode` `sourceCommit` reports BASE for a dirty `--source` tree. `sourceSHA256`
    carries the real bytes, but the commit field alone misleads.
25. Self-observation ledger rows carry no count, target or session. A count-based criterion such
    as V1-3728 AC2 can only be shown by replay into an emptied ledger, and a live row's source
    cannot be told apart.
26. Android: `emulator-5562` stays `offline` and no emulator binary is on PATH, so a live APK
    witness needs an owner-started device.
27. Line moves in `bridge.go`, `observations.go`, `heavy.sh` and `host_adapter_pretool.go` broke
    23 line citations across six documents. `make line-citations-check` is not on the charter's
    pre-commit list, so it surfaced only at closeout, and `--repin` fixed it. Expected: the lane
    checklist names it. Actual: it is found late.
