## Friction

- In a fresh worktree, `query` and `impact` rebuild the index on every call until
  `index --if-stale` runs (V1-4012).
- `heavy.sh` refuses a whole-package run of one non-tools package without `HEAVY_WHOLE_REASON`,
  which forces the manifest flow for a single-package check.
- The unraid host has no `/usr/bin/time`.
- Charter command examples fail under zsh.
- V1-3780 names the wrong registry path.
- An edit that moves cited lines (`help.go`, `select.go`) fails `line-citations-check` in
  unrelated specs until a repin.
