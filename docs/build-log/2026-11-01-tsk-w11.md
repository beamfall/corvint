## Friction

- The lane tickets file `~/lanes/tickets-tsk-w11.json` holds concatenated JSON objects, so
  `json.load` fails. Repro: `python3 -c 'import json;json.load(open("tickets-tsk-w11.json"))'`
  raises `Extra data`. Reading it needs `JSONDecoder.raw_decode` in a loop.
- Nested quoting through `ssh wsl-lanes '...'` breaks on any single quote in a heredoc. Repro: a
  Python heredoc containing `'` inside `ssh wsl-lanes '... <<EOF ... EOF'` fails with zsh parse
  errors. Workaround: write scripts locally and `scp` them to the host.
- V1-3713 was reassigned although `claude/lane-tasksaudit-w8` had already delivered it on a lane
  no batch took. That lane's TCD-V0-955 also collides with V1-3607's TCD-V0-955 on
  `origin/claude/batch-1101a`. Repro: `git grep -n "TCD-V0-955" origin/claude/batch-1101a --
  docs/specs` against `git show 658fdcc22`.
- `claude/batch-1101b` exists only in the Mac clone, not on origin or WSL, so a WSL lane cannot
  verify that V1-3565 and V1-3566 were delivered. Repro: on wsl-lanes, `git -C ~/projects/corvint
  rev-parse claude/batch-1101b` fails.
- `gate run`'s `reusedFrom` names only the source result and attempt, not the source tree or
  that the reuse was a TCD-V0-151 descendant reuse. Readers took a correct descendant reuse for a
  cross-tree defect (V1-3826). Repro: a reusable gate PASS on a main commit, then `gate run` for
  an attempt whose candidate is an ancestor tree. The result's `reusedFrom` lacks
  `tree`/`descendant`.
- The corvint MCP server failed to connect in this session (`CONNECTION_CLOSED`), so context
  reads used the CLI.
- `ScanLaneCommits` takes only a full OID, so a revision such as `HEAD^1` refuses `MALFORMED`.
  It is called with the batch's recorded merge OID only, so this was fine; the test resolves the
  revision first.
