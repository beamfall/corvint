## Independent review

One Codex round (read-only, diff `c77d35c6..f06d2aa76`). It re-checked all 170 manifest entries
and the 28 recorded value changes and found them consistent. One finding, medium, recorded and not
fixed in this change:

- `tools/cem-stable-regen/replace.go` refuses `no case value changes; nothing to re-emit` before it
  reads `--cell-values`, so a correction that changes only cells no case matches (such as the
  `-sha256` forms) cannot be re-emitted. The refusal fails closed and this re-emission changes
  cases, so it is not affected. Accepting a cell-only re-emission needs the no-change check moved
  after cell processing, the case file and its `predecessorSHA256` left byte-identical when no case
  changes, and a passing cell-only test. Filed as a residual.
