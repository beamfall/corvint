## Decision and scope

The lane request supplies human intent: report sustained row absence while preserving CIN-V0-001
producer-epoch isolation. CI Narrowing V0 owns this surface and had 12 obligations before this
change (15 afterward), below the 256-obligation cap. CIN-V0-2140..2142 use only the assigned numeric
block and record standing acceptance, not owner read-back. Existing CIN-V0-861 remains the
experimental marker proposal; its unimplemented marker producer cannot detect an actual outage.

The standalone developer alarm reads completed same-repository main-based PR CI runs, outcome
artifacts and immutable tested workflow bytes, then checks trusted forward rows. It includes
narrowed PRs: that is the critical outage scenario. It needs no selection document. Three absent
runs among the bounded latest-20 eligible window cause JSON TRIPPED, a GitHub error annotation and
exit 1. Unknown evidence exits 2 with an annotation. Epoch-1 outcomes point to epoch-1 workflow
bytes and never count as epoch-2 absence. The bar and narrowing authority are unchanged.

The existing row wire has no attempt field. Claiming exact rerun-attempt coverage from a row name
or timestamp would invent a binding; eligible current-epoch reruns instead report UNKNOWN. Row
bodies bind run IDs so a delayed row from another run cannot mask absence. The run sample is the
API's latest 100 created completed PR runs, reordered by completion inside that sample; it cannot
claim globally latest completion order. Queue, push and fork runs are excluded. Outcome-artifact
loss is outside the positive eligibility proof. No hosted coverage is claimed.

addressed with executable regressions. The reviewer also required explicit bounded-sample semantics
and canonical UNKNOWN on malformed documents. Final review outcome is recorded in the handback.
