# Lane lnt-u32: lane-host tooling and hygiene

Lane `lnt-u32` on the Unraid host, branch `claude/lane-lnt-u32-1101` from `origin/main`
`35475f860d97bfde9bbaa6cccf1f2ba8f78ea44b`. Requirement IDs come from the lane block 765-774:
ASD-V0-765..773 in `docs/specs/corvint-self-development-v0.md`. ASD-V0-774 is unused.

## Problem

Lane hosts were found unfit only after a lane had started. The gaps were:

- missing toolchains, ssh identities and adopter checkouts
- a hand-written `~/lanes/heavy.sh`
- slow `git log --all -S` searches
- a scratch directory shared between lanes
- ssh heredoc quoting that broke on an apostrophe
- in-flight lane branches that remote hosts could not see
- worktrees cut from the host's HEAD instead of the lane base
- friction filed for capabilities that `docs/CAPABILITIES.md` already listed

## Decisions

- **V1-4056 (ASD-V0-765)**: `script/lane-scratch.sh` prints `ROOT/LANE`, created with mode 0700. A `.lane` marker records the lane and the worktree. A directory owned by another lane, or by another worktree, is refused with exit 2.
- **V1-4057 (ASD-V0-766)**: `script/lane-host-heavy.sh` is the tracked source of `~/lanes/heavy.sh`.
  - Its own `git rev-parse` runs with `GIT_CONFIG_GLOBAL` unset.
  - It delegates only to a `script/heavy.sh` that answers `--print-lock-dir`. Otherwise it refuses with `REFUSED no-delegate` (exit 2).
  - Installing it on each host is an owner step: `install -m 0755 script/lane-host-heavy.sh ~/lanes/heavy.sh`.
- **ASD-V0-767**: `script/lane-host-check.sh` serves V1-3653 AC1, V1-3785, V1-3953 and V1-4102.
  - It prints one `OK`, `MISSING`, `DRIFT` or `WARN` line per check, covering the toolchain, wrapper, ssh identity and peers, adopter, and repository hygiene.
  - Each finding names the owner step that fixes it. The script never installs, repacks or creates keys.
- **V1-3834 (ASD-V0-768)**: `git diff | script/lane-remote-edit.sh [--check] HOST WORKTREE` applies a patch read from stdin in a remote worktree. It needs no perl and no nested quoting. This lane used it for every edit to the Unraid worktree.
- **V1-3868 (ASD-V0-769)**: `script/ssh-heredoc-check.sh` scans a command with quote awareness.
  - A `<<` inside a quoted `ssh` argument is refused (exit 2), and the refusal names `ssh HOST 'bash -s' <<'EOF'`.
  - It also reads hook JSON on stdin.
  - Fork: wiring it into the lane hook is **blocked: owner/orchestrator**, because the charter forbids lanes to edit hooks.
- **V1-3867 (ASD-V0-770)**: `script/lane-inflight-branches.sh publish|check` pushes lane heads to `refs/remotes/inflight/*` on a host without force, and reports `VISIBLE` or `MISSING`. Running `publish` at dispatch is an orchestrator step, documented in LANE-ORCHESTRATION section 14.
- **V1-3697 (ASD-V0-771)**: `script/capability-screen.sh 'TEXT'` matches the friction text against the CAPABILITIES rows. The V1-3649 text gives `MATCH 115: corvint test flags=--dry-run row-flags=--dry-run,--summary,--go-parallel,--base`.
  - The intake step is documented in section 12.
  - Fork: deduplication inside `corvint-tasks ticket create` belongs to lane tcl-w31 and is not duplicated here.
- **V1-3061 (ASD-V0-772)**: `script/lane-base-check.sh` refuses any of these:
  - the shared checkout
  - a detached HEAD
  - a branch whose first reflog entry was not cut from the base
  - a base that is not an ancestor of the branch
- **V1-3653 AC2 (ASD-V0-773)**: `integrations/host-adapters.test.mjs` handles a missing `CORVINT_TEST_NATIVE_FIXTURE` or `CORVINT_TEST_REAL_BINARY` itself.
  - It builds `./integrations/testfixture` and `./cmd/corvint` into a temporary directory and removes that directory afterwards.
  - Before this change, the tests skipped on every lane host.
- **V1-4102**: section 12 now carries pickaxe screening guidance: search `origin/main` first, then name specific in-flight branches. Repository maintenance on the hosts is **blocked: owner**. Measurements are in the evidence section.
- **V1-4067**: refuted by test. The HOST_REBOOT proof is applied only with evidence. Evidence is below.
- **V1-3692**: already delivered at `9565779dd`. It was re-qualified live on both hosts.
- **V1-2862**: the Mac cutover is already live: the Mac `heavy.env` sets `HEAVY_REMOTE_HOST=wsl-lanes`.
  - Fork: AC3 asks for an offloaded `-coverprofile` copy-back. `-coverprofile` is a `writes_flag` that always runs locally by design, so that AC cannot be met as written.
  - The copy-back was qualified with a golden `-update` instead.
- **V1-2901**: superseded. CI has run on GitHub-hosted runners since 2026-10-30 (`CORVINT_SELF_HOSTED=off`), so the 7-day window has no self-hosted runs to compare. The routing decision stays **blocked: owner**.
- **V1-3785**: **blocked: owner**. The step is authorizing Unraid's key on WSL and adding WSL's host key to Unraid's `known_hosts`.
- **V1-3953**: **blocked: owner**. The step is choosing the VanillaTwisted location and pinned revision, then cloning it on each host. `lane-host-check` reports it as `MISSING adopter`.
- **Makefile `lane-scripts-test`**: it gains `@script/lane-host-tools_test.sh`. Lane scr-u30 also edits this target, so the batch merge needs to resolve both additions.

## Friction

1. A long ssh test run was auto-backgrounded by the session harness after about 180 s.
   - Repro: `ssh unraid-lanes '... script/heavy.sh bash script/batch-precheck_test.sh'` while host load was 28.
   - Expected: the run stays in the foreground until the Bash timeout.
   - Actual: it moved to the background, and its output had to be read from the task file.
2. The corvint MCP plugin did not connect.
   - Repro: lane session start.
   - Expected: the corvint MCP tools are available.
   - Actual: `plugin:corvint:corvint (CONNECTION_CLOSED)`. The CLI was used instead.
3. The ticket list has no per-ticket gap text.
   - Repro: read `tickets-lnt-u32.txt`.
   - Expected: each ticket carries the gap the charter promises.
   - Actual: only truncated titles. Each ticket had to be read in full.
4. The lane charter says Unraid has no gh, but the binary is present.
   - Repro: `command -v gh` on Unraid.
   - Expected: the charter matches LANE-ORCHESTRATION section 14, which says Unraid has gh with no login and WSL has no gh at all.
   - Actual: `/usr/bin/gh` exists. `lane-host-check` checks only that the binary is present, so it reports OK and cannot see the missing login.
5. `make shell-foreign-callers-check` gives no reason when it refuses.
   - Repro: write a declaration reason over 512 bytes.
   - Expected: the refusal names the 512-byte limit.
   - Actual: only "the shell plugin refused".
6. `flow-guide-check` misparses a refusal message.
   - Repro: put `$(sed ... <<< "$have")` inside a `refuse "..."` message.
   - Expected: the recovery word after it is found.
   - Actual: "names no recovery".
7. `corvint affected` cannot narrow on Unraid.
   - Repro: `corvint affected --base 35475f860` on Unraid.
   - Expected: a narrowed selection.
   - Actual: `DEGRADED self-binary-stale` (build 40 at `6d4713fb8`), and the scope is UNKNOWN with 86 `LANGUAGE_FRONTIER` unknowns.
8. Unraid cannot reach WSL over ssh.
   - Repro: `ssh -o BatchMode=yes wsl-lanes true` from Unraid.
   - Expected: rc 0.
   - Actual: the alias does not resolve, and the direct address fails host-key verification with rc 255.
9. Unraid has no `bc`.
   - Repro: `bc` in a timing script.
   - Expected: available as on the Mac.
   - Actual: command not found. Used `$EPOCHREALTIME` with awk instead.
10. V1-2862 AC3 cannot be met.
    - Repro: `script/heavy.sh go test -coverprofile=...` with an offload host set.
    - Expected: the run offloads and the profile is copied back.
    - Actual: `-coverprofile` is a `writes_flag`, so the run always stays local. The AC needs rewording.
11. Both lane hosts carry a hand-made `~/lanes/heavy.sh` that drifts from the repository.
    - Repro: `script/lane-host-check.sh --only wrapper`.
    - Expected: OK.
    - Actual: DRIFT on both hosts.

## Rollback

Revert the lane commits. Every new script stands alone, and only the docs, the spec rows, the
Makefile target line and the shell-foreign-callers entry refer to them.
