## Decisions

- `CEM-V1-710` amends the `CEM-V1-322` guidance. The rule and the nearest stable spans stay. The
  refusal now adds which bound is unstable and, when an unedited run sits inside the span, the
  longest such run that cites as stated. That inner run is classified with the same
  `verify.ClassifySpan` test, and cut to the span byte bound.
- `DCW-V0-710` changes the bind's behaviour for the four plan-row codes. These are
  `cite-span-not-stable`, `cite-self-modified-authority`, `missing-evidence` and
  `invalid-arguments`. For these codes the bind cites on, then fails once, listing at most 32 rows.
  Any other refusal still fails at its row. The bind is still all-or-nothing: no partial binding is
  published.
- `DCW-V0-711` puts the intents draft in `propose-citations` and not in a new verb. The draft uses
  the same derivation inputs-check runs (`lrfrepo.DeriveIntentAt`), so a drafted manifest cannot be
  refused `intent-invalid`. A repin-only spec edit is left out, because it declares no intent
  (`DCW-V0-548`). The draft does not choose among more than 16 specs, and it does not check the
  aggregate obligation bound. inputs-check still refuses both by name.
