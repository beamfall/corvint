# go1.27.3 becomes the sole Go toolchain pin

Date: 2026-10-24. Decision 0557, which partially supersedes decisions 0522 and 0547 for the pin.
Authority: the owner's request in chat, "can we make sure thing are using go1.27.3 so things are
always valid". Base `origin/main` 73f0af89b6a53bcabb82d1fadc3dc83bdaa71592.

## What changed

Before this change, go1.27.3 was admitted only for local checks (0547). CI, the release scripts,
the release identity, the go-live-test provider tuple and `tools/**` still asserted go1.27.2.
Now every place that asserts or installs a toolchain names exactly go1.27.3. The Makefile
`go-version` target keeps no go1.27.2 transition revision.

Changed files by category (92 files):

| Category | Files |
|---|---|
| Module directives (`go.mod`, `tools/local-authority/go.mod`) | 2 |
| Makefile, `AGENTS.md`, README and operator docs (runbook, MCP server, release notes, example/integration/tool READMEs) | 12 |
| `.github/workflows` (6) and `.github/cishards` (2) | 8 |
| Post-merge host templates under `protocol/postmerge-host/github-actions` and their audit test (generator templates, not sealed packets) | 3 |
| Release scripts and identity (`script/public-release-check`, `script/corvint-companion-release-gate`, `cmd/corvint-public-release-check`, `conformance/release-artifact-v0`, `internal/companionrelease`, `internal/releasecandidate`, the evidence-provider authoring proof) | 26 |
| Go-live provider tuple (`internal/liveverify/provider`, `conformance/go-live-test-v0`, the `cmd/corvint-go-test-provider` fixture without the 0547 module-cache fallback) | 4 |

The goldens were regenerated with their documented switches: `CORVINT_UPDATE_GOLDEN=1` for
`TestCoreVerbsEmitTheFrozenProfiles`, and `UPDATE_CEM_GOLDENS=1` for
`TestCEMEndToEndAndGoldenEnvelope`. Only the `goVersion` field changed. The analyzer schema
stays `corvint-analyzer/148`. `script/analyzer-schema.sh bump` only repinned its input digest,
because `go.mod` is an analyzer input. That is why `internal/contextindex/analyzer_schema_test.go`
changed.

## sql-native ratchet rows

`SNR-V0-030` admits only versions that `go-version` admits, so both go1.27.2 rows were removed.
The darwin/arm64 Homebrew go1.27.3 row stays; its digest matches this host. `SNR-V0-031` is
amended to require the linux/amd64 official-module go1.27.3 row. That row is `NOT_OBSERVED`, so
the opt-in `make sql-native-ratchets` refuses on such a host with `TOOLCHAIN_MISMATCH` until it
is measured.

- The unpublished 1.0.0-rc.3 candidate was built with go1.27.2. It must be rebuilt with go1.27.3
