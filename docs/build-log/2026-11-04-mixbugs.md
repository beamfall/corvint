## Friction

1. Configured heavy lock directory `/home/russell/bench/rt/.locks` and its fallback log are
   read-only here. The wrapper refuses before tests; writable shared `/tmp/corvint-heavy-1000`
   plus a scratch fallback log admits the same commands.
2. `/var/tmp` is read-only in this sandbox. A private executable user-cache TMPDIR avoids both
   that refusal and the stray `/tmp/.git` found by Git discovery in an archived source tree.
3. An archive-only base build needs `-buildvcs=false` because it has no .git and the ancestor
   scratch Git marker is invalid. The base binary's source is the exact base archive.
4. Retrieval diagnostics with `--context-packets --jobs 4` are refused; registered four-worker
   readings omit diagnostic capture and retain complete result/registration files instead.
5. `dogfood prechange` refuses hand-written receipts at its reserved paths. Preserve those
   original receipts elsewhere and rerun the supported producer with actual tracked Go files.
6. ASD's Requirements section already has 256 obligations. A redundant new requirement for
   existing shard behavior would exceed capacity. The documentation-only correction cites
   existing ASD-V0-026 instead; no capacity or verification limit was raised.
7. Initial broader score correction altered unrelated pair/cochange display scores guarded by
   existing tests. Restrict the delivered change to definition/test slots; the focused suite
   verifies those other contracts without changing their expectations.
8. Host load admission adds measured waits of 5–35 seconds to some focused checks. These are
   scheduler waits, not test execution times or evidence of a test timeout.
9. The standalone marker checker reads repository files, but its tests only read private
   fixtures. It is not an unbounded test reader; do not add it to that declaration merely
   because its command scans source.

10. Spec moves require 23 mechanical line-citation repins across existing documentation. The
    resolver stages only moved anchors; the line-citation gate then passes, keeping the
    180 pre-existing untracked-basename skips visible.
