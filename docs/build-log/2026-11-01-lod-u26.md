## Friction

1. Unraid mawk does not handle the `(^|[^0-9])` alternation inside a dynamic regex.
   - Repro: `awk -v id=V1-1 '$0 ~ "(^|[^0-9])" id'` on unraid-lanes.
   - Expected: it matches the way gawk does. Actual: whole-ID matches fail.
   - Worked around by padding the text with spaces and matching `[^A-Za-z0-9-]ID[^0-9]`.
2. In mawk, `-v RS=...` also changes `getline` inside `BEGIN`.
   - Expected: an idfile read line by line. Actual: the whole file arrives as one record.
   - Worked around by setting RS inside BEGIN after the getline loop.
3. The charter names off-limits paths that do not exist at BASE: `internal/affected` and
   `benchmarks/cem2-discovery-replay-v0/`. Expected: real paths. The new screen's `missing-path`
   warning catches this kind of mistake.
4. `corvint version` is not a subcommand; the form that works is `corvint --version`. The brief
   assumed the subcommand.
5. The brief says unraid-lanes has no gh, but `lane-host-check` found gh installed. The brief is
   out of date.
6. The Unraid corvint binary is stale: built from 6d4713fb, with 5 or 6 Go paths behind. As a
   result, `corvint affected` degrades. Operator rebuild needed.
7. A first `--charter` mode extracted every ID-shaped token in the charter and produced noisy
   refusals. IDs are now positional only, and the charter is passed as `--refs-file`.
8. A checkout copy without `script/requirement-ids-free.sh` made the block check pass silently.
   - Expected: a refusal. Actual: ok.
   - Fixed with `block-check-failed`, and covered by a test.
9. `make spec-requirements` refuses an unstaged spec. Expected: a hint before the edit. Actual:
   only the refusal tells you to `git add` first.
10. zsh heredoc quoting breaks inline `python3 - <<EOF` sent over ssh. Worked around by writing
    scratch files and running `ssh HOST python3 -I - < file`.
11. Unraid tar warns about `LIBARCHIVE.xattr` headers on tarballs made on the Mac. The warning is
    noise, but it hides real errors.
12. `/tmp` on unraid-lanes is 72% full (it holds the shared Go cache).
13. The V1-4136 skill text lives in `.claude/`, which lanes may not edit, so the ticket cannot be
    fully delivered from a lane.
14. V1-1754 AC1 requires a seal, which lanes are forbidden to do. Any ticket whose acceptance
    needs a seal cannot be closed by a lane.
15. `conformance/divergence-register.md:2497` keeps the old selector-miss message text. It was left
    as is because it is historical, but it is now stale.
16. `docs/specs/ocm-v0-dogfood.md:542` cited `ocm_write.go:930`, which was already 11 lines off at
    BASE. `line-citations-check` let it pass because the line was not blank. Expected: unpinned
    citations to be content-checked. Actual: only blank or bracket lines are caught.
