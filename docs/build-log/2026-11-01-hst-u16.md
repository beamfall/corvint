## Friction

1. V1-3686 and V1-3521 blamed `/tmp` or `TMPDIR`, but the cause was the 0002 umask that WSL and Unraid use for `t.TempDir()`. A check that flags a `t.TempDir()` home passed to an ownership-checking path would catch the next one.
2. `heavy.sh` refuses `-run Test`, which matches every test, as a whole-package run. A lane needs a narrower pattern even to run a package's full set.
3. The assigned block 960-979 was already partly used in `ASD-V0` (960-962, 965, 970), `SRG-V0` and `CAP-V0` (960-962, 965, 970, 972-974). Each prefix needed its own free check.
4. V1-3781 was delivered on BASE but its ticket was still open (delivered-but-open).
5. Wiring `windows-main-check` into `make windows-vet` is blocked by `TestAFPV0054`, which pins both the recipe lines and the exact `windows-vet: go-version` prerequisite line. So the early check is opt-in.
6. A generator edit moved a pinned line citation (`script/gen-spec-requirements.sh:404`), and only `make line-citations-check` found it. `spec-requirements-check` did not.
7. The V1-3508 acceptance bar asks for load >= 40, which a lane cannot produce without background load, which the charter forbids. It needs an orchestrator-run loaded host.
8. The `internal/specindex` test fixture README header differs from the table header the generator requires.
9. `corvint affected` on the lane head reports `self-binary-stale`, because the installed binary is built at BASE.
