## Round four: test-read-scopes-check (V1-4238)

The profile of `tools/test-read-scopes-check` on this repository showed where its time went. All of it ran on one thread:
- 27 sequential `go list -deps` calls, about 3 s;
- each test file parsed up to six times by `go/parser`, plus GC;
- one call to the affected graph build, about 1.2-1.4 s.

The single slowest package was `cmd/corvint-test`: 11 files and several identical `go list` calls, 0.9-1.0 s.

The fixes:
- `DCW-V0-759`: packages run on a `GOMAXPROCS` pool, and each package's files on their own goroutines. Results merge in unit and file order, so the output is unchanged.
- `DCW-V0-760`: four of the parsing functions share one memoized parse per file content.
- `DCW-V0-761`: each distinct `go list -deps` runs once per package. Go commands drop from 27 to 23.
