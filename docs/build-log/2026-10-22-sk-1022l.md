## Problem

Nothing in Corvint listed page objects with their methods and actions, or normalised test bodies
into steps. AMAP-V0 test files bind page objects by manifest only (V1-1236), so a request such as
"how do I X" had no step-level knowledge to draw on.

## Decisions

- **Surface (SKH-V0-008, 013).** Two new verbs in the existing family, `corvint flows appmap
  pageobjects` and `corvint flows appmap steps`, each with `--map`, a repeatable `--source` (1..16
  repository-relative directories) and `--budget`/`--full`. Sources are read from `--root` at the
  map revision. There is no new model or top-level command.
- **Profiles (SKH-V0-007, 023).** `site-knowledge-page-objects/0` and `site-knowledge-steps/0`.
  `DecodeSKStep` refuses an unknown field, kind or opaque reason, and trailing data, by name.
- **Forms (SKH-V0-010).** Playwright TS class and module, Cypress TS class and module, Capybara
  class, SitePrism page. Any other file type is an unknown naming the file and form. A TS class
  counts as a page object only when it looks like one (extends, locator properties, a page
  parameter or `this.page`, Cypress `cy`), so reporters and utilities are neither listed nor
  unknown.
- **Hops (SKH-V0-012).** Inheritance, included modules, imported helpers and spec-local helpers
  (including helpers nested in `describe`) are followed one anchored hop at a time, at most 8. A
  name declared twice at nested scope stays `unresolved-call` rather than picking one.
- **Arguments (SKH-V0-021).** Literals, parameter slots and template literals: `${param}` becomes
  a slot, `${CONST}` takes a module constant's literal, and anything else is `dynamic-value`.
  Inlining substitutes bound slots and screens every bound literal (SKH-V0-006).
- **Asserts.** `expect(subject, message)` reads the first argument only. The assert target is the
  locator, `page` for a page subject, or `value` for a test-local value.
- **Effects (SKH-V0-011).** The ANL-V0-035 classes over a method's own actions:
  - `navigation-only` when every action visits, waits, asserts or clicks a link role;
  - `state-effect` when any action fills, selects, checks or uploads;
  - `unknown` for any other click, an opaque step, an unresolved hop or an empty method.

  The screen join reuses the AMAP import-graph join.
- **Bounds**, set before the extractors were built: 4096 candidate files, 8 hops, 512 body steps
  per test and 2048 inlined steps. The existing AMAP test-file byte caps also apply.
