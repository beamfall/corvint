## Delivered

- **V1-0479** (`EEP-V0-821`, external-evidence-provider-v0). The agent-side gopls provider
  (`internal/lspprovider`) previously sent an empty `capabilities` object, never read the server's
  position encoding or method capabilities, and pinned no executable identity. Only
  `internal/goplsclient` (the editor companion) negotiated. The provider now offers UTF-16 only,
  refuses any other or malformed `positionEncoding`, queries only the advertised `definition` and
  `references` methods, refuses a server that advertises neither, and reports
  `position_encoding`, `methods`, `unavailable_methods` and `executable_sha256` in the query
  summary. The digest is observed, not authenticated, and is bounded at 1 GiB; an unreadable
  executable fails as `gopls executable unreadable`. `TestExpandNegotiatesBeforeQuerying_EEPV0821`
  covers default, definition-only, references-options-only, utf-8 refused, null refused and no
  providers refused, and checks that no textDocument query follows a refusal.
- **V1-0481** (slice, `LQP-V0-012`). `assertTestedCapabilitySubset` in
  `internal/lspstdio/semantic_test.go` now runs on every semantic harness initialize and fails on
  any standard capability outside `positionEncoding`, `textDocumentSync` and `experimental`, or a
  `textDocumentSync` member outside `openClose`, `change` and `save`. A falsifier that added
  `hoverProvider` to the initialize result failed `TestSemanticOverlayDefinition` with
  `untested standard capability "hoverProvider" advertised`, and the change was reverted.

## Review repairs (Codex, CONCERNS on 9e1535e7d)

All four findings were checked against the code and confirmed.

- `executableDigest` opened the path before supervision began, so a FIFO named gopls blocked
  forever. It now reads only a regular file (Stat, then fstat after Open). Any other file type
  fails as `gopls executable unreadable`, and the `EEP-V0-821` text says so.
  `TestContextLSPRefusesNonRegularExecutable` timed out at 10 s on the old code. One residual
  race is accepted: a path swapped to a FIFO between the Stat and the Open can still block.
- `dialogue` returned an empty expansion on any error after negotiation, which dropped
  `position_encoding`, `methods` and `unavailable_methods` even though `EEP-V0-821` already
  requires them once the encoding is accepted. It now returns the walked expansion. The server
  version is set only after a complete dialogue, so a failed shutdown still reads as
  `gopls session failed` and is never treated as a success. A crash-mode case in
  `TestExpandNegotiatesBeforeQuerying_EEPV0821` failed on the old code.
- The scripted gopls moved to `internal/testsupport/fakegopls.go`.
  `TestContextCLIMatchesMCPReceipt` now also compares a completed dialogue with relations and an
  outside-root count.
- `TestAttachCarriesProvenanceAndDedupes` now requires a 40-hex blob string on both endpoints,
  instead of `fmt.Sprint`, which turned a missing blob into the non-empty string `<nil>`.
