# V1-0632 S5c: read-only stable witness, collapse, documentation and console projections

Date: 2026-10-11. Base: `a8c05c4f45a8971665ee97d2eada7c739a0e0d14`. Branch:
`claude/cem1-s5-projections`. Scope: migration rows C13, C14 and C16 of

to sibling lanes. No decisions, ticket-store writes, PRs, CEM bind or seal.

## Decisions

- Each family gets a new stable route and a new profile or schema beside its unchanged 0.x
  route: `corvint-witness-stable/0` with binding `corvint-witness-stable-binding/1`,
  `corvint-correlated-witness-collapse/experimental-stable-v0`, and
  `corvint-corpus-cem-stable/1`. No 0.x byte or profile is reinterpreted.
- Admission is the complete stable verifier over the full input binding (repository,
  expected base, target, artifact root) and the exact map digest. A refusal keeps the
  verifier result and produces no citation, collapse or claim row.
- Witness, collapse and documentation routes compute over the private mechanics view
  (`wire.Map(document.Change)`), which is never serialized or handed to a writer. The
  documentation route offers no `cem cite` argv.
- The console is display only. It admits `cem/1.0` in its closed registry after a strict
  `wire.ParseStable` of the whole document, runs no verifier and opens no artifact. Its
  stable rows are appended to the binding edges, so `views.go` is unchanged.
- `internal/witnesscollapse/compile.go` was restructured with identical line positions for
  the lines `docs/specs/correlated-witness-collapse-x0.md` cites.

## Limits

- Library-level only. No CLI route reaches the stable witness (`corvint witness` has no
  artifact-root flag), the stable documentation projection (`docs corpus` paths) or the
  stable collapse. Wiring those is follow-up work.
- The console has no dedicated stable panel; it draws envelope, axes, sidecar and reference
  rows inside the existing binding table and states verification NOT_RUN.
- Evidence-drift and unsupported-runtime cases rely on the verifier's own vectors; this
  slice adds per-family refusal tests for wrong base, edited map, tampered artifact and a
  missing artifact root, not new per-family runtime vectors.
- `make gate` and `./...`: NOT_RUN by lane policy.
