### V1-2744: symbol-level reachability (ADN-V0-660..663)

`GoAdditive` gains a symbol mode for an edited Go declaration (`internal/liveverify/affected/golang/symbol.go`).
- It computes the name closure of the changed declarations inside the package, including the receiver rule.
- Only importers that name an exposed (exported, reached) name keep their tests.
- Hazards fall back to whole-package selection with a named reason:
  - `init`;
  - an unproved var initializer;
  - a bodyless func;
  - assembly;
  - `go:linkname` in the package or in an indirect dependent;
  - an unmodelled dependent.

Soundness proof (ADN-V0-663): `TestADNV0663SymbolSelectionCoversLinkedTestBinaries` is a differential oracle.
- It builds each fixture test binary with `go test -c -gcflags=all=-l` and reads its symbols with `go tool nm`.
- Every binary that links the edited symbol must be selected.
- Result: recall 6/6 linked binaries; 13 unlinked binaries excluded.

Fork decision (mine, with evidence): reachability works at importer granularity, not at test-function granularity.
- A test binary always runs `TestMain`, `init` and package-level initializers.
- So dropping single test functions inside cmd/corvint, internal/tasks/store or internal/tasks/cli is unsound unless always-run code is modelled.
- Those packages stay whole with a named reason.

AC1 for the V1-2708 allow-listed packages is NOT met. On repro 1b the plan went from 84 to 75 selected units (9 excluded), and the mode is now SYMBOL. The exposed names are `How`, `HowDraft`, `Prefixes` and `ProjectEntries`. The three reached importers (`cmd/corvint`, `cmd/corvint-corpus-mcp`, `internal/changee2e`) really do name an exposed symbol, so importer-granularity narrowing keeps them. Narrowing inside them needs the test-function model that the fork above rules out for now. The substrate and the oracle are delivered; that remainder stays open.

### V1-4118: plan-delta replay (TSP-V0-666)

`go run ./tools/plan-delta before.json after.json` compares two `corvint affected --format json` receipts for one path list. It prints:
- the units removed and added;
- the units re-witnessed;
- the unknowns removed and added.

The recipe:
1. Run a clean `corvint affected --path P --format json` to get the before receipt.
2. Edit the declaration.
3. Run `corvint affected --worktree --path P --format json` to get the after receipt. A dirty declaration that is not in the path list is read without counting as a change.

## Friction (full list)

1. **Stale WSL binary.**
   - Repro: run `corvint` on wsl-lanes after main moved.
   - Expected: a current binary.
   - Actual: the self-binary-stale warning, so I had to build a lane binary.
2. **heavy.sh refuses whole-package runs without HEAVY_WHOLE_REASON**, even for small packages (tools/plan-delta runs in 0.3 s).
   - Expected: a size or cost threshold.
   - Actual: a blanket refusal.
3. **plugin:corvint MCP fails to connect.**
   - Actual: CONNECTION_CLOSED on every session start in this lane, so the MCP tools were unavailable.
4. **zsh expands a leading `=====`** in echo separators.
   - Repro: `echo =====`.
   - Actual: zsh treats it as `=cmd` expansion and errors.
5. **Spec header and Claim lines are capped at 160 characters**, which forced rewording.
   - Expected: the limit stated in the spec template.
   - Actual: it is discovered only at check time.
6. **`corvint test` needs the full base sha.**
   - Actual: an abbreviated sha is refused.
   - Expected: resolve it, or name the fix in the refusal.
7. **The jq shape of `corvint affected --format json` is undocumented.**
   - `.plan.selected[].witness.kind` was found only by trial.
8. **The V1-2708 build log exists only in the archive/final tag**, not on origin/main, so the evidence route breaks.
9. **aff-w26 left items open and out of time.** V1-2744, V1-2583, V1-4178 and V1-4118 came to this lane unstarted.
10. **An `affected.FSSource` over an `fs.FS` needs an undocumented `OpenBounded(name, limit)` method.**
    - Actual: without it, ReadBounded fails with ErrWalkUnrepresentable, which surfaced as foreign-callers-invalid or read-scopes-invalid.
    - Expected: a documented interface or a fallback.
11. **ssh heredoc quoting ran commands on the Mac.**
    - Repro: a nested-quote heredoc inside `ssh ... '...'`.
    - Actual: zsh ran fragments locally, including `script/check-install-lifecycle_test.sh` in the primary checkout (no repo files changed).
    - Workaround: pipe scratch scripts as `ssh ... python3 - < file`.
12. **.github callers were invisible to both completeness checks** (fixed here, TSP-V0-665).
13. **A dirty declaration file makes a plan UNKNOWN**, so replaying a declaration change needs `--worktree --path` with the declaration outside the path list. This is now documented in tools/plan-delta.
