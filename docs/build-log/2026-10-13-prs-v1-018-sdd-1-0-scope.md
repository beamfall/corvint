## Decisions

- The acceptance is recorded in the spec header, Agent digest, `INDEX.json`, `README.md` and the

  dependency; the owner decides whether to drop the clause by amending this requirement.
- No Tasks claim backs this lane, so the ticket-side closeout that normally carries a spec change
  (submit, gate, complete) is absent; the PR and this entry are the only record.
