## Decisions

- **V1-1857.** At load, `promptSafeHost` matches the interpreter list only when the element's last
  path segment is all literal. `{ticketLocal}sh` now loads, because its rendered value is rechecked at
  launch (ATR-V0-133). `{workRoot}/bin/python3` and `{ticketLocal}/sh` stay refused. The code-string
  option rule still applies to every element.
- **V1-1853.** The checks stay name-based. ATR-V0-164 states the limit and puts the remaining part on
  the operator who configures the host: a wrapper or renamed program that evaluates its argument is
  not detected. A maintained test records which cases are caught and which are not. Inspecting the
  program file was rejected as unbounded.
- **V1-1854.** The dispatcher alerts once per ticket under one applied configuration digest. The
  record is in memory only; a restart may alert once more. The block is still withheld on every
  launch.
- **V1-0748.** Spec only (ATR-V0-166). A gate on a non-file stdin cannot interrupt a read already
  blocked in the caller's reader without making shutdown block. So the contract says a caller must
  not reuse a non-file stdin after `HOLD`; the CLI passes an empty reader. The output-gate sentence
  now says later writes are refused, so survivors may see `EPIPE` or `SIGPIPE`.
