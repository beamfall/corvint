## V1-3711: opt-in labelled fuzzy fallback for context (TCP-V0-650 to TCP-V0-652)

- Decision: the fallback is opt-in through `CORVINT_CONTEXT_FUZZY=on` and stays off whenever an
  explicit term selection is in force. With it off, the context results JSON is byte-identical to
  the base binary on four queries, and the recipe golden is unchanged for the values "", `off` and `1`.
- Each fuzzy credit is labelled in the row reason (``fuzzy `a`~`b` `` or `` `x` verbatim ``). The
  credits are: edit-distance-one neighbours of rare terms (minimum term length 5), path stems,
  two-term concatenations matching a path token, verbatim hyphenated words, and configuration files
  for config/settings words. Record data is no longer gated out when the path names two or more query
  terms.
- Probe ranks with the flag on (base rank, limit 20, in parentheses):
  - `unplaned read ledgr`: `internal/unplannedread` at 2 (absent).
  - `merge-base check for PR narrowing`: `.github/forward-rows/mq-narrow.sh` at 4 (18).
  - `test read scopes config`: `.corvint/test-read-scopes.json` at 3 (8).
- Cost: about 0.92 to 1.07 s with the flag on, against 0.85 to 0.91 s with it off, on Unraid.
- PARTIAL (external): the frozen context bench (`tools/retrieval-bench --arms context`) is NOT_RUN,
  because its data is absent on the lane host. Without that gate the fallback cannot become the default.
- Review fixes (Codex round 1, three P2 findings, each confirmed by a regression test that fails
  without the fix):
  - A fuzzy lexical row that only corroborates a path another relation admitted now prefixes that
    row's evidence reason with its `fuzzy` label; a promoted reservation does the same
    (`TestContextFuzzyCorroborationIsLabelled`). Decision: the label goes in the reason, where
    TCP-V0-650 puts it, not into the relation names, since `orderRelations` only knows slot names.
  - The verbatim hyphenated literal keeps its case, so the case-sensitive anchor match no longer
    credits a source that has the word only in lower case (`TestContextFuzzyVerbatimKeepsCase`).
  - The configuration-word credit now counts as a path-field credit, so `scopes config` alone
    promotes `.corvint/scopes.json` to code; the promotion test no longer hides this behind a third
    term (`corvint`).
