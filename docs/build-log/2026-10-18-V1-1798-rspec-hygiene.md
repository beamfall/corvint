## Intent

A Ruby example cited as proof must not pass review when RSpec never ran its assertion as cited:
- skipped, pending or focused examples;
- an example inside a shared example group, which runs only through an including group.

A stub on `described_class` and an example body with no expectation weaken what a pass shows.
The TSA-V0-045 and TSA-V0-049 findings existed only as library calls (V1-1787). They now reach a
command and the discovered test-validity document.

## Decisions

- **One RSpec reading.** The example rules reuse the TSA-V0-048 line reader and abstain exactly
  when it does. The reader now also treats `skip` and `pending` declarators as examples, records
  each group's declaring line and head, and keeps hook bodies. Its memoized-block logic is
  otherwise unchanged, so the in-flight BLOCK-NOT-CALLED rule (#1141) composes with it.
- **Injection instead of an import.** `internal/testsource` already depends on
  `internal/testvaliditydoc` through `appmap`. So discovery takes a `RubySourceReader`
  (`DiscoverWithSources`), and the CLI and the MCP bridge both pass `RSpecExampleSources`. That
  keeps their bytes identical, and `Discover(root)` stays unchanged.
- **Bound spec only.** Discovery reads a spec file through the existing confined receipt reader
  and uses it only when its Git blob ID equals the retained `specBlob`. An edited spec abstains
  with `rspec-source-not-bound` rather than reading new text against an old run.
- **Strength is not decided statically.** Strength stays `NOT_MEASURED`. The stub and expectation
  facts are its reason and anchors; only a mutation run gives `KILLED` or `SURVIVED`.
- **Pending is a run fact.** A `pending` status from the provider is `INELIGIBLE`
  `rspec-example-pending` on every path. This amends LPCV-V0-093's "hygiene never claimed"
  reading for that one status.
- **Command surface.** `corvint tests validity` reads named committed files and exits 1 when a
  test is `INELIGIBLE`. Its refusals reuse the existing `tests-*` codes.

## Overlap

PR #1141 (BLOCK-NOT-CALLED, TSA-V0-053..056) touches `validity_rspec.go`, `validity.go`,
`source_rules.go` and the static-rules section of the spec. This change avoids those IDs, those
spec lines and the delivery table. Its own traceability table sits in a new section. Generated
spec indexes will need regeneration when the two meet.

## Evidence and residuals

Focused tests in `internal/testsource`, `internal/testvalidity`, `internal/testvaliditydoc` and
`cmd/corvint` trace every ID. Real-suite qualification is NOT_RUN.

Residuals (spec non-goals):
- resolving the group that includes a shared example;
- conditional or config-driven skips;
- expectations in helpers;
- JS/TS discovery attaching source findings;
- an MCP tool and a preflight surface for `tests validity`.
