## Decision and boundary

`ASD-V0-1990` extends the existing `ASD-V0-825` lane marker rather than introducing a new
receipt format. `LANE=1` defers selection-baseline before inspecting its recipe packages or
planner results. Both closeout targets already export that variable, so neither the pre-bind
`BATCH_PRECHECK_SKIP_DRIFT=1` pass nor the sealed-head `BATCH_PRECHECK_SINCE_RECEIPT=1`
pass builds or runs the baseline target. The emitted print-only step bypasses the gate ledger,
reports `NOT_RUN` in progress and the table, and contributes an explicit `not-run
selection-baseline-check` deferral reason to a receipt, never a passing check. The existing
`.lane` sidecar now also marks a baseline-only deferral. A non-lane since-receipt run refuses
to narrow from that receipt before either the HEAD shortcut or ancestor selection.

Outside `LANE=1`, the existing input-based skip and run rules remain in place. CI, the plain
batch precheck and `make selection-baseline-check` retain their workload. No Makefile change,
Go implementation change, baseline data change, or change to the companion lane's `at_base`
comparison or case-1b Pi fixture is included. Rollback removes the lane deferral and restores
`ASD-V0-944` selection in both modes.

The independent read-only review found an aggregate bypass: when `doc_gate_expansion` cannot
recognize the Makefile recipe, `make doc-gates` stays opaque and could invoke the deferred
baseline. Lane mode now refuses before executing steps for that condition, with an explicit
repair diagnostic. The recognized aggregate still runs peer gates. Non-lane aggregate fallback
is unchanged. The follow-up independent review reported no remaining findings; it did not run
tests or benchmarks and is not a committed-head review, because this lane cannot commit.

`ASD-V0-1990` was unused in `origin/main`'s requirement ledger before allocation (the reserved
1990–2009 block had no ASD rows). The existing self-development spec and generated requirement
ledger/README were updated. Staging used a private index and object directory under `.lane-tmp/`
with the real object store as a read-only alternate; the real index and `.git` were untouched.
`make spec-requirements` then passed, including its OCM obligation-bound test. An initial
`##` subsection failed SRG-V0-891 because it placed the definition outside Requirements; changing
that to `###` fixed the failure. This failed generation is not passing evidence.
