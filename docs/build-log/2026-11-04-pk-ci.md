## Decisions and scope

The CI jobs now make the declared adapter family and required web-flows consumers part of the
required result. The latter installs the npm lockfile without lifecycle scripts and its matching
Playwright browser. A dry-run plan selects that job; an unrelated Go change leaves it skipped.
A separate, explicitly networked preparation job populates the exact local-authority module cache;
`go-static` restores that cache, refuses a miss, verifies checksums and tests offline. This avoids
vendoring a stale copy of Corvint itself through the module's `replace ../..` directive. No claim
of a network-free *workflow* is made; the compiler job performs no network fetch.

The permission check already understood per-job exceptions, but only the exhaustive gate invoked
it. It is now a shared PR documentation gate. Its real index check also exposed an unlisted
`go-product-shard` actions:read grant; the exact read-only grant and reason now have an exception.

Error-code ownership retains index authority and explicitly names omitted unstaged/untracked
inputs. Worktree bytes do not silently replace the bytes a clone receives. Closeout checks line
citations before binding and disables mechanical regeneration in the sealed-head precheck.

The self-development Requirements section already holds 256 obligations. New maintenance clauses
therefore use its registered CSD companion rather than exceeding the OCM bound. Every new ID was
checked with `git -C /home/russell/projects/corvint log --all -S ID --oneline`; no collision was found.
The existing protocol-package version checks and proactive capacity warning were confirmed rather
than reimplemented. The latter warns at 248/256 with default margin 8, stays quiet at 247 and
supports an explicit margin override; doc-gates' index check emits that warning too.

Snapshot truncation required a product repair: private mapped pages on the nightly macOS host
remained readable after truncation, so a fault guard could return ten apparently valid bodies.
Each mapping now owns one close-on-exec duplicate of its backing descriptor, released with its
last lease. An uncached lazy body checks that exact inode's size before copying. This adds one
fstat per uncached body; latency and comparative performance are NOT_OBSERVED. Verified cached
heap bytes retain their prior semantics. No language, authority or snapshot wire format changes.
