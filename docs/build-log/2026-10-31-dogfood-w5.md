  `cem status` pairs are safe. The option is opt-in (`CheckOptions.ConcurrentVerifiers`, set by
  the dogfood commands) so unit-test fakes that are not concurrency-safe keep sequential runs.

## Review fixes

One independent review round (five findings). Each fix has a regression that failed on the lane's
code and passes after the fix.

- P2 batch-precheck SIGPIPE: FIXED in 70c1fe832. Under `set -o pipefail`, `grep -v ... | grep -q .`
  SIGPIPEs the writer once `grep -q` exits, so the negation read 10,000 non-documentation paths as
  docs only and skipped `@go` entries. Now a single `grep -qvE`. `script/batch-precheck_test.sh`
  case 7 (10,000 untracked `notes/*.txt` plus a docs change, planner exit 3) failed at line 768
  before the fix and passes after it.
- P2 mixed-prefix ranges: FIXED in d4f8da803 (spec, `OCM-V0-900`) and af7ef310f. The upper
  endpoint's prefix is now captured, and a row such as `TCP-V0-990..ABC-V0-999` traces nothing.
  `TestOCMV0900TracesCompactTestSuffixesAndRowRanges` failed before (`traced TCP-V0-995`).
- P2 `~` hint test on Windows: FIXED in 5a020d70a. The test also sets `USERPROFILE`, which
  `os.UserHomeDir` reads on Windows. NOT_RUN on Windows: `make windows-vet` only type-checks it.
- P2 REVIEW path assertion on Windows: FIXED in 5a020d70a. The expected path is built with
  `filepath.Join`, as `reportReview` does. NOT_RUN on Windows: `make windows-vet` only type-checks
  it.
- P3 sequential query abstention: FIXED in 28c45287b. `verifyPair` and `verifyAll` take a `status`
  flag, set only on the `cem status` path. `verifyQueryAbstention` passes false, so its pair stays
  sequential, as `DCW-V0-907` already required.
  `TestDCWV0907QueryAbstentionVerifiersStaySequential` failed before (`ran [tree base]
  overlap=true`).
