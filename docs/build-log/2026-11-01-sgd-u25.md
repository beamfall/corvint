## Landing review fix (2026-11-04): JSON mask hid shell code

The landing review found that the GOC-V0-081 mask blanked any single-quoted word starting with `[`
or `{`, so `sh -c '{ python3 -c "print(1)"; }'` was masked, although the base scan reported it.
The mask now blanks such a word only when it parses as JSON arrays or objects (strict check in awk,
after an optional leading comma for spliced array elements), its command names no shell, `eval` or
`-c` flag, and it is not a bare word in command position (the scan sees only grep-matched lines, so
such a word may continue an earlier `sh -c \` line). The self-test adds eight shell-code cases,
among them the review's: the reviewer's case fails the previous mask, and dropping the command guard,
the command-position guard or the JSON check each fails a case. The tree still passes under gawk,
mawk and macOS awk.
