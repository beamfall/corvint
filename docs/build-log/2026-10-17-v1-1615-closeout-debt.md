# V1-1615: closeout-debt read verb

Tickets stayed OPEN after their work merged. Completion is a separate native write that no merge
triggers, and the 2026-10-17 audit found 22 of 37 suspected tickets were delivered but still open.
This change adds `corvint-tasks ticket closeout-debt`, specified in
`docs/specs/corvint-tasks-closeout-debt-v0.md` (new prefix `TCD-V0`, checked unused on
`origin/main`).

Intent: `TCD-V0-001..010` are accepted under the owner's standing auto-accept of lane requirements
(2026-10-11). No other spec was edited. CAL-V0 (leases) and TQD-V0 (doctor) are excluded.

Design:

- The verb is labelled "candidate" and is a pure read. A test compares the `.taskman` and
  `.git/taskman` bytes before and after.
- Git reads go through the store's sanitized environment. Hooks and fsmonitor are disabled, and so
  is the credential helper. `git log` runs without `--first-parent` and with
  `--no-show-signature`.
- The scan is bounded by `--limit` (default 1000) and a 64 MiB output bound. Truncation is reported.
- Citations are matched as exact tokens. Direct-id beats issue-link, and a commit that cites more
  than one ticket marks each row umbrella.

Exit codes differ from the CLI's usual "0 iff OK": 0 means no candidates, 1 means candidates and 2
means a typed refusal. This is specified in TCD-V0-009.

`COMPLETE_REFUSED` is NOT_PRODUCED. A refused `complete` writes no journal record, so the store
cannot show it. Instead, the verb reports `GATES_PASSED_COMPLETE_PENDING`.

Review fix round (one Codex round, four findings, all fixed with a regression test each):

- `git log` now forces `--encoding=UTF-8`. Under `i18n.logOutputEncoding=UTF-16` the NUL-split
  parser lost every citation (TCD-V0-002).
- Rows are counted in full but at most 2000 are held, in a bounded max-heap, so a fan-out of many
  tickets linking one issue times many closing commits no longer materialises every row first
  (TCD-V0-007).
- Tickets of every status are indexed, so a commit citing an OPEN and a COMPLETED ticket marks the
  OPEN row umbrella. Only OPEN rows are emitted (TCD-V0-004, TCD-V0-005).
- `rev-parse` exit 1 stays `MALFORMED`; any other Git failure, including one during the default
  origin probe, is now `UNSUPPORTED` (TCD-V0-002).

Rollback: revert the change. The verb has no state and no wire dependants.
