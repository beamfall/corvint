## V1-4695: cmd/corvint fixture git identity

Already delivered on origin/main by V1-4719 (`CCF-V1-9800`, merged in `83660e9c5`, 2026-11-07):
`internal/testsupport.WithoutGitIdentity` strips inherited `GIT_AUTHOR_*` and `GIT_COMMITTER_*`
from every direct cmd/corvint fixture Git command, the fixture helpers that commit pin their own
identity and dates, and `TestFixtureGitCommandsUseHermeticEnvironment` refuses a new direct
`exec.Command("git", ...)`. The drift cause was the Git environment: `GIT_AUTHOR_*` and
`GIT_COMMITTER_*` take precedence over `-c user.*` and config, so an exported identity or date
changed the fixture commit IDs the frozen profiles and the TCP-V0-024 wire golden carry. Measured on
this base: all 639 tests of `./cmd/corvint/` (`script/go-test-shard.sh ./cmd/corvint/ I 8`, I=1..8)
pass with foreign `GIT_AUTHOR_NAME/EMAIL/DATE`, `GIT_COMMITTER_NAME/EMAIL/DATE` exported and a
foreign `GIT_CONFIG_GLOBAL` identity. No code change.
