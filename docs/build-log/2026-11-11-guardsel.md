## V1-5364: the flow-guide-check predicate matched every licence header

`tools/flow-guide-check` reads three things below `cmd/`, `internal/` and `tools/`. `checkGuide`
looks up each code of the guide's recovery table, with `bytes.Contains`, in the concatenation of
every non-test `.go` and `.sh` source. `unclassifiedCounts` counts calls whose callee starts with
`refuse` or `Refuse` (in `--audit` only). `load` reads the command-tree snapshot
`internal/capcatalog/trees/corvint.json` and, while it exists, `internal/dogfoodflow/`. The
declared predicate `[rR]efuse|[a-z][a-z0-9]*(?:-[a-z0-9]+)+|[A-Z][A-Z0-9]*(?:_[A-Z0-9]+)+`
matched any hyphenated or upper-snake word instead of the six codes the table maps
(`local-reason-missing`, `whole-reason-missing`, `unsupported-object-alternates`,
`unpinned-review`, `RESOURCE_COLLISION`, `OUT_OF_SCOPE`).

Decision: the predicate is `[rR]efuse\w*\s*\(` plus the six codes as literals. A test in the
guard fails when the table maps a code that a predicate misses (AFP-V0-9981). The command-tree
snapshots and `internal/dogfoodflow/` become plain subtree entries, because the new predicate does
not describe a JSON snapshot. Rejected: deriving the predicate at plan time from the guide, which
would make selection read a document the reader rule does not model.

## V1-5365: confirmed, a frontier site re-selected the guard

Reproduced on `origin/main` with the build 167 binary: after a comment-only edit of
`internal/analyzerruby/lexer.go`, `corvint affected --full --format json` selected
`go:github.com/Beamfall/corvint/tools/flow-guide-check` with witness `PATH_LITERAL_READER` and
`via` `typescript:internal/appmap/navigation-events.cjs -> go:.../tools/flow-guide-check`.
`lexer.go` does not match the predicate. The site edge (AZU-V0-212, `observersOf`) passes the site
unit's own files to `readers`, and `treeScopeBears` found no endpoint content for
`navigation-events.cjs`, because content was gathered for dirty paths only, so it selected.
`navigation-events.cjs` also matched the old predicate (`navigation-events`), so either defect
alone kept the guard selected.

Decision (AFP-V0-9982, AFP-V0-9983): `observersOf` records the site file's BASE and HEAD bytes on
demand, once per plan, from the plan's own sources, and the predicate then decides that edge as it
does for a dirty path. Anything unknown still selects. The sources are kept in the per-plan
`readScopeInputs` behind a mutex and never enter the graph cache. After the CLI's Git object
session ends, a BASE read falls back to the budgeted one-shot path; a failure there keeps the
reader selected.
