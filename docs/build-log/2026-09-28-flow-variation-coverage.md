read-only MCP tool confined to the opt-in flows profile. AFU-V1-049..053 defines the denominator,
original `/3` run inventory, proof statuses, global paging and safe documentation write-back.
PWP-V3-007 admits exact empty project names only for `/3`; earlier profiles retain their boundary.

exclusions, proposed-exclusion promotion and empty entry locators. The implementation rechecks whole
current inventories, pairs subject/control by immutable execution group, and preserves human acceptance
boundaries. Old changed run groups remain historical; a fresh current proof can requalify without
discarding history. Comparable retry/manual contradictions remain blockers. Final review found that metadata-only source/test revisions could split identical-byte history; comparison now hashes mapped input/build bytes and execution configuration, while the stricter subject/control proof group separately retains declared app identity. source bindings are checked independently of visible working bytes.

Important boundary: PROVEN binds source/test/config/package/served-build bytes and declared application
identity. `/3` does not attest deployed lineage, observe a clean execution repository, or locate the
negative control's exact failed assertion. Control adequacy remains the accepted declaration, with

never accepts intent, and flow coverage grants no ETS exclusion authority. Rollback is additive removal
of this compiler/tool and regeneration from retained source-generation data; no intent rewrite.
