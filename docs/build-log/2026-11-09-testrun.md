## V1-5256: corvint test runs selected non-Go and E2E tests through the language providers

What was wrong. The affected plan selects Vitest and Playwright files as
`typescript:<runner>:<path>` units, but `corvint test` had adapters only for Go and for a
language's declared full command. A selected file therefore named the whole declared TypeScript
command (`make ts-test` here) or, with none declared, left the run `INCOMPLETE`; it never reached
`corvint-js-test-provider`, and the receipt held no per-file result beside the Go outcomes.

The fix (`docs/specs/session-test-runner-v0.md`, `internal/sessiontest`, `cmd/corvint/test.go`):

- A third adapter, `provider`, under the unchanged `corvint-test-adapter/0` manifest. It is used
  only where `.github/cishards/test-commands.json` declares it in the new optional `providers`
  member (runner `vitest` or `playwright` to a `corvint-js-test-provider unit|e2e` argv). The
  strict read refuses another runner, another executable or subcommand, a `watch` flag, a bare
  `--` that would end the provider's flags before the appended files, and a Vitest `--dir` outside
  the repository. A declaration without the member keeps its digest.
- Planning (local profile): a selected file whose runner is declared becomes one `provider` unit.
  A file outside the Vitest `--dir`, an undeclared runner, a path that cannot be passed as one
  word and the `ci` profile all keep the declared full command, so nothing is selected away.
- Execution: one invocation per runner after the Go and declared ones, the declared argv plus
  `--test-file` per file and, for Playwright, an escaped `--test-arg` filter per file. The receipt
  document on stdout gives each unit `PASS`, `FAIL` or `NOT_RUN`; the invocation is recorded in
  the same `corvint-test-run/0` receipt and counts toward the same result and exit code.
- `NOT_RUN`: a provider that is not on PATH, has no readable version, refuses (exit 2 or 3),
  reports an infrastructure failure, a cancelled run or a stale app build, prints no receipt or
  names no test of a selected file leaves that file `NOT_RUN` with the reason in `incomplete`.
  The run is `INCOMPLETE`, exit 3, and the other invocations still run and report.
- `cmd/corvint/test.go` reads `advice.test_selection` when the plan carries it: an
  `e2e-safe-selection/1` member in a selectable state adds its files as Playwright units; any
  other member is a reason in `incomplete`, never an empty set. `corvint test` supplies no
  selection profile today, so this is forward wiring for the E2E join.
- The spec gains a "Per-language run status" table and `corvint test --help` names the member.

Limits kept visible:

- A changed Playwright spec still carries the plan's `e2e-runtime-dependency` frontier, so the
  declared TypeScript command runs beside the provider. Narrowing that is the E2E join's work.
- The Vitest subcommand runs the whole suite of its `--dir`, a superset of the selected files.
- With `--external-server`, setup files of project dependencies must be named in the declared
  argv, or the provider refuses and the unit is `NOT_RUN`.
- A declared argv that ends the provider's flags with a positional word other than `--` is not
  detected at read time; a selected file is then `PASS` only when the receipt names its tests.

Rollback: delete the `providers` member, which restores the declared full command with no code
change; to remove the capability, revert the commits from `23ccf2da3` to the head of this branch.
