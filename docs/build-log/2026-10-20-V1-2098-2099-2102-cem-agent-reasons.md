# V1-2098, V1-2099, V1-2102: CEM reasons and help that an agent can act on

Spec: `docs/specs/cem-stable-v1.md`, `CEM-V1-320..323` and `CEM-V1-340..343`. Issues:
beamfall/corvint#1330, #1331 and #1335.

## Problem

These came from agent use of CEM:

- `cem verify --hunk-revert` on a Ruby-only change printed an empty `hunks` array. That output
  could not be told apart from "nothing to do".
- `cite-span-not-stable` gave no rule and no alternative span.
- `unsupported-object-alternates` in a `git clone --shared` clone named no fix.
- `cem ACTION --help` printed the whole cem help.
- `assemble-stable` output had no `ok` member, unlike the other envelopes.
- `cem cite` on an assembled stable map refused with `unsupported-spec`, although `cem/1.0` is
  supported.

## Decisions

- **`notAttempted` is a new trailing member.** `hunks` and the counts keep their candidate-only
  meaning, so existing readers stay correct. Each map hunk appears in exactly one of the two lists.
  Its reason is the first match in a fixed precedence: test-only, language, disposition, patch
  membership, test claim.
- **Refusal codes are unchanged for #1331.** Only the message text grows:
  - The cite guidance classifies at most two candidate spans with the stable classifier, so it
    never names a span that would refuse.
  - The alternates fix strings live in `internal/cem/gitauth`, not `cemcode`, because every
    `cemcode` constant is registered as an error code and admitted as a dogfood reason.
- **`not-a-producer-map` covers every Core stable-mutation refusal.** All of them go through the
  shared `stableMutationRefusal`: cite, mark, cover and discriminate inputs, writer destinations,
  and prepare backups. Narrowing the new code to `cem cite` alone would have given one condition
  two codes.
- **Per-action help is projected from `cemHelp`.** The two cannot drift. `cover` and
  `discriminate` became registered help choices. `verify-stable` and `gate-verdict` own their argv
  before the help router, so they are left out.
- **`ok` is spliced at command level.** The internal result structs and their decoders are
  untouched, which leaves the concurrent receipt-labelling lane (#1328) free to change them.

## Limits

The guidance names only the nearest unedited run above and below the span. `corvint help cem ACTION`
is not a topic.
