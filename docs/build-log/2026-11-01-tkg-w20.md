## Decisions

- V1-3958: reversing the CAL-V0-250 clause is safe because only an exact digest match replays. A
  changed payload, actor, role, target or revision still refuses REQUEST_ID_CONFLICT. Batch and
  multi-target verbs already print their shared issuedAt and are unchanged.
- V1-3940: `failurePattern` is optional, so a policy without it keeps today's policy digest and bytes.
- V1-3941: each beat is an ordinary HEARTBEAT lease write by the gate run's actor, so no new
  authority is added. A supervised or fenced attempt refuses the beat, and beating then stops
  quietly. The gate program itself still runs outside the writer lock.
- V1-3948: enforcing these fields is an owner policy decision. The live `.taskman/policy.json`
  sets `reviewLane.required: true`, so refusing that value would break the live store. Options:
  (a) reserved plus a warning (built); (b) enforce reviewLane/docsLane as required review/docs
  lanes before complete, and cemRequired/ocmRequired as a CEM/OCM binding before complete;
  (c) remove the fields in `taskman-policy/1`. Recommendation: keep (a) until a spec defines
  (b) per field. Note that (b) for cemRequired would duplicate the dogfood seal gate.
- V1-3669: no verb reads an arbitrary receipt's post-state, because `receipt show` and
  `receipt replay` are OmittedVerbs that answer NOT_RUN. That missing capability is the likely
  source of the friction report, and it is filed below as friction, not as a defect.

## Friction

1. zsh `echo =====` fails with "==== not found" (the `=` expansion). Expected: a separator prints.
2. `corvint-tasks ticket show --json` nests the fields under `items[0].record`, and the description
   text lives in `body` and `acceptanceCriteria`. A naive parse of `description`/`acceptance` prints None.
3. `git grep PATTERN REV -- path -A3` refuses ("option must come before non-option arguments").
4. corvint-tasks-agent-leases-v0 is over the 256-ID limit, so CAL changes go to companion
   prefixes (TCL, LGL, TCD).
5. A python heredoc inside single-quoted `ssh '...'` breaks on `'''`. Workaround: scp a script.
6. `.github/cishards/test-slices.json` pins test names. `TestCALV0250_DefaultedIssuedAtRetryNamesTheDifference`
   now asserts a replay, but it cannot be renamed without touching off-limits `.github/`. The new
   tests are not in the slices; whether the drift check flags them is unknown.
7. On WSL lanes, `corvint-tasks ticket show` refuses because the journal is absent, so tickets
   have to be read on the Mac.
8. `corvint affected` reports DEGRADED self-binary-stale on the lane (a WSL binary built at BASE),
   and the selection goes UNKNOWN on LANGUAGE_FRONTIER.
9. Missing capability: `receipt show` and `receipt replay` are NOT_RUN OmittedVerbs, so no CLI
   verb reads a recorded step's post-state by seq or request id. Only a same-request-id retry
   reads it (V1-3669 context).
