## Review dispositions (Codex, e9a5d6c80..f319d042a)

All five findings were fixed. Each fix has a focused regression test, and each test was seen
failing with only its own fix reverted.

1. P1, a vanished cite text was kept at its old coordinates. Fixed: `repinLines` now returns a gone
   reason when the prior bytes do not resolve, or do not occur exactly once at BASE. The carry
   then emits an `insufficient-evidence` unknown with a `[stale: cited PATH SPAN, review]` NOTE,
   which is never re-pinned or marked used. Test: `TestProposeCitationsDCWV0842VanishedCiteRowGoesUnknown`.
2. P1, the map BASE was assumed to be the plan BASE. Fixed: the map's baseRevision becomes the
   prior BASE only when the citation-plan binding records this `--refresh` plan against exactly
   that map's hunk IDs. Otherwise, NOTE `refresh-base-unproven` prints, and cite rows are carried
   as written for the vet. `--from-cem` keeps the CEM base. The DCW-V0-842 merge test now writes
   the binding the real bind leaves. Test: `TestProposeCitationsDCWV0842UnboundPlanIsNotRepinnedFromMapBase`.
3. P2, the vet refused `bytes:START:END`. Fixed: `citeRefusal` accepts both span forms and derives
   BASE lines for the removed-lines check. `repinLines` re-pins a byte row by bytes. Test:
   `TestProposeCitationsDCWV0842ByteSpanRowIsRepinnedAndVetted`.
4. P2, a `no-evidence` reason from `--from-cem` failed validation. Fixed: any reason other than
   insufficient-evidence or conflicting-evidence becomes `insufficient-evidence`, with the CEM's
   reason kept in the NOTE. Test: `TestProposeCitationsDCWV0843NoEvidenceUnknownIsAPlanRow`.
5. P2, unresolved reasons were skipped on early `--repin` exits. Fixed: they print before the
   refused, unstaged and non-convergence exits. A rerun pass recomputes them. Test: case 39 of
   `script/check-line-citations_test.sh`, a refused dirty document beside a deleted citation.

Callers of `--repin` exiting 1:

- `script/repin-use-case-receipts.sh` never runs `--repin`.
- `script/repin.sh` (`set -eu`) runs it last. Its exit status becomes the script's, and the
  header already says the final check names what is left for a person.
- `script/batch-regen.sh` `citations` and `changed_citations` now FAIL their step and stop the run,
  with changes staged and nothing committed, as its header specifies. Re-anchored `--changed`
  spans carry "--repin rewrites it" and are not counted as unresolved. Before this change, the
  same rows passed regen and then failed line-citations-check.

No caller was changed. `repin_test.sh` and `repin-use-case-receipts_test.sh` pass. The spec text of
DCW-V0-842 and DCW-V0-843 was amended to match. The shared `propose.go` change is one guarded
branch in the map-base-mismatch path.
