# V1-0632 S2 stable report and MCP preview

Date: 2026-10-11. Base: S1 head `5871c380a` (`claude/cem1-consumers-s1`, under independent review).
Scope: the second consumer slice of the CEM 1.0 plan. `cem report` (JSON and Markdown), the report
preview and MCP `corvint.cem.report` now read an exact `cem/1.0` map through the stable verifier.
Proposed requirements `CEM-V1-029..031` (`docs/specs/cem-stable-v1.md`) and `MCPV0-036..037`
(`docs/specs/mcp-server-2026-07-28-v0.md`). `CEM-V1-020..028` were left to the parallel S3/S4 lanes.

- The envelope embeds the verifier's complete 21-field result as `stableVerification`, unchanged, and
  the command exits with the verifier's code. Nothing is folded into 0.x `verification` or
  `ready-for-ci`.
- `review` (profile `cem-stable-review/0`) is a pure projection of that result. It carries per-hunk
  drift, coverage and discrimination states copied from the verifier, plus `testExecution: NOT_RUN`,
  `ocm: NOT_PRODUCED` and an explicit non-claim that a `NOT_OBSERVED` axis is not established.
  `stableResultSha256` hashes the key-sorted JSON (no HTML escaping), so a consumer can recompute it
  from `cem verify-stable` output.
- Markdown publishes for every outcome. A reviewer should read an `UNSUPPORTED` or `REJECT` review
  rather than get no file. The repository is opened for publication only after the verifier returns.
  Output resolution was extracted to `reportOutput` unchanged, so 0.x aliasing checks apply.
- Refusals: `--ocm`, `--patch` and policy ceilings refuse before the verifier runs. These refusals,
  and any stable action not yet migrated, are marked `stableRefusal`, which MCP names
  `cem-map-stable-refused`. `cem/9`, the candidate and 0.x keep `cem-map-invalid` and
  `cem-map-unsupported`.
- MCP `artifacts` is optional, uses the `map` path rule, and is resolved under the bound root. For a
  0.x map it is `cem-map-unsupported`. The task-review tools-list golden changes only by that property.

## Limits

- Help stays hidden (fork default); `cem report --help` does not list `--artifacts`.
- OCM binding of a stable result is undefined, so the stable report refuses `--ocm` (owner fork).
- On host Go 1.27.2 the public sealed positive fixture is the verifier's `UNSUPPORTED`
  (structural runtime). The ACCEPT/`stable`-drift assertions run only under a local Go 1.27.1
  toolchain, where they passed.
- S1 is under independent review. This branch sits on its head and must be rebased if S1 changes.
