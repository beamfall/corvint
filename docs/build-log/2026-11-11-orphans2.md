# Remove the orphan package `internal/docviews` (V1-4804)

Owner decision R33 (2026-11-09, `docs/specs/PRODUCT-PLAN-1.0.md` row O42) deletes orphaned code
and tracks it in a table. V1-4804's other orphan packages were removed earlier; this change removes
the last one it names, `internal/docviews`, which the source-removal verdict table lists as
removed (`docs/specs/openspec/changes/source-removal/path-verdicts.md`). It adds no capability and
no requirement ID.

## What was deleted

`internal/docviews` (six files: `compile.go`, `types.go`, `verify.go`, `compile_test.go`,
`verify_test.go`, `benchmark_test.go`), the pure-core compiler and verifier of the experimental
Cross-Audience Truth Nondivergence profile (`CATN-V0`). Before the deletion,
`git grep -n 'corvint/internal/docviews' -- '*.go'` outside the package returned nothing, so no
importer existed. After it, `go build ./...` and `go vet ./...` (linux, darwin, windows) pass.

## Retention

The deleted code, its tests and its fixed truth and bundle digest vectors (in `compile_test.go`)
stay retrievable at commit `4c3c203336a6cc4a9772af39b1a771f34236138e`, which the retired spec
names as its `Retirement base:`. No benchmark result or other evidence file was deleted.
