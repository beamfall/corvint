## New on main: GOC-V0-008 shell-scan failure (stopgap here)

`make no-python-runtime-dependency-test` fails at `63384e26`. The ASD-V0-834 and ASD-V0-836 groups
added by `03c4a6f02` and `10435b358` call `python3` from `script/lane-scripts_test.sh`, and every
`script/*.sh` file is a scanned build/test path.

- Decision: move both groups unchanged into the operator tool's own Python test,
  `script/lane-transcript-metrics_test.py` (`SessionTests`). They keep the same fixtures and
  assertions. A Python tool's behaviour belongs in its Python test, which no gate path runs.
  Neither exempting `lane-scripts_test.sh` nor adding a Go port of the tool would be a smaller
  change.
- This is a stopgap that accepts the review finding: it clears the `script/*.sh` scan behind the
  nightly failure but does not make the Python operator tool itself GOC-V0-008 compliant. The full
  port is tracked by V1-3849.
- The ASD-V0-834 and ASD-V0-836 acceptance and rollback rows in
  `docs/specs/corvint-self-development-v0.md` now name the Python test cases.
- Rollback: restore the two groups in `script/lane-scripts_test.sh` and drop `SessionTests`. This
  reintroduces the shell-scan failure.
