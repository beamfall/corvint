# Lane doc-u14 (wave 14): documentation audit findings

Lane `doc-u14` on the Unraid host, branch `claude/lane-doc-u14-1101` from `origin/main`
`e9a5d6c803cb0a1cce3d4eebf74ab1da84dcd4e1`. Requirement IDs come from the lane block 630-639 in
each governing prefix: SDD-V0-630..634, DCG-V0-630, UCV0-630 and DCI-V1-630. Each spec amendment
is its own commit before the implementing commit.

## Decisions

- V1-3719 (SDD-V0-630): a draft whose owner spec does not name the drafted package is labelled
  `OWNER_UNRELATED`, so a draft never reads as owned by an unrelated spec.
  Test: `TestSDDV0630OwnerRelationLabelsUnrelatedOwner`.
- V1-3717 (SDD-V0-631): Go entries carry their doc comments, struct fields and the package doc,
  and provenance prints once per file instead of once per entry.
  Tests: `TestSDDV0631DeclarationsCarryDocCommentsAndFields`, `TestSDDV0631ProvenanceOncePerFile`.
  AC3 ("no larger than `go doc`") is NOT MET and is infeasible as stated. Measured on
  `internal/doccompiler`: the draft is 18,186 B (22,119 B before this change), `go doc -all` is
  11,796 B, and the cited source excerpts alone are about 13.6 KB. The excerpts are the draft's
  evidence, so they stay.
- V1-3718 (SDD-V0-632): declarations and importers are paged 64 per list. A list cut on a page gets
  a `TRUNCATED:` limitation naming the span shown and how many entries are UNKNOWN on that page.
  The page count is the larger of the two lists' page counts. `corvint docs draft --page N` takes
  1..9999, and a page outside the draft's range is refused with `documentation-limit-exceeded`.
  Tests: `TestSDDV0632PagesOverSixtyFourEntries` (110 declarations), `TestSDDV0632ImportersCountSeparately`
  (71 importers), plus `--page` refusals in `TestDocsCLIRefusalsAndHelp`.
- V1-3721 (SDD-V0-633):
  - `--owner-section HEADING` drafts against a foreign spec's named section. It needs exactly one
    literal `## HEADING` outside fenced code, and the section is limited to 64 lines.
  - `corvint docs citations check [PATH...]` is a native port of the line-citation anchor check,
    in the new package `internal/doccitations`, which reads the Git index through `gitrun`.
  - On this repository it checks 1711 citations in 1084 documents in 0.4 s. It agrees with
    `script/check-line-citations.sh` on the draft.go drift that both caught.
  - Tests: `TestSDDV0633OwnerSectionDraftsWithoutAgentDigest`, `TestSDDV0633CitationsCheckForeignRepository`,
    `TestSDDV0633DocsCLIOwnerSectionAndCitationsCheck`.
  - The help text change regenerated `internal/capcatalog/catalog.json` (`make capability-catalog`).
- V1-3720 (SDD-V0-634): the `docs maintain` help and the `internal/docmaintain` package doc say the
  human documentation compiler "remains partial", as `docs/specs/INDEX.json` records. The drift test
  `TestSDDV0634MaturityStringsMatchSpecIndex` matches each `docs/specs/X.md remains <state>`
  statement against INDEX.json delivery. A negative run with "not-started" fails it.
- V1-3723:
  - `docs/DOCUMENTATION-CORPUS.md` now hosts a docs maintain insertion point, and the first real
    `corvint docs maintain --apply` wrote the generated `internal/docmaintain` block (460 lines)
    into it.
  - Receipt (`corvint-docmaintain-receipt/0`, applied true):
    - commit `b22d121eb66bfeaf37bb6b77e1a86513045fde5e`, tree `529dcb073b863bd182ec376d9baaf3ecb5a91c22`
    - new source digest `34de78b9d1cce6c3b58d805807fee955dfe3043ebcb05a33be19b07a346d8f6e`
    - page digest before `14dc92d4dcf660d53ca6e93ed4f4e47ec63b6eeff4b685e9cc301a3516c10b4e`
    - page digest after `2203f286a177891de5b86c71ad93e2d07b1ff21f9846b149975348e1341f7c7b`
  - A second preview reported the block not eligible, skipped as `unchanged`, so the apply is
    idempotent.
- V1-3722 (DCG-V0-630, UCV0-630):
  - `script/check-line-citations.sh --repin --show-changed` prints each changed span's old lines
    (at the base) and its mapped lines (in the index), then writes the new anchor only on a `y`
    answer.
  - The script's Perl program arrives on standard input, so the caller's answers are passed on
    descriptor 3. That is the smallest change to the script (owned by cit-w12): the flag, one
    prompt loop, and a list return from `diff_suggestion`. Only the first `--repin` pass prompts.
  - Use-case receipt subjects may carry `lines` (`"N-M"`) or `symbol` (one top-level Go
    declaration), so an edit elsewhere in a subject leaves the receipt current.
    `script/repin-use-case-receipts.sh` repins a symbol subject by
    `go run ./conformance/use-cases-v0 -subject-digest PATH#SYMBOL`, and refuses to repin a span
    whose own lines changed.
  - Existing receipts are unchanged and still whole-file; all 18 stay current.
  - Tests: case 36 of `script/check-line-citations_test.sh`, `TestUCV0630SpanAndSymbolSubjects`,
    case 10 of `script/repin-use-case-receipts_test.sh`.
- V1-3762 (DCI-V1-630): the corpus Git budget refusal reads the bound from gitrun's own refusal
  (`at its N-operation bound`) instead of formatting `gitrun.DefaultOperations`. With no bound in
  the refusal, it says `Git operation budget exhausted`. With one pinned revision a 1-operation
  bound verifies (one batch per checkout, DCR-V1-975), so `TestDCIV1630BudgetRefusalNamesBoundInForce`
  proves bound 1 through gitrun's real refusal from a spent 1-operation budget, and bound 0 through
  `verifyPinnedRevisions`. The requirement was first written as DCP-V1-630, but the parent
  spec's Requirements section is at the 256-obligation OCM bound and a definition outside that
  section is refused by `make spec-requirements`, so it lives in the inventory companion
  `documentation-corpus-inventory-v1.md` as DCI-V1-630.
- Gate repairs found by `make doc-gates`: SDD-V0-633 now names `citations-check-failed`, the exit-2
  code of `corvint docs citations check` (error-code ownership); `internal/docmaintain` declares its
  repository-root reads (`cmd/corvint/`, `docs/specs/INDEX.json`) in
  `.corvint/test-read-scopes.json`; package names inside test fixtures in
  `internal/doccompiler/draft_test.go` and `internal/docmaintain/blinded_test.go` carry
  `//corvint:fixture-path`. Declaring the docmaintain scope also brought the base-era
  `blinded_test.go` under the check for the first time.

## Friction

- `corvint impact` had no index snapshot in the lane worktree, so pre-change impact reads fell back
  to reading source.
- The corvint MCP plugin failed to connect (`CONNECTION_CLOSED`) for the whole session.
- zsh on the first ssh call read `echo ====` as an `=`-expansion command (zsh `EQUALS`).
- V1-3717 AC3 ("no larger than `go doc`") cannot be met while the draft carries source excerpts as
  evidence.
- A help-text change silently requires `make capability-catalog`, and the resulting
  TestMCPV0100/TestMCPV0105 failures do not name that target.
- Every `internal/doccompiler/draft.go` edit breaks pinned citations in
  `docs/specs/human-documentation-compiler-v0.md`, so `--repin` follows each code edit.
- The `docs maintain` preview "diff" prints the whole page as context rather than hunks.
- The lane ticket JSON keys tickets as `ticket:corvint:main:V1-xxxx`, not the bare ID.
- `script/check-line-citations.sh` reads its Perl program from standard input, so any interactive
  or piped input to the script was impossible until descriptor 3 carried it (V1-3722).
- Case 30 of `script/check-line-citations_test.sh` leaves `internal/demo/demo.go` unmerged at the end
  of the fixture, so any case appended after it must first restore the index entry.
- The OCM 256-obligation bound fails late: a new requirement in a full spec passes
  `make spec-requirements` and fails only `TestSpecsStayWithinTheOCMObligationBound` in
  `make doc-gates`, and moving it to a new section in the same spec is then refused by
  `make spec-requirements`; the only route is a companion spec with another prefix.
- `make doc-gates` error-code ownership flags a new code (`citations-check-failed`) only at the
  final gate; nothing earlier in the lane (focused tests, spec-requirements) reports it.
- Adding a package's first entry to `.corvint/test-read-scopes.json` puts every existing test file
  in that package under the check at once, so unrelated base-era fixture strings fail it.
- `heavy.sh` refuses a whole-package `go test` without `-run` (`whole-reason-missing`), even for a
  0.03 s package.
