## Cause shared by V1-3580 and V1-4099

`script/batch-precheck.sh` runs each step through `tools/gate-ledger` as `NAME+SALT`. A salted
step whose NAME has no `scopes` entry keys on the whole tree (GL-V0-051), so the post-seal
precheck, whose tree differs only by a new CEM and a build-log entry, missed both checks. The fix
declares each step's real inputs. Those are the lists batch-precheck already names (ASD-V0-944,
ASD-V0-051), plus two new scope forms: `@go` for every Go build input, embedded and `testdata`
files included, and `@root` (GL-V0-600, GL-V0-601). The salt, which covers the command and every
`GO*`/`CGO_*`/`CORVINT_*` variable, and the toolchain identity stay in every key. `tooling` adds
`Makefile`, `go.mod`, `go.sum`, `script/` and `tools/`, which covers each checker's own source.
