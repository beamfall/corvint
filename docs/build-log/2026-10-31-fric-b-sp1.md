## Codex review round (one round, three P2 findings)

- HOLD retry (TCD-V0-967): a hold reads each target's revision itself, so after one target landed
  a retry read the incremented revision, changed the mutation digest and refused
  `REQUEST_ID_CONFLICT`. `landedRevision` looks the request ID up in the journal's request index
  and, for a completed request, reuses its original expected revision (resulting revision minus
  one; every ticket mutation advances the revision by exactly one). The writer's digest still
  refuses a retry whose other inputs changed. This covers single-target and multi-target holds.
  `TestTCDV0967_InterruptedMultiTargetHoldResumes` fails without the fix.

  backslashes; it now compares the decoded warning text.
- Rollback exclusion (SRG-V0-966): the generator's out-of-section check (SRG-V0-891) and
  `check-requirement-definitions.sh` still counted a bulleted or unbulleted rollback restatement.
  Both now skip lines under a Rollback heading. The definition checker's test generates
  REQUIREMENTS.tsv with the real generator and then checks it, and fails without the fix.
