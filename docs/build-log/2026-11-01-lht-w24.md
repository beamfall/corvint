# 2026-11-01 lht-w24: lane-host tooling and disk

BASE=c605450399873cca71193213c5aa4d3f7e43624b (origin/main at worktree creation on wsl-lanes),
branch `claude/lane-lht-w24-1101`. Tickets: V1-3817, V1-3816, V1-3061, V1-3262, V1-2904, V1-3824.

## Problem

Lane hosts ran out of disk on a tmpfs `/tmp` (WSL: 16 GB tmpfs, 93% used at closeout) because Go
build caches and test temp trees defaulted there, and heavy.sh only warned. Lane dispatch inputs
(BASE, build-log name, ticket bodies) were retyped by hand per lane, which produced base and
build-log drift, lanes started from the host primary checkout, and lanes on hosts without the
Tasks journal could not read their tickets.

## Decisions

- Requirement IDs: the dispatched block 1060..1079 has four digits, but the generator, the OCM
  regex and `script/requirement-ids-free.sh` accept three only. Mapped to ASD-V0-061, 062, 063,
  065, 066, 067 (block minus 1000; 064 was already used). Each was checked free on origin/main
  with `git grep` and `git log origin/main -S`.
- New IDs sit on their own definition lines only; the frozen Intent status lines (5 and 12,
  `docs/specs/INTENT-STATUS-FROZEN.tsv`) are unchanged.
- heavy.sh on a tmpfs `/tmp` defaults GOCACHE and TMPDIR under `${XDG_CACHE_HOME:-$HOME/.cache}`
  (ASD-V0-061) and refuses below `HEAVY_REFUSE_FREE_GB` with one cleanup hint (ASD-V0-062).
  go-cache-trim adds the `corvint-tmp` root (ASD-V0-063). Nothing outside the worktree was
  deleted and no host configuration was changed.
- New `script/lane-dispatch.sh`: `inputs` writes lane.env, brief-header.md and plain-text plus
  JSON ticket bodies, optionally copied to `~/lane-inputs` on a host (ASD-V0-065); `check`
  refuses a brief whose BASE or build-log name differs from lane.env (ASD-V0-066); `base-check`
  refuses a shared primary checkout, a BASE that is not an ancestor, a HEAD ahead of BASE with
  `--fresh`, and commits from another local lane branch (ASD-V0-067).
- Build-log shape unified to `docs/build-log/YYYY-MM-DD-<lane>.md` = `BUILD_LOG` from lane.env.

   `COPYFILE_DISABLE=1`.

   heavy.sh at host load about 50; passes run directly.

    although the Mac store has it.
