## Decisions

Go serial test windows use scratch source overlays, including cleanup, atomic
counter reset/dump and early metadata initialization for test binaries. An
order-only block retains its test and preceding prerequisites. A third unrelated
test demonstrates narrowing beyond the suite union. Parallel tests, examples,
fuzz entry points and packages without instrumentable source retain the named
union fallback. Setup, teardown and child coverage retain a residual union owner.
The checkout is never rewritten by collection.

The Go launch observer lives in the scratch os/exec overlay. It rejects missing
coverage metadata and unexpected destinations, and gives each covered launch its
own counter directory, so one completed child cannot hide another missing dump.
The overlay propagates through child builds. Build tools are distinguished from
test subjects; unsupported tool launchers conservatively reject records. This is
an os/exec observation boundary, not a security sandbox or qualification of raw
syscall launch paths.

The existing records-list `linecov.Build` was already language-neutral. Ruby now
uses it directly; public file, block-by-line and tests-of-file lookups serve both
Go and Ruby analysis. `linecov.Load` validates command-produced indexes. Index
merging preserves deadlines and collection identities and rejects mismatches.
Qualification passes the recorded test deadline and refuses unknown legacy
values, rather than silently substituting another timeout.

Ruby collection adds an isolated process for every ordinary-order outcome and
unions both reaches only after exact identity/status comparison. Environment
clearing and non-Ruby children leave unmatched launch tokens and cannot produce
complete records. Forks, popen/backticks and unobservable replacement processes
conservatively remain incomplete. Failed exec cancels its marker. Load/eval
execution joins the load bucket; uncalled method edits and changed test files
fall back. Data-driven test-unit cases have distinct identities. Rails workers
remain conservatively incomplete, without an exclusion claim.

Explicit `ruby-collect`, `ruby-select`, `js-collect` and `js-select` commands
provide the shared index and analyzer path, help/examples, a generated command
snapshot and capability rows. Candidate counts distinguish coverage selection,
static fallback and exclusion, including files whose every test is selected by
coverage. Effective language execution remains static: these bounded experiments
do not satisfy the 1,000-change promotion gate.

`watch` is foreground and event-driven. Linux directory events support ordinary
and atomic editor saves; editor stdin events and one-shot execution cover other
hosts. Every save reanalyzes staged, unstaged and untracked changes against the
recorded commit, including ignored Go source that the compiler would still read.
Failures stream without terminating the next-save workflow. Every observation
states user scope and false CI gate eligibility. Native Windows/macOS events
remain unavailable rather than being emulated by a permanent polling service.

## Dogfood and boundaries

Used: start-of-change dogfood, prechange context/query/impact, dirty-diff affected
selection, common immutable index construction, native runner qualification,
CEM/OCM review and final local binding/check. Query/context/impact receipts remain
bound to the base and their original task; no rewording hid omissions. Retrieval
ranking, trace learning, learned weights, browser providers and external service
profiles were not changed; their frozen evaluations are not applicable.

NOT_RUN: repository-wide gate and exhaustive tests, by the lane charter; the
known BASE failure in batch-precheck is untouched. Independent review is owned
by the orchestrator. NOT_PRODUCED: production exclusion admission, the
1,000-change promotion campaign, general runner/OS parity, comparative cost or
cache benefit. The bounded shadows cannot substitute for those claims. No push,
pull request, Tasks write, release or seal belongs to this lane.

Rollback removes the developer command/watch additions, restores conservative
suite-union attribution and whole-file language fallback, and rebuilds derived
indexes. Missing/legacy deadlines refuse qualification until recollected. No
existing repository or CI gate is weakened.
