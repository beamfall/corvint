## Semantic reconciliation after the merges

The focused suites showed conflicts no textual merge reported. Each was repaired in
`29e68ebe2`, and AZU-V0-005 was amended in `6793df767`:

1. Under AZU-V0-005, fullplan's fixtures that expected nested hidden and build directories
   below `.github` to stay out of the graph now expect them indexed. A missing planned helper is
   refused by `go list` itself, since that package is now also listed explicitly; the refusal
   text changes, but the refusal does not.
   A missing `.github` directory adds no enumeration pattern instead of failing discovery.
2. The general hidden walk made the Go plugin index `.agent-evidence/*.go`, which AZU-V0-9921
   declares non-source. In `TestFullplanReplay_AZU_V0_9920_9921`, every plan went FULL with
   `go:unparsed-source`. Declared output now takes precedence below hidden or underscore
   directories in both the planner (`affected.DeclaredNonSourceHolds`) and the gate selector
   index. Paths outside hidden directories keep their existing treatment.
3. The shared walk validates every file name (`acceptEveryName`), so an unrepresentable name
   anywhere in a newly walked hidden directory refused every plugin. That broke main's
   `TestOwnershipInvalidUTF8Membership_AZU_V0_9900`, which relies on `.metadata/` not being walked.
   The walk now defers such a name only below a hidden directory. A plugin that claims the name
   still refuses (`TestHiddenUnrepresentableNames_AZU_V0_005`).
4. `TestPrecisionReplay_AFPV09003` (main) bounds the language units a `script/heavy.sh` change
   selects below 86. Selection was measured with `affected --worktree --path script/heavy.sh`:
   main selects 80 non-driver units and the merged head 95. That is 14 Go `PATH_LITERAL_READER`s
   from AFP-V0-2203 round 8, which deliberately drops Go placement (a lone `"script"` token
   names the `script/` directory at any depth), plus `.github/cishards` (BINARY_EXEC) from
   AZU-V0-9920. The accepted spec governs. The bound is now below 100, with the measurement
   recorded in the test. This loosens a main-side precision guard and is flagged for the
   owner's review.

Each new or changed regression was observed failing without its fix: the gate selector's
declared-output check, the planner's declared-output filter and the hidden-name deferral.
