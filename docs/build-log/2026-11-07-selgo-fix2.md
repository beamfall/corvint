# Selection: a narrower reader match never masks a record walker (review fix round 2)

Date: 2026-11-07
Lane: selgo (branch `claude/sel-go`, base `4052b8540`), review fix round 2 after
`2026-11-07-selgo-fix1`.
Ticket: V1-4933. Requirement: AFP-V0-2748 in `docs/specs/affected-plan-selection-v0.md`, which
amends AFP-V0-2747.
Owner goal: never fewer tests than needed.

## Finding

The fix-only review marked both round-1 findings fixed. It raised one new P1 in
`Graph.RecordReaders`.

- When a package also had a constrained glob that matched one of its probes, the glob set `reads`,
  and the package was classified only as a reader. Its walker status was lost.
- Example: an undeclared test package in `reader/` walks `../docs` and reads the Markdown files
  below it. It also calls `filepath.Glob("../docs/*/2026-*.md")`.
- The glob matched the generated 2026 probe, so listing the package in
  `.corvint/record-readers.json` passed the ratchet.
- A new `docs/build-log/2027-entry.md` matches neither that glob nor the joined-literal rule. The
  package's test could therefore be skipped while its walk reads the entry.

## Decisions

- **A walker stays a walker unless selection covers the whole namespace.** `RecordReaders` now
  tries every probe and no longer stops at the first read, so a read through one probe cannot hide
  the ancestor another names.
- A package naming a proper ancestor below the root (`../docs`) is a walker unless one of these
  holds (`coversRecord`):
  - it locates the root at run time;
  - one of its tokens resolves to the record directory itself, or to the root or an ancestor
    whose other literals join the rest of the way (AFP-V0-2746);
  - one of its globs matches the directory or one of its ancestors (`/docs/*`), or matches the
    directory with its leading components and admits every entry name with its last one
    (`globCoversRecord`).
- **A probe hit is not proof of coverage.** The fixed probe `ffff…f.md` is itself matched by narrow
  patterns such as `[a-f]*.md` or `[0-9a-f]*.cem.json`. Coverage is therefore decided by the kind of
  resolution (directory or joined ancestor, not a fragment or an entry name), never by one
  synthetic name.
- A token must also name two entries that share no leading or trailing rune before the suffix.
- **`globCovers` is `globEntry`'s complement.** It searches the subsets of `path.Match` items a name
  can have reached, crossed with the suffix and length state, for an entry name the pattern does not
  match. It reports coverage only when none exists.
- The search alphabet (`globAlphabet`, now shared with `globEntry`) adds each class bound and the
  runes just outside it. A run of runes a class tells apart then always has a member, even when no
  rune of the pattern lies in it: `[\x00-\x05\x07-\U0010FFFF]*` misses `\x06`, and
  `[\x00-퟿]*` misses everything above the surrogate block. This only widens `globEntry`'s
  witness search.
- **`internal/gateselect` needs no change.** It has no record-walker classification and no glob
  model. The ratchet (`tools/unbounded-readers`) reads only the planner's graph, so the
  classification is decided once for both selectors.
- `TestRecordWalkerWithGlobSkippedByBothSelectors_AFPV2748` shows, on real Go source, that neither
  selector selects the walking-and-globbing package for `docs/build-log/2027-entry.md`. That is why
  the record must not admit it.

## Effect on the repository

- `make unbounded-readers-check` passes with the unchanged baseline record: no package on the real
  tree was a masked walker.
- Selection itself is unchanged. `RecordReaders`, `coversRecord`, `globCovers`, `globEntry` and
  `globAlphabet` feed only the ratchet; `Select`, `resolves` and `globRead` are untouched. The
  round-1 PR #106 replay therefore stands and was not rerun.

## Fault injection

Each regression fails without the fix:

- `TestRecordWalkerNotMaskedByNarrowerReads_AFPV2748`:
  - With the walker case decided by `reads` again, as before the fix, `globwalker` and `hexwalker`
    become readers, and the test shows those "readers" are not selected for the out-of-glob entries.
  - With the class bounds removed from `globAlphabet`, `[\x00-\x05\x07-\U0010FFFF]*` is reported as
    covering.
  - With the surrogate neighbours removed, `[\x00-퟿]*` is reported as covering.
- `TestAFPV2748RecordRatchetRefusesAMaskedWalker`, with the round-1 `recordreaders.go`: the listed
  package that walks `../docs` and calls `filepath.Glob("../docs/*/2026-*.md")` passes the check
  (exit 0). The covering-glob control (`../docs/build-log/*.md`) passes once listed.
- `TestRecordWalkerWithGlobSkippedByBothSelectors_AFPV2748`, with the round-1 `recordreaders.go`:
  `RecordReaders` returns the package among the readers.

The under-selection controls stay readers, and the test checks that each is selected for an entry
outside every constrained glob:

- a lister;
- a covering glob (`/docs/build-log/*.md`, `/.corvint/changes/*.json`);
- a directory glob (`/docs/*`);
- an unanchored covering glob (`build-log/?*`);
- a root-locating package.

## Limits

- A package that walks `docs` and globs only some of its entries can no longer be recorded. It needs
  a declared read scope (AFP-V0-023) or the fixture marker. None exists today.
- Coverage is decided one token or glob at a time, so it errs towards refusal. A package whose
  narrower matches only together admit every entry (`[0-7]*.md` beside `[^0-7]*.md`) stays a
  walker and needs a declared read scope.

Rollback: revert this round's fix commit and spec commit. AFP-V0-2748's Rollback names the
functions to drop.
