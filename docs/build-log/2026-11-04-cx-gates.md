  It reads immutable commits, reuses the capacity mode's OCM section reader, and counts base IDs
  plus distinct lane additions. It reports every spec and contributing refs/commit IDs and refuses
  above 256 before any merge. Keep deleted base obligations conservatively: removal and duplicate
  definition conflicts remain the final merge/collision gates' job. This is an explicit preflight
  target, not an implicit merge or a change to OCM's bound.

  static spec phase calls the same generator mode before repins, receipt reuse or Go work.

  lane script target when `script/lane-*` differs from BASE, including committed, staged,
  unstaged and untracked paths. Invalid Git reads and failed tests refuse the check. Force the
  `all` group at the nested Make invocation so inherited group selection cannot narrow it.
- V1-4542 / SRG-V0-982: split the existing doc gate target set into sorted continuation lines.
  The fast status target checks sorted, unique, one-target-per-line shape; batch-precheck expands
  that representation while retaining its existing single-line fixture compatibility.

  family 5 owns selector, lane-selection and doc-target regressions. The default still runs all
  families. Preserve scenario comments and the earlier STATIC_ONLY alias. Real Go test commands
  in the selection fixtures go through heavy.sh one package at a time.
