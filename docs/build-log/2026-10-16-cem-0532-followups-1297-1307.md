The tool needed two extensions:

1. Cell-only re-emission. When no case value changes, `FULL-RESULT-CASES.json` and its predecessor
   stay as they are. A run with no changes at all is still refused. This closes the residual "Replace
   mode: admit a cell-only re-emission" in the 2026-10-15 entry.
2. Disagreeing cells. A cell whose verdict-matching cases disagree on a re-emitted member needs an
   explicit `--cell-values` entry. Without one it is refused rather than derived.
