## Friction

Each item gives the repro, then what happened, then what was expected.

1. **`dogfood prechange` with Makefile in PATHS.**
   - Repro: `make dogfood-prechange PATHS="... Makefile"`.
   - Actual: the whole impact receipt refuses with `unsupported-impact-path-suffix`.
   - Expected: skip or note that one path and record the rest.
2. **Inputs-check prefix mismatch.**
   - Repro: the inputs-check pre-flight with an invalid intent.
   - Actual: the refusal is prefixed `dogfood-change:` while its TIMING lines say `dogfood-inputs-check:`.
   - Expected: one prefix.
3. **ssh heredoc runs in local zsh.**
   - Repro: ssh with an inline heredoc that contains backticks.
   - Actual: the Mac's local zsh expands and executes it.
   - Expected (process): lanes ship patch scripts as stdin files. The charter could say so.
4. **`ticket show --json` nesting.**
   - Actual: the record is nested under `items[0].record`.
   - Expected: the shape is documented in the help.
5. **`".."` literal in test-read-scopes-check.**
   - Repro: one test file holding a `".."` literal.
   - Actual: every path token in the package becomes root-relative, and many unrelated tokens fail. The cause shows only in a long message.
   - Expected: name the triggering literal first.
6. **batch-regen froze a varying golden value.**
   - Actual: the next batch-precheck broke.
   - Fixed here by CCF-V1-620.
7. **batch-precheck ledger salt (suspected, not confirmed).**
   - Actual: the `env | grep` salt pipeline under pipefail yields an empty salt when no GO*/CORVINT_* variable is set, and the ledger turns off silently. Seen in the harness only.
   - Expected: a ledger that stays on, or a visible note.
8. **Mac git archive too slow.**
   - Actual: extracting the 151 MB archive took more than 180 s and was auto-backgrounded.
   - `git format-patch BASE..HEAD | git am` onto an existing clone took seconds and gave an identical tree hash. Expected: lane docs prefer this.
9. **`wsl-lanes` from Unraid.**
   - Actual: the ssh alias does not resolve from Unraid.
   - Expected: cross-host hops documented, or the alias added.
10. **Mac heavy.sh wait.**
    - Actual: it waited 120 s at load 30 for a 1.2 s build.
    - Expected: a short build bypasses the slot wait.
11. **V1-3758 lineage label.**
    - Actual: `.corvint/cem-lineage.tsv` names `beamfall/corvint-history@1c4d8793` as the retained ref. That repository returns 404 to the owner's gh account, and the commit's only ref is a Mac-local tag.
    - Expected: the label names a ref that exists remotely.
12. **dogfood-change before the bind.**
    - Actual: it exits 2 (`cem-status: not-ready`, `outcome-input-not-provided`) on every pre-bind run. A lane cannot tell whether a pre-bind run is healthy without reading the tail.
    - Expected: a one-line "expected before bind" status.
