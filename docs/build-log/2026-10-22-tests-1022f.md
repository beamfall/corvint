# Test-gap lane 1022f: VSC vectors, source-view TERM grace, Linux descriptor bound, live keep-reporters

Lane `tests-1022f`, branch `claude/tests-big-1022f`, base `f29ddc0db`. This lane covered 21 pre-1.0 test-gap
tickets. Decisions are delegated to the orchestrator (decision 0548). PWP-V0-055 is accepted under the owner's
standing auto-accept of lane requirements (2026-10-11).

## Problem

Each ticket named a test gap. Two of them hid product defects:

- **V1-2319.** The source-view cancellation witness flaked under host load. `procgroup` gave a TERM handler a
  fixed 100 ms before KILL, so the trap marker raced the kill.
- **V1-1002.** On macOS, keep-reporters qualification always returned `keep-reporters-inputs-differ`. The
  reporter compared `require.cache` keys, which are real paths, with an output root that ran through the `/var`
  symlink. So the provider's own scratch `playwright.config.cjs` and `reporter.cjs` were bound as per-run config
  inputs.

## Decisions

- **TerminateGrace seam (V1-2319).** `procgroup.Spec.TerminateGrace` overrides the 100 ms default, and a negative
  value is refused. The source handoff sets a 1-minute grace only through a test context key, so production
  behavior is unchanged. The `source_handoff.go` native digest is re-frozen (ESV-V0-005).
- **PWP-V0-055 (V1-1002).** The reporter always realpaths the output root, not only under the freshness profile.
  This is a one-line fix with a Node unit case and a live Go witness, `TestPWPV0010KeepReportersLive`. That
  witness skips with NOT_RUN unless `CORVINT_PLAYWRIGHT_MODULES` is set.
- **PWP-V0-010..013 stay `proposed`.** The live evidence is recorded in their traceability rows, but acceptance
  remains with the owner.
- **V1-1225 is evidence only.** No code change was needed. A Linux run reproduces the bounded-descriptor claim.
