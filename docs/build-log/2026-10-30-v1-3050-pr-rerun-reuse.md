# PR reruns reuse the prior run's passes — V1-3050 (TSP-V0-007)

## Question

V1-3050 asks that a PR's second CI run, after a fix to one failing package, rerun only that
package and what the fix touches, instead of the whole base-relative selection again, and that
every unproven input still runs FULL.

## Decision

TSP-V0-007 (experimental, `docs/specs/test-selection-precision-v0.md`) adds two pieces to
`tools/corvint-pr-tests`:

- `--mode prior --evidence DIR` turns one completed run's shard output directories into
  `prior.json`: the tested merge M0, its PR head and tree, the tool identity, and the packages that
  passed whole (a package-level `pass`, no `fail`, never sliced) in some shard.
- `--mode plan --prior FILE` writes `rerun.json` beside the unchanged `selection.json`: the packages
  of M1 the record does not list as passed, plus the trusted selector's `run` set for
  `corvint affected --base M0` at M1. The planner and selector step is the one `plan` uses, moved
  into `selectSince` without changing its reasons.

`rerun.json` is a separate output so the existing narrowing gate (the superset check against the
shadow selection, and its `.github` refusal) keeps its meaning until the CI wiring lands. Every
unreadable or unknown-field record, identity difference, record that does not match its merge,
non-ancestor prior head, `.github` path in M0..M1, planner or selector failure, non-`run` verdict,
missing universe, or drift runs `./...` with a named reason.

The CI wiring is a `.github` change this lane may not make (Open question 4 of the spec): keep each
run's shard directories, fetch the previous run's M0 for the same PR, build the record, pass
`--prior`, and decide from `rerun.json` with the `.github` refusal scoped to M0..M1.

## Evidence

Tests: `TestTSPV0007RerunReusesPriorPasses` and `TestTSPV0007PriorRecordFromRunEvidence`; the whole
`./tools/corvint-pr-tests` package passes with the `selectSince` refactor (75 s, Mac). A mutation
check removed, one at a time, the `.github` refusal, the ancestor refusal, the identity refusal, the
not-passed union and the slice exclusion; each made a TSP-V0-007 test fail.

Replay of the #1957 shape (estimate, not a hosted observation): run 1 failed only in
`internal/liveverify/affected`; the fix touched only `internal/liveverify/affected/graph.go`. A
one-line change to that file at `fd51f53a2`, planned by this branch's `corvint affected` and the
current `gate-affected-select`, gives a `run` verdict of 161 of 394 packages, including the failed
package, so `rerun.json` is those 161 when everything else passed in run 1. Weighted by
`.github/cishards/package-costs.json`, they are 6,419,789 of 8,887,238 ms (72.2%): the rerun saves
about 28% of a full run, roughly 69 of the 248 shard-minutes of eight shards of about 31 minutes.
The saving is small here because the changed package is imported by `cmd/corvint`, the largest
package (1,045,523 ms); a fix in a leaf package saves nearly the whole run.

## Rollback

Stop passing `--prior`; `rerun.json` is then not written and `selection.json` alone decides. No
stored state depends on it.
