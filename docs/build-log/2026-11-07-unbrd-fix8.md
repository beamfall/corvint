# unbrd review fix 8: certify self-reference unrolling (2026-11-07)

V1-4283, AFP-V0-3149 (refining AFP-V0-3147 and TSP-V0-960). The independent review's blocking
P1 is confirmed: `unset x; x=${x:-script}; x=${x:+$x/check}; "$x"` lost the reachable

`use/wrap_test.sh`. The previous shortcut accepted an entire braced expression as an identity and
removed every other self-referential assignment, including defaults that supplied literal values.

## Decision and class repair

Certify the complete set of self-referential assignments before substituting seeds. The closed
allowlist consists of plain `$name` / `${name}` identities; standalone `-`, `:-`, `=`, `:=`
defaults with literal operands containing neither `$` nor backquote; and a plain reference after
a top-level prefix whose complete bounded expansion always contains an unknown part, with only
a literal suffix. Preserve every allowed default operand alongside non-self values and the
unknown earlier value. References inside command substitutions/backquotes are excluded from
recursive references because the existing expander treats their results as opaque. Keep same-depth expansion for certified forms, as required by AFP-V0-3149.

Everything outside that allowlist retains `shell:dynamic-source` protection, including composed
alternatives and unsupported transformations, even when they would not recurse to a numerical
bound. This is a certification rule, not a list of forbidden operators. No wire, diagnostic,
golden, core-freeze output or existing assertion changes. A rollback must preserve the conservative
cut; reverting to unchecked unrolling would restore the soundness gap.
