## Review repair (round 1)

Eight review findings, all accepted, each with a `make lane-scripts-test`,
`agent-preflight_test.sh` or `batch-precheck_test.sh` case that fails on the prior head:

- `ASD-V0-640`: `benchmarks/retained-data.tsv` is a lane-scripts-test input, since the
  `ASD-V0-646` group validates it; a manifest-only change no longer skips the step.
- `ASD-V0-641`: `check-test-script-refs.sh` lists tests with `git ls-files -z` into a file, so a
  failed listing exits 2 and a name Git would quote is scanned. It matches the full file name, so
  `exists.sh.bak` is checked as itself. The real tree still has 333 resolving references.
- `ASD-V0-643`: the landlock row is `UNKNOWN` when the temporary directory cannot be made, instead of
  a `set -e` abort. It is also `UNKNOWN` when the probe's exit disagrees with its ABI line (test-confine exits 0
  at ABI 2 or more, 1 below).
- `ASD-V0-645`: an empty `ticketId` or one holding a control character exits 2, because a tab or
  newline would shift the path out of its TSV column and hide an overlap.
- `ASD-V0-646`: the digest fails closed (exit 2, no counts printed) when the byte count or the
  listing hash fails. The digest algorithm is unchanged.

The V1-2761 row now carries `sha256`, `files` and `bytes` from a `retained-data-digest.sh` run on
wsl-lanes, relayed to this lane. This lane did not observe that run: Unraid still cannot reach
wsl-lanes. `producing_commit` stays `NOT_OBSERVED`, because no record names the producing commit.
