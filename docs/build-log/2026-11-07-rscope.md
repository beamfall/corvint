Ticket: V1-4993 (lane rscope). Requirements: AFP-V0-3010 and AFP-V0-3011 in
`docs/specs/affected-plan-selection-v0.md` (the parent `affected-plan-v0.md` is at its

## Finding

At the base, 25 of the 219 packages in `.corvint/test-read-scopes.json` declared `internal/`,
`cmd/`, `script/` or `docs/` (26 counting `tools/ci-forward-row`'s `.github/`). An entry naming a
top-level tree selects its package for every edit below it (`DECLARED_READ_SCOPE`). Nothing
asked why a tree was declared, and nothing checked whether a narrower declaration would hold.

## Method

For each of the 26 packages:

1. Trace. The package's tests were compiled with `go test -c` and the binary was run from the
   package directory with `GOFLAGS=-buildvcs=false`, as the confined shard runs it. A scratch
   inotify watcher (outside the repository) recorded every `IN_OPEN`, for files and directories,
   below the root except `.git`. Controls: a `sleep` records nothing, and `cat go.mod
   internal/cem/verify/guards.go` records exactly those two paths. The first attempt recorded
   1300 directory opens from the watcher's own setup walk, and with VCS stamping left on a
   further whole-tree `git status` walk appeared. Both artifacts were removed before any
   result below.
2. Static reads. `test-read-scopes-check` was run with every whole-tree entry removed. Its
   findings (test-file literals, plus the import closures of the literal `go list` and
   `go build` targets it models) give a lower bound that also covers darwin-only and opt-in
   tests a Linux run skips.
3. Code reading. Each package's tests, and the tool code they run on the repository, were
   searched for `filepath.WalkDir`, `os.ReadDir`, `filepath.Glob`, `os.Stat` on data-derived
   paths, and builds through helpers or variables. Landlock does not mediate a `stat`, and the
   trace cannot see one.
4. Narrow only where every read is a literal or a modelled literal-target closure (AFP-V0-3011).
   Then run the check, and the package under the AFP-V0-023 wrapper
   (`.github/testconfine/cmd`, Landlock ABI 7 on this WSL host).

Decision on the `cmd/corvint` closure readers (clause (4)). The closure is bounded by a literal
the check models, so narrowing would be sound. It covers 166 of the 313 package directories
below `internal/`, in 121 of the 185 top-level directories. Declared exactly, that is 140 subtree
entries per package, about a dozen packages share it, and every new package `cmd/corvint` comes to
import would have to be added to each of them. The gain is small: of the last 77 first-parent
merges on origin/main that touched `internal/`, 7 touched only directories outside that closure.
This lane therefore keeps `internal/` for these packages and records the reason. Over-selection
is the accepted cost, and no read is lost. The guards.go example below shows why these
packages stay selected for that edit: `internal/cem/verify` is in the closure, and `go list
-deps` parses every file of it.

## Residuals and follow-up

- A whole-tree reason is a reviewed statement. The check proves only that one exists and that it
  begins with a tracked file.
- The trace sees opens on one Linux run. `stat`, darwin-only files and opt-in tests are covered
  only by code reading and the static check, so any doubt kept the tree.
- Idea: an entry form that names a build target (the closure of `./cmd/corvint`), computed by the
  planner, the check and the wrapper alike. It would narrow the clause (4) packages without
  repeating 140 entries in each.
