## Decisions

- **Report publication (V1-4573, V1-4488).** pk-dogfood (DCW-V0-7409), v1fix-a (DWC-V0-929)
  and cx-dogfood (DWC-V0-048) each carried a different fix. Main had meanwhile landed
  DTL-V0-016, which stages the report beside its destination, so the cross-device rename cannot
  happen. All three lane publishers, with their tests, ignore patterns and clauses, are dropped as
  superseded. Main's build logs had expected v1fix-a's clause to land; DTL-V0-016 replaces it.
  Report-mode preservation, part of v1fix-a's acceptance, is not carried over (the report becomes
  mode 0600), so V1-4573 is PARTIAL.
- **Static pre-check binary (V1-4406, V1-4466).** Main's 85641a4a8 already ships the order: cached
  tree build, then `CORVINT_BIN` (a relative path made absolute), then the installed binary, with a
  stale-binary SKIP. lanetools' LVT-V0-010 ("CORVINT_BIN only") contradicted it, so that clause now
  defers to DCW-V0-731. dfric's DCW-V0-2140 matches main. Its extra relative-path cases were kept.
- **Requirement ID ranges (V1-4291).** lanetools (LVT-V0-001, 0..9999, canonical spelling) was kept
  over dfric's 1-to-9-digit variant. dfric's bare-run usage refusal was added, and DCW-V0-2146 now
  defers its range to LVT-V0-001.
- **Doc-gate list (cx-gates, V1-4542).** The lane's one-target-per-line format now holds main's
  full inventory, including six targets the lane did not know about. Main's bounded-parallel
  recipe (DTL-V0-006) is kept, and so is the lane's `spec-status-check` prerequisite.
- **batch-precheck test selector (V1-4543).** Main's `BATCH_PRECHECK_TEST_GROUPS` (ASD-V0-2473)
  was kept over the lane's `CASES` families. The lane's assertions were ported, including a new
  group 19, and ASD-V0-780 names the kept selector.
- **Rebind stop (V1-4545).** cx-dogfood's DWC-V0-044 stopped before the recorder, which contradicts
  main's accepted DCW-V0-015 and broke the `dogfood-change_test.sh` first-pass case. The stop is
  removed. Its remaining intent, that the impact refusal caused by the dirty CEM is pending rather
  than a failure, now lives in dfric's PENDING pass (DCW-V0-2143).
- **pibrow.** Batch-1105a (63c2c229a) already re-resolved this lane onto main. That batch dropped the
