## Friction

- `make spec-requirements` writes to `/tmp` unless TMPDIR is set. On a full `/tmp` it fails with
  ENOSPC and leaves a `gen-spec-requirements.*` directory behind.
- `corvint affected`:
  - It warns self-binary-stale.
  - On a full `/tmp` with no TMPDIR, it fails silently or prints empty output.
  - `--path` refuses a dirty worktree.
- The `shell:foreign-callers-invalid` refusal names neither the script nor the offending file. It
  took scratch probe tests to find the cause.
- The repo completeness test and the plugin disagree:
  - The test checks literal names. The plugin also counts built names, but missed the built name
    in `dogfood-cache_test.sh`.
  - The test scans `.txt` files. The plugin's candidate set excludes them.
- A Go comment that spells a declared script's name invalidates the whole declaration, and says
  nothing about why.
- Unknown entries in an affected plan name no source script or unit.
- A seal commit's transient `.corvint/change.cem.json` delete keeps `--base` UNKNOWN through readers
  that build script names.
- `FRONTIER_OK` already masks the shell frontier, so V1-3571 gives batch-precheck no wall-time gain.
- Nothing in the per-package focused tests flags a Tasks to Core import. Only `TestImportDirection`
  and the archive test catch it, and they run in batch-precheck.
- `go test ./internal/tasks/store` takes more than 500 s, which exceeds the lane's 600 s
  foreground cap.
- `corvint test` needs a full SHA for `--base`. `HEAD~1` is refused as invalid-arguments.
- `corvint-tasks ticket show` from the WSL worktrees: the journal is absent, so the ticket state
  is NOT_OBSERVED.
- The corvint MCP server failed to connect (CONNECTION_CLOSED).
