## Classification of every reason code

Class (a): the reason hides an executed command, interpreter, sourced file, working directory or
make target; the site stays computed. Class (b): the reason does not hide one under a stated
condition, which a rule of this lane makes exact. Class (c): unclear; the site stays computed.

| reason | class | argument |
|---|---|---|
| `make:evaluated-uncertified` | (b) for one shape, else (a) or (c) | The AFP-V0-3122 hedge keeps an evaluated target a site when it runs an uncertified command, to guard a missed alternative. (b) when no make variable, function over a variable, or prerequisite-derived automatic variable reaches any shell word of the recipe other than the value of an assignment AFP-V0-3128 admits (`GOCACHE`), and no prerequisite line holds one: every executed command, operand, working directory, redirect and make goal is then literal text whatever value make or the caller's environment or command line gives, so the target is a literal recipe whose cache location is unknown, the form AFP-V0-3128 admits for an unevaluated target. Rule AFP-V0-3600. (a) when an overridable variable is a command word: `$(HEAVY_ADMIT)` is `?=` and its comment documents `HEAVY_ADMIT=` as the opt-out, `$(DOC_GATE_LIGHT_GO_TEST)`, `$(GO_TEST_COMMAND)`, `$(MAKE)`, `$(SUB_MAKE)` and `$(GATE_LEDGER)` can each be set on the command line, so the program run is not known. (c) when an environment or command-line value is an operand or assignment value of a repository script or `go run` program (`DOGFOOD_BASE`, `REV`, `RECORD`, `CORVINT_RELEASE_BIN`, `APPLY`, `GO_TEST_TIMEOUT`): the program may execute or source its operand (`cem-release-suites --corvint PATH` runs PATH), and the shell plugin leaves an operand-built command outside its model (TSP-V0-960), so no edge would see the file it names. |
| `shell:assignment` | (b) for one shape, else (c) | An assignment hands a name to the command or the rest of the script. A name a program gives execution meaning (`PATH`, `BASH_ENV`, `NODE_OPTIONS`, `GOFLAGS=-toolexec=...`, `GIT_*`) can run a file no edge names, and no closed list of harmless names exists for an arbitrary repository program. (b) for Go toolchain names whose listed literal value only narrows what the go command reads or selects a build variant the Go claimant already unions (AFP-V0-580): `GOOS` and `GOARCH` from a closed list, `CGO_ENABLED=0`, `GOENV=off`, `GOWORK=off`, `GOPROXY=off`. Rule AFP-V0-3601. Every other name or value stays (c). The make sites sole on this code each hide a command word or an environment value behind it (`$(HEAVY_ADMIT)`, `$(DOC_GATE_LIGHT_GO_TEST)`, `REV`, `BASE`), and `windows-vet` keeps a `$(shell stat ...)` in its cache value, so resolving the literal assignments alone clears only `ci.yml#go-interop`. |
| `shell:local-referenced` | (c) | A CI-local variable whose later reference revokes AFP-V0-9622 narrowing. Its value comes from a command substitution, `read`, a loop or a condition; proving where each reference lands needs value propagation, which the earlier shell attempt tried and whose single review round found six fail-open cases. |
| `shell:unsupported-syntax` | (c) | A revocation reason: `case`, `[[`, pipes, subshells and braces are outside the grammar the narrowing proof covers. It only appears beside a narrowed form whose soundness depends on that grammar. |
| `shell:builtin-set` | (c) | `set` outside the AFP-V0-9621 allowlist (`set --`, `-f`, `-a`) changes positional parameters, globbing or exports for later commands; in a make recipe no environment is known, so even the allowlist does not narrow. |
| `shell:local-command-word` | (a) | A shell variable is a command word. |
| `shell:loop-variable` | (a) | The loop variable's values come from a runtime word list and it is used later, including as a command word or path operand. |
| `shell:computed-command-word` | (a) | The command word is an expansion. |
| `shell:heredoc-body` | (a) | The skipped body may be fed to an interpreter or saved and run (AFP-V0-9400). |

## Earlier attempts

Both read from `refs/orphans/` with `git diff 447bdcbd5..refs/orphans/NAME`.

- `refs/orphans/v1-5179-make-computed`: not ported; written again. Its central change, that
  speculative expansion of values no recipe uses no longer marks literal targets, is already on
  main as AZU-V0-610, which is why the base has 41 such sites, not 70. What remains of it is a
  static resolver that takes `?=` defaults (`BASE`, `CORVINT_BIN`) as known values under the
  default-invocation assumption; this charter's fail-closed list forbids resolving a variable the
  environment can supply, and its own review withdrew ordered include inlining. AFP-V0-3600
  instead treats every make variable as unknown and asks only where the unknown can land. Its
  review cases (`override`, `override define`, target-specific `override`, pattern inheritance, a
  rebuilt include) are rewritten as fail-closed rows of this lane's table, not copied.
- `refs/orphans/v1-5179-shell-computed`: not ported; not rewritten either. It propagated shell
  constants through `driver_shell.go`, which has changed since, and one review round found six
  fail-open cases (a conditional or pipeline `cd`, a newline that erased conditional state, a
  generated file then sourced, `env --unset VALUE`, `taskset` operands, `bash --rcfile`). Value
  propagation is not needed for any (b) rule above; AFP-V0-3601 is a closed allowlist extension of
  AFP-V0-3128, and its neighbours include the review's generated-file and wrapper cases.
