## Friction

- When edits were shipped from the Mac with `tar` over ssh, macOS tar added AppleDouble `._*`
  files. One of them was staged and broke `make spec-requirements`. `COPYFILE_DISABLE=1` avoids
  them, but GNU tar still warns about `LIBARCHIVE.xattr.com.apple.provenance` headers.
- The lane brief said to finish with SendMessage to `main`, but the subagent harness only accepts
  a SubagentHandback report.
- The DCG Traceability rows this lane de-duplicates are the same rows cit-w12 repins, so merging
  this lane with cit-w12 is expected to conflict on those rows.
- SRG-V0-740 was already named on origin by a build log, as a forward reference, so "is this ID
  free?" has no mechanical answer. `requirement-id-collisions` does not cover IDs that appear
  only in prose.
- The corvint MCP server failed to connect (CONNECTION_CLOSED), so the lane used the CLI.
- WSL `/tmp` had 1G free against heavy.sh's 3G floor (it warned on every run).
- `heavy.sh go test ./internal/specindex` was refused for a missing HEAVY_WHOLE_REASON even
  though `affected` had already reported UNKNOWN.
- Even with no new ticket, `corvint affected` on a shell- and spec-only change selects 90 Go
  units at tier 2, because `script/*.sh` and `docs/specs` are shared reads.
