  the lane 18; it now counts the Makefile's tree lines (`fe2bbfe39`). This already failed on
  `claude/batch-1101d`.
- afr-w31's `.corvint/runtime-edges.json` names TypeScript tests, so the Go-only and Python-only
  live-repository graphs in `measure_test.go` refused to build

  refuses (`3f52710f3`).
- `internal/dogfoodflow/propose_repin.go` was added by both sides with different content (HEAD's
  DCW-V0-842 re-pin and aff-w26's DCW-V0-548 repin-only hunks). Both are kept; aff-w26's file is
