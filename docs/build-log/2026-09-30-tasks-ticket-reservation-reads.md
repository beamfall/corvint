# Tasks ticket reservation reads (GitHub #409)

The ticket `currentAttempt` projection now reads audited reservation membership at the same immutable journal head and intent tree as its inventory. The old CLI supplied only queue/policy context, so a reserved ticket was reported `NOT_OBSERVED` even while `queue status` reported its reservation. The production change is limited to `internal/tasks/cli` and preserves the accepted attempt/reservation wire identifiers.

`CAL-V0-007` creates a reservation; `CAL-V0-010` fences expired renewal; `CAL-V0-011` removes membership through release or reap. An expired but unreaped entry therefore remains observed. This read does not establish a live process, authentication, a valid lease, runtime qualification, publication, or eligibility. Journal-absent `show` remains an unaudited intent projection; `blockers` keeps its existing journal requirement. Missing, replaced, malformed, wrong-queue, or moving state refuses through the existing typed protocols.
