## Decisions

- V1-3921 (GPK-V0-882): with `TMPDIR` unset, isolated `git status` scratch tries the user cache
  directory (`os.UserCacheDir`) before `/tmp`, and only an explicit `TMPDIR` (or Windows) makes the
  first parent strict. A copy that fails with `ENOSPC` is refused with a fixed reason that names the
  full scratch filesystem and the `TMPDIR` fix, instead of the raw write error. The refusal class is
  unchanged (`scratch-dir`).
- V1-3914: the PTF special-files fixture is rooted in `os.MkdirTemp("", ...)` (so it honours
  `TMPDIR`) and falls back to `/tmp` only when the unix socket path would exceed the 104-byte
  Darwin `sun_path` limit. A new test asserts the fixture lives under a short `TMPDIR`. Test-only;
  no spec change.
- V1-3911 (AMAP-V0-880): the JS lexer reads an identifier that contains a `\uHHHH` or `\u{H+}`
  escape as one identifier token flagged `escaped`, keeping the raw text (never decoded). Object
  keys, React router reads and state-constant export audits treat a flagged token as doubt, the
  same as the previous bare `\` punctuation.
- V1-3908: the CCF-V1-007 register coverage observer counts the frozen Core modes that ran. When
  `-run` filters them (for example a filtered `CORVINT_UPDATE_GOLDEN=1` regeneration) or an earlier
  failure stops them, it logs that coverage was skipped instead of failing on rows no mode could
  reach. A full run still fails on every unreached row. Test-only; no spec change.

## Review fixes

An independent Codex review of `0e908b148` returned CONCERNS with two findings; both were
confirmed against the code and fixed (spec amendment `07ebbc04c`, fix `e4062121e`).

- P2: `objectKeys` in `internal/appmap/endpoints.go` read an escaped identifier key as a plain key
  under its raw text, so `axios({url:'/a', \u006dethod:'DELETE'})` read GET and an escaped
  `baseURL` passed. `configKeys` now reports an escaped key and leaves it out of the map;
  `objectKeys` fails on one. An `$http`/axios config, an axios init and an axios verb-call config
  with an escaped key refuse with `non-literal-config` (the key may be `baseURL`); a fetch init
  reads `*`. Test: `TestAMAPV0880EscapedEndpointConfigKey`.
- P3: `unicodeEscape` rejected braced escapes with more than six hex digits, including leading-zero
  forms. It now takes any digit count and refuses a value over `0x10FFFF` (checked per digit, so an
  arbitrarily long run cannot overflow). This also applies to string-literal escapes, which share
  the reader. Test: `TestAMAPV0880BracedEscapeDigits`.

## Friction

  became `a`. Workaround: write `\\u` in double-quoted Go strings, or build the text with
  `chr(92)`.

  `ASD-V0-880` by `imp-w13`) is visible only by grepping every `claude/lane-*` branch.
