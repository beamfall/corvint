# Bidirectional LSP quality contract and exploratory baseline — V1-0477

Date: 2026-09-29. Base: `cf93522e149c754e002426e422270f24c88777fe` (`origin/main`). The owner chose both upstream language-server enrichment for agents and a Corvint language server for editors. This change registers `docs/specs/lsp-quality-platform-v0.md` as a proposed technical contract. It is not an implementation or promotion of those new profiles.

## Decision and scope

The proposed contract keeps a shared evidence engine, separate immutable Git and live editor-overlay identities, bounded and task-relevant upstream queries, exact capability negotiation, and an optional editor-owned native-Go stdio process. It preserves Core's default no-daemon/no-network boundary, project-owned authority, explicit uncertainty and nonexecuting reads. The previously deferred VS Code extension is not implicitly reopened. Eighteen stable requirements cover profiles, snapshots, provenance, adapters, lifecycle, agent projection, editor behavior, qualification and rollback. Exact editor/server tuples, wires, resource budgets and numerical promotion thresholds remain proposed and must be accepted and frozen before their implementation or promotion.
