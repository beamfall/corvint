## Decision and contract

CIN-V0-4625 and CIN-V0-4626 add one `macos-15` PR job and connect it to the existing required
`go-product` aggregate, including before the batched-label early exit. No new required status
context or branch-protection edit is needed. The existing `ci-control-plane` admin review still
controls activation. The nightly full macOS gate is unchanged.

A native `go list` inventory selects Darwin build files, runtime GOOS comparisons and macOS
`/var` alias witnesses. Inclusion reasons name the source/test file. It scans ignored platform
files too, and includes CI's two existing nested modules. Tests run one package per wrapped
command, without race instrumentation, sequentially with two build/test workers on one runner.
Every run recalculates the inventory, rather than maintaining a frozen package list.

Design fork: do not intersect with Linux shard artifacts, because Linux cannot see every Darwin
file. After the existing MET verdict only, build the existing driver, selector and shadow natively
from the tested merge's trusted main parent and reuse `narrow.sh` unchanged. Its existing FULL,
merge-queue, `.github/` change and shadow-superset guards remain binding. Any failed build, missing
record or mismatched identity retains the full Darwin inventory. Root narrowing cannot omit
nested-module packages. DOCS alone skips the native tests; REUSE does not. Native artifacts use
`macos-selection`, outside the Linux shard coverage/forward-row denominator.

Cost is an estimate, not a native measurement: a small narrowed change is budgeted at 5–15
runner minutes including setup/planning. A Linux metadata replay selects 142 packages, with
138.42 minutes in the existing Linux race cost table; it includes `internal/contextindex`
(V1-4413's package). This is neither a macOS timing nor an upper bound on its native inventory.
The expensive fail-closed case is bounded by a 180-minute job timeout. An unavailable forward
bar disables narrowing and can incur that larger cost; no low universal cost is claimed.

The lexical inventory can overselect comments and negated tags, and cannot prove completeness
for computed OS checks or path sensitivity with no source witness. Add a platform/path regression
witness when such a failure is found; the nightly gate remains the full-suite backstop. New
independent nested modules need explicit provisioning; fixture modules are excluded by go list.
Rollback removes this job, selector and aggregate dependency/check, leaving the nightly gate.
