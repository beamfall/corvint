# Build log

Each build-log entry is its own write-once file in this directory,
`docs/build-log/YYYY-MM-DD-<slug>.md` (decision 0423). Record material design decisions,
independent findings, failed evaluations and promotion evidence here; contracts belong in
`docs/specs/` and decisions in `docs/decisions/`.

Entries written before the 1.0 repository started, including the closed `docs/BUILD-LOG.md`, live
in the archive repository
[`beamfall/corvint-history`](https://github.com/beamfall/corvint-history/tree/1c4d8793cf71cbb01b8509b68a6cb1502a40a13e/docs/build-log)
at commit `1c4d8793cf71cbb01b8509b68a6cb1502a40a13e` (decision 0587). A citation of an older entry
resolves there.
