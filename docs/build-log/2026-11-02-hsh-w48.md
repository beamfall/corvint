# Heavy offload host paths — V1-2691 and V1-4335

Lane `hsh-w48`, branch `claude/lane-hsh-w48-1102`, base
`b486d3978728731c6638b50fa2210dfbb6e365ea`. Owner-requested scope: prevent the remote Go
cache from filling a tmpfs and keep forwarded Mac scratch paths out of remote commands.

## Contract and decision

The owning `corvint-self-development-v0.md` had 224 indexed obligations before this change;
`ASD-V0-2120` and `ASD-V0-2121` bring it to 226. Both use the assigned 2120..2129 block and
the standing acceptance marker. The full daily-change spec receives no new requirements.

The remote already defaulted to a home cache and private scratch, but its environment file
could retain a tmpfs cache and command assignment words could override its scratch or Makefile
cache. Linux offloads now inspect both cache filesystems, including symlink targets, relocate
RAM-backed caches to the home cache, and declare the remote unavailable with a repair when no
checkable disk fallback exists. Host-local scratch and cache settings win over caller argv
assignments, including Makefile assignments. The help text describes the decision.

Existing per-run EXIT cleanup now also covers tests whose caller supplied an unrelated TMPDIR:
the command cannot escape that directory through its forwarded TMPDIR/GOTMPDIR assignments.
Rollback is a revert of the checks/filtering, tests and these two clauses together. Existing
shared caches and unowned temporary directories are never deleted by this change.

## Independent review fixes

- Make assignment operators: GNU make 4.4.1 applies `NAME:=`, `::=`, `:::=`, `+=`, `!=` and
  blank-padded words over the environment, so the `NAME=*` filter let them restore a caller cache
  or Mac scratch path. The remote now drops every operator form for the five cache/scratch
  names. The host-environment mode adds a ninth case: the stub make exits 34 on any assignment
  word, and the old filter fails it.
- Darwin callers: the fake SSH remote inherited the caller's `uname` and `timeout`. With a Darwin
  `uname`, the Linux cache check was skipped, and the old fixture failed its first tmpfs
  relocation assertion. A remote-only stub directory now supplies Linux `uname` and a
  pass-through `timeout`. The default suite repeats the mode from a simulated Darwin caller.
  No real macOS run is claimed.
