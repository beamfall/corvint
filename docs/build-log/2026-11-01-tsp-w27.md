9. Other lanes' load burners (48 processes) made wsl-lanes perf rows unqualified. Load swung from 5 to 155 within minutes.

11. The hold help example did not run as written (fixed).
12. Mac load stayed at 34-188, and the V1-1516 `-count=3` runs could not finish within the 9-minute bound.
13. The scratch queue needs `script/tasks-scratch-queue.sh`. A plain template init refuses claims with CUTOVER_MISSING and nothing in the init output points at the helper.
14. `queue status` journalAudit is NOT_OBSERVED on an attempt-free store, so the read mode is unobservable from the CLI there.
15. The LGL harness qualification uses an absolute 1-minute load of 12 regardless of CPU count (32 on wsl-lanes), and its load-after sample catches other lanes' spikes.

17. Under mixed binaries, the current binary's RETRY_EXHAUSTED share rises from 18% to 60% of claims, and old-binary claims get SNAPSHOT_MOVED and REDO_PENDING (candidate ticket).
18. The whole store package cannot run in one ≤9-minute ssh command, so it had to be partitioned.
19. corvint on WSL reports build 44, while corvint-tasks labels stay build.40 or build.0.
