## Method

The subject is the sealed lane cmd-w26: 9 commits and 35 hunks on this BASE, lane head
`3e66f5e8a`. Each subject is a throwaway worktree under `~/lane-scratch/csp-w33/`. It runs the
`dogfood-closeout` sequence one phase at a time through `phase.sh`, which records wall, user and
sys time (`/usr/bin/time`), git spawns (`GIT_TRACE2_EVENT` start events) and `/proc/loadavg`
before and after each phase. The phases are:

1. `dogfood-change`, then `propose-citations`;
2. `dogfood-inputs-check`;
3. `BATCH_PRECHECK_SKIP_DRIFT=1 make batch-precheck` (precheck1);
4. `make dogfood-finish DOGFOOD_FINISH_ENTRY=dogfood-closeout` (bind, check-seal, seal);
5. `BATCH_PRECHECK_SINCE_RECEIPT=1 make batch-precheck` (precheck2).

The closeout total is phases 2 to 5, which are the steps `make dogfood-closeout` runs. Each
re-measured subject has its own fresh `CORVINT_GATE_LEDGER_DIR` and `SELECTION_BASELINE_CACHE_DIR`,
so no record from an earlier run can hit.

- 26 changes, each replayed with `git checkout` + `clean` (1.3 s), `corvint affected` (2.3 s,

## Fixes (this lane)

1. `ASC-V0-778` (V1-4166, V1-3580): a per-change result cache in `tools/selection-baseline`.
   - Key: the bytes of the planner, selector and replay-tool binaries, the cost table, the
     module, `go version`, `git --version`, the behaviour environment and the change entry.
     Replayed commits are immutable, so this key fixes the result.
   - `make selection-baseline-check` builds `-trimpath -buildvcs=false` unless
     `SELECTION_BASELINE_OUT` is set, so identical Go inputs give identical bytes in any worktree.
   - Evidence: a cold run took 75.8 s and the identical rerun 1.65 s. A real-repo cold-then-warm
     pair (69.0 s, then 0.08 s) wrote a byte-identical `--out` and identical stdout and stderr,
     except for the REUSE line.
   - Stamped, unstamped and trimpath `--out` results are equal, except the `planner` field (so
     `--out` keeps the stamp).
2. `ASC-V0-777` (V1-4166): the default replay worker cap rises from 4 to 8 (CPUs/3 at most 8).
   A 12-CPU host is unchanged. Measured at 89.2 s with 4 workers and 64.8 s with 8, with
   identical results.
3. `GL-V0-775` / `GL-V0-776` (V1-4160): a `@test:DIR` ledger scope. It keys a one-package
   go-test doc gate on that package's `go list -deps -test` files plus its declared test read
   scope. `shell-test-registration-check` and `go-version-pins-check` use it. Any doubt (an
   undeclared package, an inexact declaration, a failing `go list`) keys the step on the whole
   tree and prints the reason.
