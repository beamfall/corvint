## V1-3173: validating a worktree store (TCL-V0-869)

- Decision: `queue snapshot --worktree DIR` reads `DIR/.taskman` directly, with no repository
  resolution and no journal. The existing `CORVINT_TASKS_SNAPSHOT` reads then validate that tree:
  `ticket show`, `queue status`, `roadmap`, and `ticket blockers`, which is now also served from
  a snapshot. A new validate verb would have duplicated those reads, so none was added.
- Decision: a record that fails to decode refuses the snapshot, and nothing is written.
  A directory with no store is refused `UNINITIALIZED`.
- Limit: `receipt audit` audits journal receipts, which belong to the repository's journal and
  not to any worktree tree. It stays refused under a snapshot (TCL-V0-012) and runs against the
  owning journal.
- TCL-V0-011's list of served verbs gained `ticket blockers`.
