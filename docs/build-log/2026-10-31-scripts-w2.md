## Problem

The lane and batch scripts had four open defects or gaps:

- `batch-precheck_test` case 10 printed an invisible mismatch (V1-3464).
- `heavy.sh` waited for load before failing on a leading `NAME=VALUE` word (V1-3256).
- Two AI-trailer checks and hook installers ran side by side (V1-3337).
- There was no cost-aware way to split a package list under the 600 s tool limit (V1-3344).

The orchestrator's PR waiters also had no supported landing supervisor (V1-1735). The rest of the
list were audits or measurements of earlier lane-procedure work.

## Decisions

- V1-3464: the step-TMPDIR assertion in `script/batch-precheck_test.sh` prints an `od -c` diff of
  expected against actual when it fails. The case passes on this base (the V1-3315 fix
  normalises the path), so the ticket's remaining criterion was a diff that shows the mismatch.
- V1-3256 (`ASD-V0-830`): `heavy.sh` rewrites a leading `NAME=VALUE` word to `env NAME=VALUE ...`
  before anything else, so `script/heavy.sh GOTOOLCHAIN=local go test ...` runs at once.
- V1-3337 (`ASD-V0-831`, retiring `ASD-V0-071`): `check-ai-coauthor-trailers.sh` is the single
  check and hook installer, and also refuses a "Generated with/by" line that names an AI vendor.
  - `--install-hook` replaces the exact retired `check-ai-trailers.sh` hook and leaves any other
    hook untouched.
  - `batch-precheck` runs the check once.
  - `lane-setup.sh` uses `--install-hook`.
  - `check-ai-trailers.sh` is deleted.
  - Non-goals: the retired script's broader vendor list, and an installer-copy fallback. A kept hook
    runs the lane's own copy of the script, so the `lane-setup` fixture commits it.
- V1-3344 (`ASD-V0-832`): new `script/heavy-groups.sh [--budget 480] [--log FILE] PACKAGE...`.
  - A package's cost is the latest completed whole-package run in the heavy.sh selection log
    (`local` or `offload` lines, `run=` seconds). Packing is first-fit decreasing, one group per
    line.
  - A package with no recorded cost runs alone. So does one over budget, which is also named on
    stderr with a pointer to `make test-shard`.
  - It never runs or splits a package.
- V1-1735 (`ASD-V0-833`): new `script/pr-landing-watch.sh [--act] PR`, plus the declared flake list
  `script/known-flakes.txt`. It makes one pass and prints one decision line, with no loop or sleep
  (`ASD-V0-016`).
  - A failed head run whose failing Go tests all match the list is rerun, at most 3 times per head
    commit.
  - Auto-merge turned off by a bot's merge-queue removal is re-armed, at most 2 times, counted once
    per removal event.
  - A human dequeue is never re-armed. It escalates, as do a real failure and an exhausted cap.
  - Each `ESCALATE` is appended once, per PR, reason and head, to an alerts file that a session
    Monitor tails.
  - The list starts with `TestPSRV0111.*`, the flake observed on 2026-10-18 in the ticket.
- V1-0610: bounded tooling disposition, no repair needed.
  - Every tracked Python signal handler was audited: `conformance/opencode-native-v1/mcp_probe.py`,
    `script/measure-lsp-quality.py`, `script/qualify-checkpoint-handoff.py`,
    `script/qualify-lsp-editors.py`, `script/qualify-lsp.py` and `tools/lsp-editors/wire-proxy.py`.
  - Each raises `KeyboardInterrupt`, `SystemExit` or a `RuntimeError` subclass, or only signals the
    child group. None raises `InterruptedError`, the confirmed bug in the retired temporary wrapper.
  - No tracked native-closeout Python wrapper exists. The 2026-10-01 wrapper under `/tmp` was
    disposable and is excluded.
  - The reusable process-group owner is `script/process_group.py`.
