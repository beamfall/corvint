### V1-3950

A `sharedResource` gate takes an exclusive, non-blocking flock for the whole run.

- The lock file is `<git common dir>/taskman-gate-resources/<sha256(class, key)>.lock`. It sits outside the state directory, so the store inventory does not change.
- A run that finds the resource held refuses `LOCK_TIMEOUT` (retryable) before anything executes or is recorded.
- `preflight` still refuses such a gate as `UNSUPPORTED`.
- On a platform without flock, the run refuses `UNSUPPORTED`.
- The CAL A13 prose now points to LGL-V0-885.

- The AC1 measurement on the CLI 4096-event fixture is NOT_RUN. That fixture's chain is not writer-built, so the store record cannot head it.
- The CLI process start is outside the store.
