# 2026-10-24 p1-cce: offline prove replay, ledger-bound reach, proven-path synthesis

Lane p1-cce. Base 0949876eba7b706a77988d94944a46c0979690d2. Tickets V1-1687, V1-1685 and V1-1684
under umbrella V1-1666. New requirements `CCE-V0-100..104` are proposed and experimental under the
owner's standing auto-accept (2026-10-11); `CCE-V0-089..099` and `105..129` stay free for this lane's
reservation.

## Problems

- **V1-1687.** Every Prove ladder test needs Node, Playwright 1.64.0 and the pinned headless shell,
  so the ordinary `go test` lane skipped all of them and a ladder regression went unseen.
- **V1-1685.** `BuildObligations` passed nil to `appmap.Impact`, so a navigation ledger was never
  consulted and the report could not say whether one was.
- **V1-1684.** A flow whose first screen has no admitted deep-link entry always stayed `INCOMPLETE`
  with a path miss, even when a qualified receipt had already crossed from an admitted entry to that
  screen.

## Decisions

- **Recorded receipts, the real decoder.** A recording (`cce-recorded-side/0`, test-only, under
  `internal/changee2e/testdata/recorded/`) holds the canonical `/3` receipt one side's pool wrote.
  Replay runs it through `DecodeAttemptReceipt` and Prove's `qualify`, so a recording the provider
  would not qualify cannot reach the verdict code. The scenario pin hashes the compiled text below
  its header, because the header names fixture commit revisions that change on every run. Missing,
  non-canonical and stale recordings read `INCONCLUSIVE` with a named reason.
- **Synthetic until a live run.** No host here has the qualified tuple (below), so all ten
  recordings are `synthetic`, generated by `go test -cce-write-recordings` in the live receipt's
  shape and carrying no host path. `TestCCEV0101LiveRecord` replaces them with `live` ones when
  `CORVINT_CCE_RECORD_DIR` is set on a qualified host.
- **Live tests that cannot pass by skipping.** `CORVINT_CCE_LIVE=required` (and `make cce-live`)
  turns a missing toolchain into a failure. The CI job that would set it is `.github` work, so it is
  proposed in the PR body for the owner.
- **The ledger is bound, never trusted for reach.** `--ledger` is checked against the head map's
  application, digest and revision and refused when trimmed (`e2e-ledger-invalid`). Impact uses it
  only to list the ledger edges that touch screens already hit, so the obligations stay identical.
  The report records `anl-edge-ledger` under `consulted` and the ledger digest, which also changes
  the impact digest. The compiled header is unchanged: it binds the obligations digest, which now
  covers the ledger.
- **Path synthesis emits only mined, anchored statements (V1-1677/V1-1733 pivot).** A missing entry
  is replaced by the ledger-bound entry projection's shortest `PROVEN` path from an admitted
  deep-link entry. Each hop emits the admitted page-object method of the crossing step the receipt
  proved, never a generated `goto` or click. A hop abstains when its edge, crossing evidence,
  preconditions or step block cannot be matched exactly. Precondition flows, session state and
  route parameters are not synthesized.

## Compatibility

`ledger_digest`, `proven_path` and `proven_by` are new `omitempty` members. A report or compiled
artifact written without a ledger is byte-identical to before, and the existing goldens pass
unchanged. `CompilerVersion` is not bumped. An older reader that ignores unknown members reads the
new ones as absent. A strict reader that refuses unknown members refuses only artifacts built with
`--ledger`. Rollback is to remove the code and tests; no stored state migrates.

## Limits

- **Live recording NOT_RUN.** This host has Playwright 1.61.1 and 1.60.0 but not 1.64.0. The Windows
  box's WSL has Node v22 and no `@playwright/test`, and cannot reproduce the qualified mac-arm64
  headless shell 1248. No toolchain download was authorized.
- **V1-1684 NOT MET.** Still open: fixture outputs and data flow, session, teardown, typed locators
  and assertions, parameterised routes, `test.step` with trace, and goldens across that vocabulary.
- **V1-1685 partial.** API contract joins are NOT MET. The TJAA module graph and the widen-only
  runtime coverage source predate this lane (CCE-V0-054 and CCE-V0-045).
