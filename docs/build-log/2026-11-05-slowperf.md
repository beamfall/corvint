- GL-V0-9500: full-capacity ledger fixtures overlap after serial global lock-hook
  tests finish. Keep 32,832 filler entries, 32 writers and 24 writes per writer.
  The concurrent-prune filler has identical immutable bytes, disjoint from writer

  objects, commits an edit, and checks another copy still has the original head
  and clean status. Twenty injection tests and the history matrix use parallel

  transitions and cases remain.

  read-only. Keep record, digest-tail, header and exact-refusal assertions.
