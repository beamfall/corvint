## Contract and implementation

Optional operator `accept --temp-root` validates an existing canonical absolute directory,
creates a private `corvint-acceptance-run-*` child, and propagates TMPDIR while retaining the
fixed PATH/LANG/LC_ALL values and exact four-key worker admission. Parent cleanup runs after
joined workers and removes residues left by forced worker retirement; cleanup failure refuses
publication. Omission preserves /tmp, original native output configuration, request digests,
and the control hook environment. Rollback omits the flag or reverts this patch; no migration.

Direct outputs: worker `corvint-new-test-output-*`; native `corvint-playwright-*` generated
config/reporter/report, attestation staging and scoped native project outputDir; control
`corvint-behavior-control-*` executable staging. Control hooks preserve only scoped sanitized
TMPDIR. Provider-owned native outputDir avoids expanding closed caller runner options.
Caller hooks, imported runtimes, browser installs/caches, arbitrary reporters, workspace/build
outputs, snapshots and hard-coded paths retain transitive uncertainty. This is cooperative
placement, not filesystem containment. Parent crash/SIGKILL requires operator residue retirement.
Vitest report and negation scratch producers exist in the provider package but are excluded:
acceptance dispatches only RunE2E and approved behavior controls, not unit/negation operations.
