### NEW-B1: root cause

Lanes followed the record-only recipe for changes that are not records. For two reasons:

- `script/dogfood-finish.sh` printed the record-only fix line on every missing-`CITATIONS`
  refusal.
- The `DCW-V0-817` hint said a record change may touch `docs/decisions/*.md`, but `RecordChange`
  does not allow that.

The checker is right. `TestChangeDCWV0058RecordBindsUniformPlanAndRecordIntent` already proves that
the recipe passes for a pure record change. The fix narrows the doc and the hint to match the
checker.

### V1-3421 decision

`small_package_bytes` stays limited to `tools/` and `conformance/` packages. The reasons:

- The size of a package's `*_test.go` files does not bound the runtime of an `internal/` or `cmd/`
  package. Those tests build large dependency graphs and Git fixtures.
- The recurring case would not have been exempted anyway. `internal/tasks/wire` holds 62,013 bytes
  of tests, above the 49,152-byte default.

The supported routes are:

- a `-run` pattern;
- a `HEAVY_SELECTION` manifest from `corvint test --dry-run --manifest`;
- `HEAVY_WHOLE_REASON`.

Since `ASD-V0-730`, the refusal prints each of these as an exact rerun line.

### V1-3420 and V1-4255

V1-3420 asks for a 100+ row plan to finish within 600 s, or for the check to be resumable. Its
cost had two parts:

- **The heavy-slot wait.** On wsl-lanes with every slot held, the wait was 24-54 s, and historical
  runs took 393.5 s. NEW-B6 removes it: the check is now admitted on the light pool in about 0.14 s.
- **The per-hunk `cem cite` subprocesses** in the prepare pass. This is V1-4255's acceptance: one
  batched invocation plus resume.

V1-4255 changes the plan replay in `internal/dogfoodflow/change.go` (`cem cite` per row) and the
cite pre-check. That is lane cit-w41's area, so it was not built here and stays open for routing.

## Review round 1 (Codex, at 1d3778119)

1. **P1: a capped run left TERM-ignoring descendants running.** These descendants kept the light
   slot through the inherited lock. Now, once the command exits, heavy.sh keeps polling the
   process group and sends KILL until no member is left (ASD-V0-731).
   - Repro, with a grandchild that ignores TERM under a 1 s cap:
     - before: rc=124, 2 s, grandchild alive
     - after: rc=124, 6 s, grandchild gone
   - Test: lane-scripts_test "the light cap left a TERM-ignoring descendant running".
2. **P2: the build key dropped bytes from GOFLAGS.** `read -a` collapsed whitespace and lost
   everything after a newline. `dogfood_key_goflags` now strips only an unquoted `-p=N` word and
   one adjacent separator. Every other byte stays.
   - Tests: dogfood-bin-reuse_test cases for quoted double spaces, a quoted value with `-p`, and a
     second line.
3. **P2: the static pre-check blocked sealed-head reruns.** On a seal HEAD it now prints
   `inputs-check STATIC SKIP already-sealed` and exits 0, so a rerun with BASE and CITATIONS alone
   reaches the full run's `seal SKIP` (DCW-V0-731).
   - Test: TestDogfoodFinishLaneDCWV0060MatchesManualRecipe.
4. **P2: the static pre-check skipped the plan's row grammar.** It now runs
   `validateCitationPlan`, as `planShape` does. It refuses `invalid-citation-plan` and
   `citation-plan-relation-unknown`, and leaves over-bound plans to the staged route.
   - Tests: TestDCWV0731StaticPreCheck/relation and /grammar.
5. **P3: the rerun hint kept an empty reason.** A leading `env HEAVY_*_REASON=` word that would
   override the reason the hint adds is now dropped, and so is an `env` left with no assignment
   (ASD-V0-730).
