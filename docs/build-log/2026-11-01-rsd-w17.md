## Friction

1. **The Corvint MCP plugin is down.** It reports `CONNECTION_CLOSED` in the lane session, so the CLI was used instead.
2. **The ticket descriptions were swapped.** The dispatch's descriptions for V1-3763 and V1-3788 belong to each other; `ticket show` has the authoritative text.
3. **The read-scope checker misses some literals and over-reads others.**
   - It missed a `filepath.Join(root, "docs/...")` literal, which only a confined run found.
   - It over-approximates `"../../cmd/"+pkg` as all of `cmd/`.
4. **The read-scope checker reports one violation per run.** Each fix needed a rerun.
   - Expected: every violation in one run.
5. **testconfine cannot grant opening `/`.** This leaves the dashboard walks (`os.OpenRoot`) unbounded for good.
6. **`dogfood-cache_test.sh` fails at BASE.**
   - Repro: run `bash script/dogfood-cache_test.sh` at `6d4713fb8b5d`.
   - Expected: pass.
   - Actual: the line-286 recipe assertion fails. It expects `dogfood-inputs-check batch-precheck dogfood-finish since-receipt:batch-precheck`, but `dogfood-closeout` now has a `@BATCH_PRECHECK_SKIP_DRIFT=1 $(MAKE) ... batch-precheck` line.
7. **`corvint test --base` refuses a short sha.**
   - Repro: `corvint test --base e00f422d3 --dry-run`.
   - Expected: the sha resolves.
   - Actual: `test needs --base FULL_COMMIT_ID`.
8. **Two byte measures disagree.** aff-w16 recorded 3,033 B for `--summary` (stdout only); the stdout+stderr measure is about 3x larger. The tickets' "under 5 KB" target does not say which stream it means.
9. **WSL `/tmp` space is low.** 2.3 GB was free during the confined runs.
10. **Background `git log --all -S` on WSL is slow.** Over 20 requirement numbers it took over 180 s, which pushed a foreground ssh call into the background.
