## Defects found and fixed (commit a302ef647)

1. **`docs maintain` wedged a seeded page.**
   - With the base binary, an empty block (`commit=""`, `source_digest=""`) did not parse.
     `--preview` reported `existed=false` and `--apply` appended a second block (rc 0).
   - The next preview refused with `marker-in-content` (rc 2), so the page could no longer be
     maintained.
   - Fix: an empty body parses and is replaced in place. A begin marker for the selector with no
     parsed end is refused as `malformed-block`, and nothing is written.
   - Tests: `TestEmptySeededBlockIsReplacedInPlace` and `TestMalformedSelectorBlockIsRefused`.
   - `TestCleanRegenerationEqualsIncremental` had passed only because its non-hex digest was
     silently duplicated. It now uses a well-formed stale digest and asserts one block.
   - The refusal table in `SDD-V0-009/010` now has the `malformed-block` row.
2. **`docs flows generate` skipped `.mjs` and `.cjs`** with no gap recorded.
   - On `tools/web-flows`, the base binary produced 0 flows.
   - Fix: both extensions are admitted. Test: `TestFlowDocsJavaScriptModuleExtensions`.
   - Spec: `AFU-V1-043`.
3. **`docs flows check` missed call-inventory drift.**
   - The drift commit c08e16696 added a `validImport(...)` call inside one flow's body.
   - The regenerated flow diagram gained that call, but check reported all 949 bindings fresh
     (rc 0). The flow binding covered only its declaration line.
   - Fix: the flow binding includes its static call anchors.
   - The same fix stops listing control keywords (`if`, `function`, `return` and others) as calls.
     The base output had them in most diagrams.
   - Test: `TestFlowDocsCallInventoryDriftIsStale`. Spec: `AFU-V1-045`.

## Criterion 1: claims against delivery

- **`corvint docs` row.** The release spec listed `corvint docs` (draft, watch, apply, maintain),
  but no `watch` or `apply` subcommand exists. The row now names the real verbs: `nav`, `draft`,
  `consume`, `maintain --preview|--apply [--watch]` and `flows generate|check|finalize`. It cites
  `SDD-V0-007..011`, `AFU-V1-043..048` and this entry.
- **`corvint flows` row.** It now names `flows navigate`, `flows docs` and `flows docs maintain`.
  `flows docs maintain` is labelled with the experimental `flow-document-maintenance-v0.md`
  contract.
- **Helper text (friction, not changed here).** `corvint docs --help` lists only nav, draft, consume
  and corpus. `maintain` and `flows` have their own help but are absent from the parent usage.
