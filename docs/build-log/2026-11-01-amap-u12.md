# Lane amap-u12 (wave 12): appmap, appflows and flowdocs tickets

Lane `amap-u12` on the Unraid host, branch `claude/lane-amap-u12-1101` from `origin/main`
`e9a5d6c803cb0a1cce3d4eebf74ab1da84dcd4e1`. Requirement IDs come from the lane block 810-819 in
each governing prefix (AMAP-V0-810..816, SKH-V0-810, ANL-V0-810..811, AFU-V1-810..811).

## Decisions

- V1-2770 (AMAP-V0-810..812): `flows appmap coverage` reports reached and total screens per router
  module. The MCP projection of the report is left as a follow-up.
- V1-2594 (SKH-V0-810): `corvint how` is a top-level alias of `flows appmap how`; it needed a
  CAPABILITIES row, a catalog regeneration and a receipt repin.
- V1-2714: a leaf tsconfig that declares every field outranks a package `extends`. This is pinned by
  `TestAMAPV0195LeafDeclaredFieldsOutrankPackageExtends` and needed no code change.
- V1-1077 (AMAP-V0-813): a bundler alias key is not an external package.
- V1-1614 (AMAP-V0-814..816):
  - Cypress `cy.visit`, `cy.intercept` and `cy.get` are references, and an `@alias` get is named
    `cypress-alias`.
  - A configured Playwright `testIdAttribute` / `setTestIdAttribute` name is a test-id selector.
  - An anchored RE2 route regex (`^/...$`, flags empty or `i`) is checked against the screen index.
  - AC4 (an adopter-scale run and promotion) is BLOCKED. No adopter Cypress suite is available on
    the lane host, and promotion is an owner decision.
- V1-2713 (ANL-V0-810): a manifest `impact_exempt` glob with a reason counts a non-UI path under
  `ignored_paths` and lists it under `exempt` with its `MANIFEST:LINE`. It never covers UI, test,
  manifest or placed paths.
- V1-2907 (AFU-V1-810): `e2e-safe-selection/1` gains `frontier_excluded`. It holds each plan
  `frontierExcluded` entry narrowed to the reasons that would have widened the selection to every
  changed path. The member is informational and the decision is unchanged.
  `internal/liveverify/affected` was not touched.
- V1-1236 (ANL-V0-811): the five step-effect limits stay named uncertainty, each `unknown` at the
  call's own line: test-id clicks, raw-selector clicks, property-bound locators, `extends` classes,
  and spec-local helpers (declared or not). No click or call has pinned static evidence of its
  effect. The page-object model already follows inherited methods and spec-local helpers
  (SKH-V0-012). `TestANLV0811StepEffectLimitsStayNamed` and `TestANLV0035StepEffects` pin this.
- V1-2338 (AFU-V1-811): a flow whose calls span several paths names each call's path in its diagram
  call lines. Single-file flows render byte-identically.

## Friction

- The Unraid host has no `node`. Because of that, `TestANLV0037ProducerNodeUnit` and
  `TestANLV0044ProducerRedactionMatchesObserve` fail in a whole `internal/appmap` run.
- A new top-level command needs a CAPABILITIES row, a catalog regeneration and a receipt repin. Each
  surfaced only through a separate failing check.
- `flows appmap impact` refuses directory paths with `unsupported-impact-path-suffix`.
- The frozen Agent digest Status line refusal appears only at `make spec-requirements` time.
- `TestCAPV0960` is brittle to a backticked `coverage` word in a capability row.
- `heavy.sh` exited 1 without a message when given several packages.
- The V1-2594 ticket cites a `--request` flag that does not exist.
- AMAP-V0-816 lets a fully literal anchored regex such as `^/ord$` match a parameter template. The
  spec records this as a non-goal.
- ANL-V0-035 reads a constructor assignment to a declared field (`readonly save: Locator;` plus
  `this.save = ...`) as `member-assignment`. Constructing such a page object is therefore `unknown`,
  which is common Playwright style.
