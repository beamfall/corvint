## V1-5168: make sites computed only as `make:evaluated-uncertified`

What was wrong. The AFP-V0-3122 hedge keeps an evaluated make target a computed site unless every
command it runs is certified. `evaluated` was set file-wide: the file-level expander walked every
variable value (`WINDOWS_VET_GOCACHE`, `HEAVY_ADMIT`, `CORVINT_GOCACHE`) and every `ifeq`/`ifneq`
condition, so each target whose recipe runs a repository script (`go-format-check:
script/check-go-format.sh`) was a site although its own text resolved nothing. Finer reasons
(`TestDriverComputedReasonCounts` with `CORVINT_DRIVER_REASONS_SITES=1`) showed the same five
functions on all 64 sites: `$(filter)`, `$(filter-out)`, `$(if)`, `$(or)`, `$(strip)`.

The fix (AZU-V0-610 to 612, `docs/specs/affected-zero-unknown-v0.md`):
- evaluation marks a target only where its value is observed: the target's own recipe or
  prerequisites (as before), a remainder recipe, or a parse-time expansion that ran a command, read
  a file, met an unmodeled function, or is a `!=`, statement or include. A variable no text expands
  and a conditional's condition (every branch is already an alternative) mark nothing;
- each `make:evaluated-uncertified` site also records `make:evaluated:<name>` and
  `make:uncertified:<reason>` naming the blocking word (`shell:uncertified-command:go:run`,
  `shell:redirect-input:local.txt`, ...); the file-level reasons mirror exactly what left the file
  uncertified (a recursive value's `$(shell ...)` records nothing file-wide);
- `GOTOOLCHAIN=local` is a modeled assignment: it forbids the toolchain switch and reads nothing;
  every other value stays computed.

Census of computed make sites at the lane base tree (`make=` counts; CI stayed 37 throughout):

| | base | after AZU-V0-610 | after AZU-V0-612 (final) |
|---|---|---|---|
| computed make sites | 112 | 63 | 60 |
| sole `make:evaluated-uncertified` | 65 | 16 | 38 (each with its blocker) |
| `shell:assignment` | 46 | 46 | 21 |

The 38 final evaluated-uncertified sites each name `$(if)`/`$(or)` from their own recipe
(`$(CORVINT_GOCACHE)`, `$(HEAVY_ADMIT)`) and an uncertified `go run ./tools/...`, repository
script or `git`, which AFP-V0-3122 excludes on purpose. The 21 remaining assignment sites are
uppercase project names (`BATCH_PRECHECK_LANE_CLOSEOUT=0`) and referenced lowercase locals, which
AFP-V0-9628 revokes; the ticket's "recipe-local variables" shape is therefore not narrowed.

## V1-5201: a Go path literal selects its unit for any dirty path it prefixes

AFP-V0-9810 (`docs/specs/affected-reader-precision-v0.md`, `tempjoin.go`): a literal that is an
argument of `filepath.Join`/`path.Join` whose first argument is `t.TempDir()` (a `*testing.T`, `*B`,
`*F` or `TB` parameter, never reassigned), `os.TempDir()`, such a join, or a once-bound local rooted
there, with plain components, names no repository read and leaves the unit's tokens. Everything else
stays: a parameter or `os.Getwd` root, a reassigned or addressed variable, a package-level variable, a
custom `TempDir` receiver, `..` or glob components, the same text spelled elsewhere, an unparsable
file. AFP-V0-2203's "no proof is sound for Go source" is amended with this one shape.
`TestFileNameOnlyReadersMustPlaceThePath_AFPV0072` now expects the `t.TempDir()` fixture out and
keeps the parameter-rooted joiner in. On the lane base tree the proof applies to 3164 literal
arguments in 689 files of 173 packages (`cmd/corvint` 91 files).

The docs-only probe above still selects the same 11 Go `PATH_LITERAL_READER` hub packages
(`cmd/corvint`, `internal/liveverify/affected`, `internal/contextindex`, `internal/specindex`, ...):
their `docs/...` literals are fixture map keys (`map[string]string{"docs/specs/cache-spec.md": ...}`)
written under a temporary root by helper functions, a flow this per-file proof does not bind and
leaves selected. The ticket's acceptance "a probe docs-only edit selects no hub package" is
therefore NOT met for this repository; the remaining lever is a fixture marker or a declared read
scope per hub package, both outside a lane step. Tests: `TestTempJoinComponents_AFP_V0_9810` (19
shapes), `TestTempJoinComponentsNeedsImports_AFP_V0_9810`,
`TestTempJoinedLiteralSelectsNoReader_AFP_V0_9810`.
