## Friction

- `corvint impact` refuses the whole request (`unsupported-impact-path-suffix`) when one path is
  `Makefile`, instead of omitting that path with an unknown. Repro: a `corvint impact` request
  naming `Makefile` and `cmd/corvint/affected.go`.
- `cmd/corvint` selection is whole for nearly every change and takes about 10 minutes, so lanes
  hand-pick `-run` lists and miss contract tests (V1-3907). `corvint test` gives no hint of the
  contract tests to keep in a focused subset.
- PR CI runs no shell tests; shell checks reach PRs only when listed in `DOC_GATE_TARGETS`, so a
  GOC-V0-008 violation landed on main (`script/lane-scripts_test.sh:1850`).
- The installed `corvint` was stale against a probe checkout (`DEGRADED self-binary-stale`).
- `make dogfood-change` prints the prechange receipt commands but does not write the receipts.
- The GOC-V0-008 scanner still flags interpreter names inside `printf` fixture strings (for example
  a `#!/usr/bin/env python3` fixture a test writes), so a test that builds a Python-shebang fixture
  must split the literal. Repro: add `printf '#!/usr/bin/env python3\n' > x` to any `script/*.sh`
  and run `make -s no-python-runtime-dependency-test`.
- The scanner's opt-in exemption is a line-text match, so any line carrying the token in a comment
  is exempt (`python3 -c 1 # CORVINT_TEST_EXTERNAL_PYTEST`). Narrowed in the trace and pinned, not
  enforced.
- TSP-V0-006 slicing almost never slices `cmd/corvint`: 1 of 281 plain-signature functions
  produced a slice, and every Core verb file's first function shares memory through its
  signature. A focused run of a Core verb change is therefore always whole-package (~10 min).
- A lane whose base predates a main fix it depends on must cherry-pick that fix, which conflicts on
  unrelated header comments and adds a foreign build-log file to the lane's citation surface.
