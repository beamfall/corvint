`--only toolchain` host check of lane lnt-u32 (ASD-V0-767). Both overlap the lane's

records the narrowing.

## Review fixes

An independent review found two P2 defects in carried scripts.

- `script/ssh-heredoc-check.sh` (ASD-V0-769) scanned shell comments as code. An apostrophe in
  `# don't` opened a quote, and the quoted heredoc on the next line passed. An unquoted `#` at a
  word start now skips to its newline. A hostile pass over the same scanner found more ways past
  it: a line continuation before a comment, subshells, `$(...)`, backquotes, case arms, `$'...'`,
  `2>&1` and `&>` read as command separators, a quoted or backslashed `ssh` name, and `bash -c`
  scripts. Each now has a fixture that fails on the earlier scanner. Command substitution inside
  double quotes, `eval` and redirections before the command name stay non-goals.
- `script/github-split-check.sh` (ASD-V0-706) parsed Git's display-quoted paths, so
  `.github/workflows/é.yml` read as code and a mixed range passed. It now reads `git log -z`
  and also refuses when the header count differs from `git rev-list --count`.
