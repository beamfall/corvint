## Friction

1. Lanes are queued on host load. Repro: Go tests through `script/heavy.sh` on a busy wsl-lanes.
   Expected: a bounded wait. Actual: load-gate queueing, plus refusals of whole-package runs
   (`whole-reason-missing`) even for a 35 ms `internal/mcp/cli` package.
2. `/tmp` disk space ran low on wsl-lanes during builds. Expected: enough room for the Go cache.
   Actual: low-disk failures until the cache was trimmed.
3. Over ssh, a `make` run longer than 180 s is moved to the background, which conflicts with the
   no-background rule. Every make call needs `timeout 170` and has to be split.
4. foreign-callers reads tracked files only, so a new script is not declared until it is
   committed.
5. The installed lane-guard differs from the copy on origin/main.
6. The genesis RefTips cap of 1024 is reached on this repository.
7. The cause of V1-4172 is outside the repository and could not be reproduced.
8. The V1-3936 merge driver is not on main, so V1-4167 cannot be proven against it.
9. The installed corvint binary is stale (`DEGRADED self-binary-stale`, built from `6d4713fb8b5d`)
   on wsl-lanes.
10. The scratchpad `tickets.txt` was garbled. `corvint-tasks ticket show ID --json` works, but for
    some tickets `operatorNote` is null, and a reader indexing it crashes.
11. Every Makefile edit moves cited Makefile lines in unrelated specs (3 this lane). `make repin`
    fixes it in one command, but the failure message did not name it (fixed, V1-4128).
12. `no-python-runtime-dependency-test` failed on origin/main, because no PR job ran it (fixed,
    V1-3489).
13. `dogfood-inputs-check` refuses an intents file of more than 16 specs (`intent-scope-limit`) and
    any spec without one `## Requirements` heading (`intent-invalid`). A wide synthetic plan
    therefore needs a hand-filtered intents file.
14. `script/check-line-citations.sh --repin` relocated a single short-line anchor
    (`Makefile:207` to `:212`), which the check's own message had said it would not do. The
    message and the behaviour disagree.
