1. File readers: existing commandPath route and AST lint pass; fix `receipt put`'s indirect reader
   and add an actual Env.Cwd integration regression, since the AST lint sees direct argv opens only.
2. `wire.HasCode`: already delivered under TCD-V0-965; its nil/positive/negative test passes.
3. `usage()` refusal codes: already MALFORMED under TCD-V0-965, retained by focused CLI tests.
4. Unfiltered search: explicitly decline a second listing spelling. `ticket list` is the unfiltered
   read; CTS-V0-870 pins the existing MALFORMED remedy. Keep the accepted distinct contracts.
5. Multi-ticket mutations: existing per-ticket multi-target note/hold and refine/progress batch
   forms cover common use. Decline a new atomic cross-ticket transaction: partial-prefix receipts,
   CAS and recovery are intentionally per entry (CTW-V0-013), not an implicit all-or-nothing group.
6. Request-ID/derived-prefix bounds: decline widening the 64-byte wire limit. Existing limit help
   names it before store access, and multi-target request derivation uses bounded digest suffixes.
   A shorter caller base preserves deterministic replay without a format migration.
7. `wire.Encode` returning bytes: decline a breaking return-type change to the canonical binary
   interface. Callers needing text use explicit `string(wire.Encode(v))` at their boundary.
8. Workflow slash encoding: already delivered `postmergeworkflow.EncodeID`/`DecodeID` under
   PMR-V0-960; branch names round-trip with a canonical encoding, and malformed encodings refuse.
