`TestCurrentTasksSourceArchiveBuildsOffline` and `TestCorvintBundledBinariesBuildTwiceIdentically`
(about 170 s each) ran in each lane closeout's sealed-head precheck, because `corvint affected`
always selects `internal/companionrelease`. Decision (`ASD-V0-825`): with `LANE=1` and a readable
diff, `@own` entries run only when a `COMPANION_INPUTS` path changed. The receipt of such a run gets

precheck always runs the builds. Trade-off: a lane change outside those inputs that breaks
reproducibility or the archive bounds is found at batch level, not at the lane.
