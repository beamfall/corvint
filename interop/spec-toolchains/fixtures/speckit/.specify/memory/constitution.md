# Session Service Constitution

## Core Principles

### I. Secure by Default
Every feature MUST fail closed when the authentication state is unknown.

### II. Test-First
Acceptance scenarios are written and agreed before implementation starts.

## Governance
This constitution supersedes other practices. Amendments need a documented reason and a version bump.
